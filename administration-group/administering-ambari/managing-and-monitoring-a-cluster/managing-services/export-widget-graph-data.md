# Export widget graph data

Use export options on the **Metrics** widget dashboard to save service metrics data locally.

**About this task**  
Many of the service metrics widgets support exporting the data represented on the widget graph.You can export the metrics data from those widget graphs using the **Export** option.

**Steps**

1. For a widget on **Service &gt; Metrics**, click the Edit Widget icon ![](https://docs.cloudera.com/HDPDocuments/Ambari-2.7.3.0/managing-and-monitoring-ambari/how-to/images/amb_edit_widget_icon.png), or click the magnify icon, ![](https://docs.cloudera.com/HDPDocuments/Ambari-2.7.3.0/managing-and-monitoring-ambari/how-to/images/amb_magnify_zoom_in.png) if displayed.
2. If the **Export** icon appears, click it.![](https://docs.cloudera.com/HDPDocuments/Ambari-2.7.3.0/managing-and-monitoring-ambari/how-to/images/amb_export_widget_graph_data.png)
3. Click either **Save as CSV** or **Save as JSON**. A file of the selected format containing metrics data downloads to your local drive.
