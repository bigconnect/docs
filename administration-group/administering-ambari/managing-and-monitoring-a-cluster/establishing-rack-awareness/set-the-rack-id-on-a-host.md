# Set the rack id on a host

**Steps**

1. In **Ambari Web**, browse to the **Hosts** page. 
2. Click **Host Actions**. 
3. Click **Set Rack**. ![](https://docs.cloudera.com/HDPDocuments/Ambari-2.7.3.0/managing-and-monitoring-ambari/how-to/images/amb_set_rack_indiv_host.png)

**After you finish**  
Verify rack awareness.
