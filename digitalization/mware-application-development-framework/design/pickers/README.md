# Pickers

All pickers are [Form](https://docs.budibase.com/docs/forms) components that cover a range of data types.

In addition, each picker can perform an Action when an item is selected through the On Change event.

This page will summarise the five available pickers within Mware Application Development Framework.

### Options and Multi-select pickers

There are three available data sources for dropdown lists in Mware Application Development Framework.

The Options Picker only allows the user to select a single item, whereas the Multi-select Picker allows a user to select many.

### Relationship picker

The Relationship picker should always be used to handle Relationship fields.

### Date picker

The Date Picker allows a user to select a Date/Time from a pop-up calendar.

### User Field

A special field type that only works with the User data type. If the _Allow multiple users_ is selected, then it will automatically allow multiple selections, otherwise only one user can be chosen.

It can also be optionally searched on the users email address.
