# Portainer

We've added a Portainer template file, which can be pulled into Portainer to allow rapid deployments.

### How to add the template to portainer

1. Go to Portainer settings
2. Enter `https://raw.githubusercontent.com/...` into the app settings URL field, and click save:

<figure><img src="https://files.readme.io/d0dd859-161258575-bcc22294-f441-4ed5-8944-006a8df775f0.png" alt=""><figcaption></figcaption></figure>

3. Go to templates, and see that it is now an option
