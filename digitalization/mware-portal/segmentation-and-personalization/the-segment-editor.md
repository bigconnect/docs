# The Segment Editor

Segmentation and Personalization in MWARE Portal provides an editor for defining User Segments.

1. Go to _Site Administration_ and select the site that you wish to create segments for.
2. Click _People_ → _Segments_.
3. Click the _Add User Segment_ button (![Add](https://liferay-support.zendesk.com/hc/article\_attachments/360033274372/icon-add.png)).

At the top of the editor you can set the name, view the current members of the segment as it is defined, and choose to _Save_ the Segment or _Cancel_ to discard changes.

![Figure 1: The top portion of the Segment Editor has the segment name and its members.](https://liferay-support.zendesk.com/hc/article\_attachments/360029911671/sp-editor-top.png)

On the right side of the page, there’s a Properties menu with the following options:

* User
* Organization
* Session

![Figure 2: You use the Segment Editor to create new Segments.](https://liferay-support.zendesk.com/hc/article\_attachments/360029927832/sp-segment-editor-full.png)

In addition to the various properties, there are operations and conjunctions that you use to define criteria.

### User Properties <a href="#user-properties" id="user-properties"></a>

User Properties are user attributes you want to capture. This is made up of user metadata as defined in their accounts, but also contains certain group memberships (like Roles and User Groups) as well as information like the date the user profile was last modified.

### Organization Properties <a href="#organization-properties" id="organization-properties"></a>

Organization Properties is a selectable list of Organizations to include in your Segment. They contain similar criteria as the User selection, like _Name_ and _Date Modified_.

### Session Properties <a href="#session-properties" id="session-properties"></a>

Session Properties contains criteria based on the user’s activity, browser, and system information. You can use this to target the user’s device or OS, or for activity-based criteria like if a user entered the website through a specific campaign driven landing page.
