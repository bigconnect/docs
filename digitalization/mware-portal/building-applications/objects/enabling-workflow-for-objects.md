# Enabling Workflow for Objects

Every published object is integrated automatically with the Workflow framework, so you can direct object entry creation through a defined review and approval process. How you enable a Workflow for an object depends on the object’s scope: Company or Site.

See Workflow documentation to learn more about general workflow features.

### Company-Scoped Objects <a href="#company-scoped-objects" id="company-scoped-objects"></a>

Follow these steps to enable a custom Workflow for a company-scoped object:

1. Open the _Global Menu_ (![Global Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-applications-menu.png)), go to the _Applications_ tab, and click _Process Builder_.
2.  Click the _Configuration_ tab.

    ![Go to Process Builder and click the Configuration tab.](https://resources.learn.liferay.com/images/dxp/latest/en/building-applications/objects/enabling-workflows-for-objects/images/01.png)
3. Click _Edit_ for the desired object.
4. Select the desired _Workflow_.
5. Click _Save_.

### Site-Scoped Objects <a href="#site-scoped-objects" id="site-scoped-objects"></a>

Follow these steps to enable a custom Workflow for a site-scoped object:

1.  Open the _Site Menu_ (![Site Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-menu.png)) → _Configuration_ → _Workflow_.

    ![Open the Workflow application in the desired Site.](https://resources.learn.liferay.com/images/dxp/latest/en/building-applications/objects/enabling-workflows-for-objects/images/02.png)
2. Click _Edit_ for the desired object.
3. Select the desired _Workflow_.
4. Click _Save_.
