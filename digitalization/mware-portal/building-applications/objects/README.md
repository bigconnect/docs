# Objects

With Liferay Objects, you can build and deliver applications without having to write code or deploy modules. Each application built with Objects is integrated with Liferay’s core frameworks, so you can quickly develop and manage flexible solutions that adapt Liferay DXP to your business needs while maintaining a seamless user experience.

When creating an object definition, you can add data [fields](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/creating-and-managing-objects/fields), [relationships](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/creating-and-managing-objects/relationships) to other definitions, and [actions](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/creating-and-managing-objects/actions) that execute under specified conditions. You can also design [layouts](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/creating-and-managing-objects/layouts) and [views](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/creating-and-managing-objects/views) to determine how fields and relationships appear during entry creation and in the object’s application page.

From the time of creation, all objects are fully integrated with Liferay’s [core frameworks](https://learn.liferay.com/web/guest/w/dxp/building-applications/core-frameworks) to provide a unified experience across the platform and leverage all of Liferay’s capabilities. This includes automatically generating [Headless REST APIs](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/understanding-object-integrations/using-custom-object-apis) for every object, so you can interact with your objects through defined endpoints. These APIs can also be used with the [Job Scheduler](https://learn.liferay.com/web/guest/w/dxp/building-applications/core-frameworks/job-scheduler-framework/using-job-scheduler) integration to configure Talend jobs to sync object data dynamically with external systems.

Every object is integrated with [Workflows](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/enabling-workflows-for-objects), so you can guide object entry creation through a defined review and approval process. Objects are also integrated with [Forms](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/using-forms-with-objects), so you can design forms that map to object fields and receive user input for creating object entries.

Once entries are created, you can leverage Liferay’s Info framework to create dynamic user experiences by [displaying object entries](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/displaying-object-entries) with Page Fragments and Display Page Templates. You can also add an object to site pages as a [widget](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/deploying-object-widgets-to-sites).

All objects are integrated with Liferay’s [Permissions framework](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/understanding-object-integrations/permissions-framework-integration), so you can assign application and resource permissions to manage access to objects and their entries. Together with scoping, role-based access control can help you secure your data and ensure it can only be accessed by the appropriate users.

With Objects, you can also extend and configure [system services](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/creating-and-managing-objects/extending-system-objects) registered with the Objects framework. This includes adding custom relationships and actions.

See [Creating Objects](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/creating-and-managing-objects/creating-objects) to get started building custom applications or [Understanding Object Integrations](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/understanding-object-integrations) to learn more about how Objects leverages Liferay’s core frameworks.
