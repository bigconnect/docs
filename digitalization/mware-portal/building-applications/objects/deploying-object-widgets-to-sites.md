# Deploying Object Widgets to Sites

When an Object is published, the portal automatically generates a dedicated widget you can deploy to Site Pages. This includes both Site-scoped and Company-scoped Objects, so you can grant access to an Object outside of the Site Menu (![Site Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-menu.png)) and Global Menu (![Global Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-applications-menu.png)).

NOTE

Widget data is saved and displayed according to the Object’s scope.

### Showing and Hiding Object Widgets <a href="#showing-and-hiding-object-widgets" id="showing-and-hiding-object-widgets"></a>

1. Open the _Global Menu_ (![Global Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-applications-menu.png)), go to the _Control Panel_ tab, and click _Objects_.
2. Select the desired _Object_.
3.  In the Details tab, toggle the _Show/Hide Widget_ switch.

    ![Toggle the Show/Hide Widget switch.](https://resources.learn.liferay.com/images/dxp/latest/en/building-applications/objects/deploying-object-widgets-to-sites/images/01.png)
4. Click _Save_.

If the switch is toggled to _Show Widget_ and the Object is published, you can immediately add the widget to Site Pages.

However, if the switch is toggled to _Hide Widget_, it is hidden in the widget menu and cannot be added to a page.

NOTE

Hiding an Object’s widget does not remove it from Site Pages where it is already deployed. Hiding the widget only prevents users from adding it to a new Page.

### Adding the Widget to Pages <a href="#adding-the-widget-to-pages" id="adding-the-widget-to-pages"></a>

When _Show Widget_ is enabled for a Published Object, its widgets appear under _Objects_ in the widget menu.

You can add the widget to Site Pages like any other Page widget.

![Add Object widgets to Site Pages.](https://resources.learn.liferay.com/images/dxp/latest/en/building-applications/objects/deploying-object-widgets-to-sites/images/02.png)

You can also click the widget’s _Options_ button (![Options Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) to access additional functions and configuration options.

![Click the Options button to access additional functions and configuration options.](https://resources.learn.liferay.com/images/dxp/latest/en/building-applications/objects/deploying-object-widgets-to-sites/images/03.png)

Available options depend on whether the widget is deployed to a Content Page or Widget Page.
