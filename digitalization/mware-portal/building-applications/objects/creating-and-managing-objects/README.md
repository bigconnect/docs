# Creating and Managing Objects

Liferay Objects provides a convenient UI for [creating](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/creating-and-managing-objects/creating-objects) custom applications that meet your business needs without writing code. You can also use Objects to manage and extend both system and custom objects. This includes adding [fields](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/creating-and-managing-objects/fields), [relationships](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/creating-and-managing-objects/relationships), [actions](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/creating-and-managing-objects/actions), [layouts](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/creating-and-managing-objects/layouts), [views](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/creating-and-managing-objects/views), [validations](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/creating-and-managing-objects/validations), and [custom states](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/creating-and-managing-objects/fields/adding-and-managing-custom-states). You can also use the Model Builder GUI to design complex object structures. This graphical tool shows object definitions as cards and visualizes relationships between definitions. See [Using the Objects Model Builder](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/creating-and-managing-objects/using-the-objects-model-builder) for more information.

NOTE

System objects are default Liferay applications integrated with the objects framework, while custom objects are definitions created and published by a user.
