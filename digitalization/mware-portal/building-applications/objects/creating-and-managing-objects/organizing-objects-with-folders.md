# Organizing Objects with Folders

By default, object definitions are grouped in the Uncategorized folder, but you can add object folders to organize data models and manage access to definitions.

### [Creating Folders](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/creating-and-managing-objects/organizing-objects-with-folders#creating-folders) <a href="#creating-folders" id="creating-folders"></a>

1. Open the _Global Menu_ (![Global Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-applications-menu.png)), go to the _Control Panel_ tab, and click _Objects_.
2. Click _Add Folder_ (![Add Folder Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-plus.png)).
3.  Enter a _Label_ and _Name_.

    **Label**: Identifies the relationship in the Objects UI and can be localized after the relationship is created.

    **Name**: Determines the relationship’s name in the back-end and uses camel case. Once the relationship is published, this value cannot be changed.

    ![Enter a folder Label and Name.](https://resources.learn.liferay.com/images/dxp/latest/en/building-applications/objects/creating-and-managing-objects/organizing-objects-with-folders/images/01.png)
4.  Click _Create Folder_.

    ![Create the object folder.](https://resources.learn.liferay.com/images/dxp/latest/en/building-applications/objects/creating-and-managing-objects/organizing-objects-with-folders/images/02.png)

This creates an empty folder with an autogenerated ERC. If desired, you can update the ERC by clicking _Actions_ (![Actions Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) for the folder and selecting _Edit Label and ERC_.

### [Adding Definitions to Folders](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/creating-and-managing-objects/organizing-objects-with-folders#adding-definitions-to-folders) <a href="#adding-definitions-to-folders" id="adding-definitions-to-folders"></a>

While in a folder, you can click _Add_ (![Add](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-add.png)) to create object definitions in it. To move existing definitions to the folder,

1. Go to the desired destination folder.
2. Click _View in Model Builder_.
3. Click _Actions_ (![Actions Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) for an object from another folder in the left sidebar.
4.  Select _Move to Current Folder_.

    ![Select Move to Current Folder](https://resources.learn.liferay.com/images/dxp/latest/en/building-applications/objects/creating-and-managing-objects/organizing-objects-with-folders/images/03.png)

This moves the definition to the current folder. Moving an object definition does not affect its relationships and is only for improving organization and object management.

### [Deleting Folders](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/creating-and-managing-objects/organizing-objects-with-folders#deleting-folders) <a href="#deleting-folders" id="deleting-folders"></a>

1. Go to the desired folder.
2.  Click _Actions_ (![Actions Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) and select _Delete_.

    ![Click the Actions button and select Delete.](https://resources.learn.liferay.com/images/dxp/latest/en/building-applications/objects/creating-and-managing-objects/organizing-objects-with-folders/images/04.png)
3.  Enter the folder’s name to confirm and click _Delete_.

    ![Enter the folder's name to confirm and click Delete](https://resources.learn.liferay.com/images/dxp/latest/en/building-applications/objects/creating-and-managing-objects/organizing-objects-with-folders/images/05.png)

Once deleted, all objects in the folder are relocated to the default Uncategorized folder. This action cannot be undone.
