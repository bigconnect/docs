# Setting a Default Sorting

With custom views, you can set a default sorting for tables. Follow these steps:

1. Begin editing the desired view and go to the _Default Sort_ tab.
2. Click _Add_ (![Add Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-add.png)).
3.  Select a _column_ and _sorting_ order (i.e., ascending or descending).

    ![Select a column and sorting order.](https://resources.learn.liferay.com/images/dxp/latest/en/building-applications/objects/creating-and-managing-objects/views/setting-a-default-sorting/images/01.png)
4. Click _Save_.
5.  (Optional) If you add multiple fields, drag and drop them to determine which is the default sorting. The sorting at the top of the list is the default order applied.

    ![Arrange fields to determine which is the default sorting.](https://resources.learn.liferay.com/images/dxp/latest/en/building-applications/objects/creating-and-managing-objects/views/setting-a-default-sorting/images/02.png)
6. Click _Save_.

Object entries are now sorted according to your default sorting.
