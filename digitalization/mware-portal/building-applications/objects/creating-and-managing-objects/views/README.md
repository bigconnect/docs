# Views

Views define how entries appear in an object’s application page. All published objects include an autogenerated table that displays all field columns alphabetically. However, you can [design custom views](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/creating-and-managing-objects/views/designing-object-views) to determine which fields to include, how columns are ordered, and available [filters](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/creating-and-managing-objects/views/adding-filters-to-views).

NOTE

Custom views can only be added to custom objects. They cannot be added to system objects.
