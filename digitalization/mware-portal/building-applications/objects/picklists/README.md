# Picklists

_Picklists_ are predefined lists of string values that consist of a name/key pair and can include any number of items. Once a list is created, you can use it to add a single select or multi-select field to object definitions. You can use these fields to filter displayed entries, define custom entry states, and more. When using picklists to define states, you can use validations, actions, and workflow processes to implement complex business logic for each state.
