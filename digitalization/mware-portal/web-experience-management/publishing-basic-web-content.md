# Publishing Basic Web Content

Web Content is one of many different kinds of assets, along with blog posts, wiki articles, message board posts, and other kinds of content. Like all of these assets, the portal handles Web Content using an asset framework that includes categories, tags, comments, ratings and more. Please see Publishing Content Dynamically for more information on the portal’s asset framework.

To start working with Web Content, publish some basic material using Web Content Management’s WYSIWYG editor. Then you can cover the editor’s features in greater depth and learn how to publish the content you create to a page.
