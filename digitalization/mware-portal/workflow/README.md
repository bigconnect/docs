# Workflow

Workflow makes it possible to define any number of simple to complex business processes/workflows, deploy them, and manage them through a portal interface. The processes have knowledge of Users, Groups and Roles.&#x20;

There are several steps to effective workflowing:

* Visually designing review processes
* Uploading workflow definitions
* Activating workflow for enabled assets
* Managing Workflow definitions
* Sending assets through review
* Using Workflow Metrics
