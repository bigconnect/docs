# Elasticsearch

A typical Liferay system’s search infrastructure comprises

* Liferay servers configured in a cluster or a single node (on-premises or Docker containers)
* Elasticsearch server(s) (on-premises or Docker containers)
* An Elasticsearch connector application deployed onto Liferay and configured to fit your deployment.

Assuming your Liferay servers are in place already, the remaining steps include

1. Determining the Elasticsearch server and connector version to use
2. Setting up your Elasticsearch server(s)
3. Connecting Liferay to Elasticsearch

### [Finding Compatible Elasticsearch and Connector Versions](https://learn.liferay.com/web/guest/w/dxp/using-search/installing-and-upgrading-a-search-engine/elasticsearch/getting-started-with-elasticsearch#finding-compatible-elasticsearch-and-connector-versions) <a href="#finding-compatible-elasticsearch-and-connector-versions" id="finding-compatible-elasticsearch-and-connector-versions"></a>

Each Liferay CE/DXP version is bundled with a connector to Elasticsearch that is compatible with a specific Elasticsearch major version (e.g., 6.x or 7.x). To add support for newer major Elasticsearch versions, Liferay releases additional connectors through [Marketplace](https://web.liferay.com/marketplace). These can be used as drop-in replacements for the out-of-the-box (bundled) connector.

The [Search Engine Compatibility Matrix](https://help.liferay.com/hc/en-us/articles/360016511651) shows the latest supported Elasticsearch component versions for each Liferay version. The Elasticsearch server and the connector to Elasticsearch are required components.

WARNING

The Liferay Connector to Elasticsearch that your Liferay installation includes may not be the latest connector. Make sure to use the latest connector for the Elasticsearch version you’re using. The connectors are available on [Liferay Marketplace](https://web.liferay.com/marketplace).

## [Elasticsearch Connector Configuration Reference](https://learn.liferay.com/web/guest/w/dxp/using-search/installing-and-upgrading-a-search-engine/elasticsearch/elasticsearch-connector-configuration-reference#elasticsearch-connector-configuration-reference) <a href="#elasticsearch-connector-configuration-reference" id="elasticsearch-connector-configuration-reference"></a>

IMPORTANT

The _Elasticsearch 7_ system settings entry and corresponding configuration file are also used for configuring the connection to Elasticsearch 8.

The connection to Elasticsearch is primarily defined in the _Elasticsearch 6/7_ configuration entry in System Settings (or via the [corresponding configuration file](https://learn.liferay.com/web/guest/w/dxp/using-search/installing-and-upgrading-a-search-engine/elasticsearch/elasticsearch-connector-configuration-reference#configuration-files-and-system-settings-entries)). In Liferay 7.3+ you can define multiple connections to Elasticsearch, through the [factory configuration](https://learn.liferay.com/web/guest/w/dxp/system-administration/configuring-liferay/configuration-files-and-factories/using-factory-configuration) _Elasticsearch Connections_. Both entries are configurable through [System Settings](https://learn.liferay.com/web/guest/w/dxp/system-administration/configuring-liferay/system-settings) or an [OSGi configuration file](https://learn.liferay.com/web/guest/w/dxp/system-administration/configuring-liferay/configuration-files-and-factories/using-configuration-files). Configuration files are the recommended approach for production environments.

### [Configuration Files and System Settings Entries](https://learn.liferay.com/web/guest/w/dxp/using-search/installing-and-upgrading-a-search-engine/elasticsearch/elasticsearch-connector-configuration-reference#configuration-files-and-system-settings-entries) <a href="#configuration-files-and-system-settings-entries" id="configuration-files-and-system-settings-entries"></a>

| Connecting Servers                           | System Settings Entry/Configuration File                                                                                                                                                                                                                                                                     |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| <p>Liferay 7.2.x<br>Elasticsearch 6.x</p>    | <p>Elasticsearch 6<br><code>com.liferay.portal.search.elasticsearch6.configuration.ElasticsearchConfiguration.config</code></p>                                                                                                                                                                              |
| <p>Liferay 7.2.x<br>Elasticsearch 7.x</p>    | <p>Elasticsearch 7<br><code>com.liferay.portal.search.elasticsearch7.configuration.ElasticsearchConfiguration.config</code></p>                                                                                                                                                                              |
| <p>Liferay 7.3+<br>Elasticsearch 7.x/8.x</p> | <p>Elasticsearch 7<br><code>com.liferay.portal.search.elasticsearch7.configuration.ElasticsearchConfiguration.config</code><br><br>Elasticsearch Connections (factory)<br><code>com.liferay.portal.search.elasticsearch7.configuration.ElasticsearchConnectionConfiguration-[connectionId].config</code></p> |

In Liferay 7.3 and beyond, there’s an additional connection configuration entry, Elasticsearch Connections. You can use this to define any connection to Elasticsearch, but if you are only configuring one connection you can still use the main Elasticsearch 7 configuration entry. If using multiple connections in 7.3+, define connections with files named accordingly:

```log
com.liferay.portal.search.elasticsearch7.configuration.ElasticsearchConnectionConfiguration-[connectionId].config
```

If configuring security on Elasticsearch 6, a separate Liferay configuration (as well as a LES subscription) is required. See [Securing Elasticsearch](https://learn.liferay.com/web/guest/w/dxp/using-search/installing-and-upgrading-a-search-engine/elasticsearch/securing-elasticsearch) for more information.

Deploy configuration files to `[Liferay_Home]/osgi/configs` and a listener auto-detects the configurations and writes them to the database.
