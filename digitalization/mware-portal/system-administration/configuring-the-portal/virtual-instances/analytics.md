# Analytics

The Analytics category defines the available analytics systems for the virtual instance. Enter an analytics system or remove one of the two pre-configured options (`google` and `piwik`). Activate these systems here, and configure them at the site level.

![Configure the Analytics engines in the Site Administration Configuration, in the Advanced section.](https://resources.learn.liferay.com/images/dxp/latest/en/system-administration/configuring-liferay/virtual-instances/analytics/images/01.png)

To access Analytics configuration settings, open the Control Panel, navigate to _Configuration_ → _Instance Settings_, and select the _Analytics_ category under the _PLATFORM_ section.

![Add or remove Analytics engines from Instance Settings.](https://resources.learn.liferay.com/images/dxp/latest/en/system-administration/configuring-liferay/virtual-instances/analytics/images/02.png)
