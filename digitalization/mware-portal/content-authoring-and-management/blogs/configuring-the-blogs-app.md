# Configuring the Blogs App

You can control how the app behaves for all blogs in your site.

1. Open the _Site Menu_ ( ![Site Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-product-menu.png) ) and navigate to _Content and Data_ → _Blogs_.
2.  Click _Options_ (![Options icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-options.png)) at the top-right of the app.

    ![Click on the options icon to configure your blogs app.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/blogs/configuring-the-blogs-app/images/01.png)
3. Configure the available options below.

**Export/Import:** Export or import a LAR file that contains the blogs app’s content. See [Exporting/Importing Widget Data](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/page-fragments-and-widgets/using-widgets/configuring-widgets/exporting-importing-widget-data) to learn more about the process.

![Export/import the blogs app's content.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/blogs/configuring-the-blogs-app/images/02.png)

**Entries Permissions:** Configure the [permissions](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/blogs/blog-permissions-reference) for blog entries. You can control which roles can add an entry, configure entry permissions, and subscribe to entries.

**Configuration:** Configure the following options for the blogs app, in these tabs:

![In Configuration, you can set email and RSS options](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/blogs/configuring-the-blogs-app/images/03.png)

**Email From:** Define the _From_ field in the email messages sent from blogs.

**Entry Added Email:** Define a subject and body for the emails sent when a new blog entry has been added.

**Entry Updated Email:** Define a subject and body for the emails sent when a new blog entry has been updated.

**RSS:** Enable RSS subscription and choose how blogs are published to RSS readers.

* _Maximum Items to Display:_ Choose the total number of RSS feed entries to display on the initial page. You can choose up to 100 to be displayed.
* _Display Style:_ Choose between Full Content, Abstract, and Title for the entry display in the RSS feed.
* _Format:_ Choose which format the RSS feed uses to deliver the entries: Atom 1.0, RSS 1.0, or RSS 2.0.
