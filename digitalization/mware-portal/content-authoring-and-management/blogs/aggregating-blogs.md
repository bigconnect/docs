# Aggregating Blogs

The Blogs Aggregator widget publishes blogs entries from multiple blog sources.

![The Blogs Aggregator widget shows multiple blogs.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/blogs/aggregating-blogs/images/03.png)

To configure the widget, click _Options_ (![Options icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-app-options.png)) → Configuration.

![There are different setup options for the Blog Aggregator widget](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/blogs/aggregating-blogs/images/02.png)

Within the configuration screen there are several tabs with different options.

### [Setup](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/blogs/aggregating-blogs#setup) <a href="#setup" id="setup"></a>

The Setup tab contains these options:

**Selection Method:** Set how the widget selects blogs for display. You can choose _Users_ or _Scope_. If you select Users, the widget aggregates the entries of every blogger on your system. To refine the aggregation, you can filter the Users by selecting an organization. If you select Scope, the widget aggregates the entries of users in the current scope. This limits the entries to members of the Site or Organization where the widget resides.

**Organization:** Select the Organization whose blogs you want to aggregate.

**Display Style:** Select the overall appearance for blog entries in the widget: _Body and Image_, _Body_, _Abstract_, _Abstract without Title_, _Quote_, _Quote without Title_, and _Title_.

**Maximum Items to Display:** Set the maximum number of entries to display.

**Show Tags:** Set whether to display each entry’s tags.

#### [RSS Settings](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/blogs/aggregating-blogs#rss-settings) <a href="#rss-settings" id="rss-settings"></a>

**Enable RSS Subscription:** Enable an RSS feed of the aggregated entries. Below this option, you can configure how you want to display the RSS feed:

**Maximum Items to Display:** Set the maximum number of RSS items to display.

**Display Style:** Set the overall appearance of each entry in the RSS feed: _Abstract_, _Full Content_, or _Title_.

**Format:** Set the language to use for your RSS feed: _Atom 1.0_, _RSS 1.0_, or _RSS 2.0_.

### [Sharing](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/blogs/aggregating-blogs#sharing) <a href="#sharing" id="sharing"></a>

Use the options here to embed the widget instance as a widget on any website, Facebook, Netvibes, or as an OpenSocial Gadget.

### [Scope](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/blogs/aggregating-blogs#scope) <a href="#scope" id="scope"></a>

Specify the blog instance the widget displays: the current Site’s blog (default), the global blog, or the page’s blog.

### [Conclusion](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/blogs/aggregating-blogs#conclusion) <a href="#conclusion" id="conclusion"></a>

When you finish setting the options, click _Save_ and then close the dialog box.

You’ll notice that the Blogs Aggregator looks much like the Blogs widget, except that it shows entries from multiple blogs.
