# Managing Blog Entries

Bloggers and blog administrators manage blog entries using the _Blogs_ application in the Site Administration menu. To access this app, open the _Product Menu_ (![Product Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-product-menu.png)) and select _Content & Data_ → _Blogs_.

The Entries tab is selected by default, which lists the site’s blog entries. Use the management bar to manage your site’s blog entries.

### Finding and Arranging Blog Entries <a href="#finding-and-arranging-blog-entries" id="finding-and-arranging-blog-entries"></a>

The management bar also contains tools that help you locate and arrange blog entries (e.g. use the search bar to find files by keywords).

To the left of the search bar, the Sort button (![Sort button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-sort.png)) arranges entries in ascending or descending order.

Click _Filter and Order_ to sort entries using these criteria:

![Filter and Order menu](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/blogs/managing-blog-entries/images/02.png)

| Filter                      | Description                            |
| --------------------------- | -------------------------------------- |
| (Filter By Navigation) All  | Shows all of the site’s entries.       |
| (Filter By Navigation) Mine | Shows only the current user’s entries. |
| (Order By) Title            | Orders the entries by title.           |
| (Order By) Display Date     | Orders the entries by display date.    |

#### View Types <a href="#view-types" id="view-types"></a>

The View Types button is to the left of the Add button. Users can choose how to display the blog entries in the Blogs app. The View Types button’s icon depends on the selected view type:

| View Type | Description                                                                                                                                                                                                  |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Cards     | Shows a card-like rendering of the blog entry, with the author’s profile picture. Each card also contains the entry’s time stamp, title, workflow status (e.g., Approved, Draft, etc.), and an Actions menu. |
| List      | Shows the same information as the Cards view type, in a list with the author’s profile picture instead of the blog entry’s cover image.                                                                      |
| Table     | Shows the same information as the other view types, in a list with no file renderings.                                                                                                                       |

![See the different View Types in the Site Administration Blogs Menu](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/blogs/managing-blog-entries/images/03.png)

### Deleting Blog Entries <a href="#deleting-blog-entries" id="deleting-blog-entries"></a>

1. Check the entry or entries you want to delete.
2. Click _Trash_ (![Trash icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-trash.png)) to move the selected entries to the Recycle Bin.

![Select and delete a blog entry](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/blogs/managing-blog-entries/images/01.png)

### Sharing Blog Entries <a href="#sharing-blog-entries" id="sharing-blog-entries"></a>

You can also share blog entries from the Blogs app in Site Administration. When you share a blog entry, you invite a user to collaborate with the blog entry. Sharing is enabled by default. Sharing blog entries works the same as sharing files in Documents and Media.

To share a blog entry,

1. Click _Actions_ (![Actions menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) for the entry you want to share → _Share_.
2. Enter the email address of the collaborator. You can enter multiple addresses.
3. To let receiving users share the entry, check _Allow the item to be shared with other users_.
4. Grant users a sharing permission to define what invited collaborators can do with the blog entry: Update (view, comment, and update), comments (view and comment), or view (view only).
5. Click _Share_.

![Share a blog entry via its Actions menu.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/blogs/managing-blog-entries/images/04.png)
