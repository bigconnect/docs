# About the Content Performance Tool

The Content Performance tool is a global application for analyzing performance metrics of your content, like traffic acquisition channels or the number of views over time. Content teams can use the Content Performance tool to periodically assess and adapt their content strategy. The Content Performance tool is available for assets based on a [Display Page Template](https://learn.liferay.com/web/guest/w/dxp/site-building/displaying-content/using-display-page-templates/publishing-content-with-display-pages) and starting with Liferay DXP 7.4, for [Content](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages) and [Widget](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-widget-pages/adding-widgets-to-a-page) Pages.

To learn how to analyze your content performance quantitatively using the Content Performance tool, see [Analyze Content Metrics Using the Content Performance Tool](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/page-performance-and-accessibility/analyze-content-metrics-using-content-performance-tool).

NOTE

To manage and audit your content across Sites and Asset Libraries, use the [Content Dashboard](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/content-dashboard/about-the-content-dashboard).

You can access the Content Performance tool when the following conditions are met:

* The Liferay DXP instance has an active [connection to Liferay Analytics Cloud](https://learn.liferay.com/analytics-cloud/latest/en/connecting-data-sources/connecting-liferay-dxp-to-analytics-cloud.html) and your site is synchronized.
* You have Edit permissions for the Page or content.
* The content is in a Content Page, Widget Page, or is based on a [Display Page Template](https://learn.liferay.com/web/guest/w/dxp/site-building/displaying-content/using-display-page-templates/publishing-content-with-display-pages).

### [Accessing the Content Performance Tool](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/page-performance-and-accessibility/about-the-content-performance-tool#accessing-the-content-performance-tool) <a href="#accessing-the-content-performance-tool" id="accessing-the-content-performance-tool"></a>

You can open the Content Performance tool using the _Content Performance_ (![Content Performance](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-analytics.png)) button from

* [Content based on a Display Page Template](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/page-performance-and-accessibility/about-the-content-performance-tool#accessing-the-content-performance-tool-from-content-based-on-a-display-page-template), like Web Content, Documents and Media, or Blog entries.
* [Content or Widget Pages](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/page-performance-and-accessibility/about-the-content-performance-tool#accessing-the-content-performance-tool-from-content-or-widget-pages) (Liferay DXP 7.4+).
* [The Content Dashboard](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/page-performance-and-accessibility/about-the-content-performance-tool#accessing-the-content-performance-tool-from-the-content-dashboard).

#### [Accessing the Content Performance Tool from Content Based on a Display Page Template](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/page-performance-and-accessibility/about-the-content-performance-tool#accessing-the-content-performance-tool-from-content-based-on-a-display-page-template) <a href="#accessing-the-content-performance-tool-from-content-based-on-a-display-page-template" id="accessing-the-content-performance-tool-from-content-based-on-a-display-page-template"></a>

Using a Display Page Template, you can display Web Content, Documents, or Blog entries in a Display Page using a unique URL. For more information, read [Displaying Content with Display Page Templates](https://learn.liferay.com/web/guest/w/dxp/site-building/displaying-content/using-display-page-templates/publishing-content-with-display-pages).

1. Go to _Site Administration_ → _Content & Data_ → _Web Content_.
2. Click the _Web Content_ tab.
3.  For the Web Content you want to review, click the _Actions_ (![Actions](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) menu and choose _View Content_.

    NOTE

    If the _View Content_ option is not available, the Web Content is not using a Display Page Template.

    ![Access the Content Performance metrics in Web Content.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/page-performance-and-accessibility/about-the-content-performance-tool/images/04.png)
4. In view mode, click the _Content Performance_ (![Content Performance](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-analytics.png)) icon in the [Applications toolbar](https://learn.liferay.com/web/guest/w/dxp/getting-started/navigating-dxp#applications-bar).

#### [Accessing the Content Performance Tool from Content or Widget Pages](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/page-performance-and-accessibility/about-the-content-performance-tool#accessing-the-content-performance-tool-from-content-or-widget-pages) <a href="#accessing-the-content-performance-tool-from-content-or-widget-pages" id="accessing-the-content-performance-tool-from-content-or-widget-pages"></a>

1. Go to _Site Administration_ → _Site Builder_ → _Pages_.
2. For the Page you want to review, click the _Actions_ (![Actions](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) menu and choose _View_.
3.  Click the _Content Performance_ (![Content Performance](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-analytics.png)) icon in the Application toolbar.

    ![Access the Content Performance metrics in Content or Widget Pages.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/page-performance-and-accessibility/about-the-content-performance-tool/images/03.png)

#### [Accessing the Content Performance Tool from the Content Dashboard](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/page-performance-and-accessibility/about-the-content-performance-tool#accessing-the-content-performance-tool-from-the-content-dashboard) <a href="#accessing-the-content-performance-tool-from-the-content-dashboard" id="accessing-the-content-performance-tool-from-the-content-dashboard"></a>

1. Open the [Content Dashboard](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/content-dashboard/content-dashboard-interface#accessing-the-content-dashboard).
2. On the [Contents list](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/content-dashboard/content-dashboard-interface#contents-list), click the _Actions_ menu (![Actions Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) next to the content you want to review, and select _View Metrics_.
3. Alternatively, hover over the content and click the _Content Performance_ (![View Metrics](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-analytics.png)) icon.

![Access the Content Performance metrics from the Content Dashboard.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/page-performance-and-accessibility/about-the-content-performance-tool/images/05.png)

NOTE

If the Content Performance option is not available, your content does not meet one or more conditions. See [About the Content Performance Tool](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/page-performance-and-accessibility/about-the-content-performance-tool#about-the-content-performance-tool) for more information.
