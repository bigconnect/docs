# Publishing Documents

Liferay makes it easy to publish and showcase documents and other types of media files. As you begin [uploading media files](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/uploading-and-managing/uploading-files), you probably want to start sharing them on your site.

The available widgets can highlight your documents and media files: _Media Gallery_, _Documents and Media_, and _Asset Publisher_. You can choose an appropriate widget based on your use case.

You can embed and display Documents and Media files on other assets such as Web Content, Blogs, or Wiki pages.

### [Using the Media Gallery Widget](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/publishing-and-sharing/publishing-documents#using-the-media-gallery-widget) <a href="#using-the-media-gallery-widget" id="using-the-media-gallery-widget"></a>

This widget publishes your media in a simple gallery-like style. It shows a large thumbnail of each file, offers file downloads, and has slideshow capabilities. A common way to use the Media Gallery is to have a separate page for displaying media and add a Media Gallery widget to it. The widget displays only audio or video files.

To use the Media Gallery widget,

1.  From the Content Management category of widgets, add the Media Gallery widget to a page.

    ![Locate the Media Gallery widget listed under the Content Management section of widgets.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/publishing-and-sharing/publishing-documents-on-a-dxp-site/images/01.png)
2. Once the widget appears, any media files previously uploaded should already be visible. If you wish to [add additional media files](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/uploading-and-managing/uploading-files), they can be uploaded from Documents and Media.

The Media Gallery widget has several options you can configure by clicking _Options_ (![Options icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-options.png)) → _Configuration_:

![The configuration window has four different tabs.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/publishing-and-sharing/publishing-documents-on-a-dxp-site/images/02.png)

**Display Settings:** Show each file’s actions, filter the media types to display, and choose a display template for your media.

**Folders Listing:** Select a Document Library folder to serve as the root folder from which to display files. This folder becomes the highest-level folder the widget can access.

In the widget, clicking on any media file automatically starts a slideshow of all the files.

![Clicking on a media file will start a slideshow](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/publishing-and-sharing/publishing-documents-on-a-dxp-site/images/03.png)

On each file is an _Options_ (![Options icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-options.png)) icon:

![You have different options when you click on the Options icon.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/publishing-and-sharing/publishing-documents-on-a-dxp-site/images/04.png)

* Download
* Edit
* Permissions
* Delete

### [Using the Documents and Media Widget](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/publishing-and-sharing/publishing-documents#using-the-documents-and-media-widget) <a href="#using-the-documents-and-media-widget" id="using-the-documents-and-media-widget"></a>

This widget provides a way to publish all types of files. Unlike the Media Gallery widget, you can publish documents and other types of media.

1.  From the Content Management section, add the _Documents and Media_ widget to a page.

    ![Locate the Documents and Media widget listed under the Content Management section of widgets.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/publishing-and-sharing/publishing-documents-on-a-dxp-site/images/05.png)
2. If you wish to [add additional media files](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/uploading-and-managing/uploading-files), they can be uploaded from the Documents and Media application.

You can configure Documents and Media via its _Options_ button (![Options button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-options.png)):

![The configuration window has four different tabs.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/publishing-and-sharing/publishing-documents-on-a-dxp-site/images/06.png)

**Display Settings:** Show each file’s actions, show the search bar, show related assets, set maximum number of files per page, and enable different view options.

**Folders Listing:** Select a Document Library folder to serve as the root folder from which to display files. This folder becomes the highest-level folder the widget can access.

**Entries listing for table display style:** Set what type of file information to display when the user selects Table view.

**Ratings:** Enable or disable the [ratings system](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/social-tools/user-guide/using-the-ratings-system).

The toolbar at the top of Documents and Media provides these functions:

![Access different tools from the toolbar at the top of the widget](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/publishing-and-sharing/publishing-documents-on-a-dxp-site/images/07.png)

**Checkbox:** Select all the media files.

**Filter and Order:** Filter files by document type. You can also sort your files by different parameters.

![Click on filter and order to choose different ways to organize and sort your files.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/publishing-and-sharing/publishing-documents-on-a-dxp-site/images/08.png)

**Reverse:** The _Reverse_ icon (![Reverse icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-sort.png)) reverses the direction of the sorting.

**Search:** Search through your media files by keyword.

**Information:** The _Information_ icon (![Click on the information icon to display file info.](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-information.png)) provides details about the media files within the folder.

**Display Style:** The _Display Style_ icon (![Click on the display style icon to choose your display option.](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-view-type-cards.png)) switches between three display types: Cards, List and Table view.

![Choose between cards, list, or table view to display your files.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/publishing-and-sharing/publishing-documents-on-a-dxp-site/images/09.png)

Users can choose the display type of their choice.

Selecting a file reveals several options:

![Click a checkbox for a file and access additional options.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/publishing-and-sharing/publishing-documents-on-a-dxp-site/images/10.png)

**Clear:** Clear your current selection.

**Information:** The _Information_ icon (![Information icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-information.png)) shows detailed information about the file.

**Download:** The _Download_ icon (![Download icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-download.png)) downloads the file.

**Move:** Click the _Move_ icon (![Move icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-move.png)) to move the file to a different folder.

**Edit Tags:** Click the _Edit Tags_ icon (![Edit icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-edit.png)) to edit the existing tags of a file.

**Delete:** Click the _Trash_ icon (![Trash icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-trash.png)) to delete a file.

**Actions:** The _Actions_ icon (![Actions icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) has options, including _Checkin_ and _Checkout_. See [Google Drive Integration](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/devops/google-drive-integration/enabling-document-creation-and-editing-with-google-drive), [Office 365 Integration](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/devops/enabling-document-creation-and-editing-with-microsoft-office-365), and [LibreOffice Integration](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/devops/enabling-openoffice-libreoffice-integration).

### [Using the Asset Publisher Widget](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/publishing-and-sharing/publishing-documents#using-the-asset-publisher-widget) <a href="#using-the-asset-publisher-widget" id="using-the-asset-publisher-widget"></a>

The [Asset Publisher](https://learn.liferay.com/web/guest/w/dxp/site-building/displaying-content/using-the-asset-publisher-widget/displaying-assets-using-the-asset-publisher-widget) widget can publish different assets and collections based on criteria. You can use it to display content from your Documents and Media library.

### [Using Documents in Other Assets](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/publishing-and-sharing/publishing-documents#using-documents-in-other-assets) <a href="#using-documents-in-other-assets" id="using-documents-in-other-assets"></a>

It is easy to add your documents or media files to other types of assets:

#### [Web Content](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/publishing-and-sharing/publishing-documents#web-content) <a href="#web-content" id="web-content"></a>

1. To be able to add documents or media to your Web Content, first [create a Structure](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/web-content/web-content-structures/creating-structures) that contains a field for documents and media.
2.  Go to the Structures tab of the Web Content application to create a new Structure. Drag and drop the Documents and Media field onto the Structure.

    ![Drag and drop the Documents and Media field onto the Structure.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/publishing-and-sharing/publishing-documents-on-a-dxp-site/images/15.png)
3.  Under the Web Content tab, click on the Add icon (![Add icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-add.png)) to create new Web Content. Select the Structure you just created as your template.

    ![Select the new Structure you just created](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/publishing-and-sharing/publishing-documents-on-a-dxp-site/images/16.png)
4. You can now select documents or media files and add them to your Web Content.

#### [Blogs](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/publishing-and-sharing/publishing-documents#blogs) <a href="#blogs" id="blogs"></a>

1. To add documents and media to your blog, first navigate to the Blog application.
2. Click the Add icon (![Add icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-add.png)) to add a new blog entry.
3.  Under Related Assets, click the _Select_ button to select your documents and media to be added to your blog post.

    ![Under Related Assets, click on the select button to add your documents or media files.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/publishing-and-sharing/publishing-documents-on-a-dxp-site/images/17.png)

#### [Wikis](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/publishing-and-sharing/publishing-documents#wikis) <a href="#wikis" id="wikis"></a>

1. Navigate to the Wiki node.
2.  Under Related Assets, click on the _Select_ button and to select your documents and media to be added to your Wiki page.

    ![Under Related Assets, click on the select button to add your documents or media files.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/publishing-and-sharing/publishing-documents-on-a-dxp-site/images/17.png)
