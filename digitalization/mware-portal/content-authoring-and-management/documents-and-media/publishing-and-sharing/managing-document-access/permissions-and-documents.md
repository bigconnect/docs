# Permissions and Documents

With MWARE Portal’s permissions framework, you can control which users can create, view, download, and manage Documents and Media assets. You can give permissions to an individual file, to an entire folder, or to a specific file type. See Understanding Roles and Permissions for more information.

### Permissions for an Individual File <a href="#permissions-for-an-individual-file" id="permissions-for-an-individual-file"></a>

1. Navigate to the _Documents and Media_ application.
2.  Click _Actions_ (![Actions Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) for the desired file and select _Permissions_.

    ![Click the Actions button for the desired file and select Permissions.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/publishing-and-sharing/managing-document-access/permissions-and-documents/images/01.png)
3. Set your desired permissions.
4. Click _Save_.

### Permissions for an Entire Folder <a href="#permissions-for-an-entire-folder" id="permissions-for-an-entire-folder"></a>

1. Navigate to the _Documents and Media_ application.
2.  Click _Actions_ (![Actions Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) for the desired folder and select _Permissions_. See [Using Folders](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/uploading-and-managing/using-folders) for more information.

    ![Click the Actions button for the desired folder and select Permissions.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/publishing-and-sharing/managing-document-access/permissions-and-documents/images/01.png)
3. Set your desired permissions.
4. Click _Save_.

### Permissions for a Specific File Type <a href="#permissions-for-a-specific-file-type" id="permissions-for-a-specific-file-type"></a>

1.  Navigate to the _Documents and Media_ application and click the _Document Types_ tab.

    ![Click the Document Types tab.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/publishing-and-sharing/managing-document-access/permissions-and-documents/images/03.png)
2.  Click _Actions_ (![Actions Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) for the desired document type and select _Permissions_. See Defining Document Types for more information.

    ![Click the Actions button for the desired document type and select Permissions.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/publishing-and-sharing/managing-document-access/permissions-and-documents/images/04.png)
3. Set your desired permissions.
4. Click _Save_.
