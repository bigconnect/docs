# Documents and Media UI Reference

The Documents and Media application is used to store, view, and manage files for your Liferay DXP instance. It’s available in all sites and can be enabled for [asset libraries](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/asset-libraries).

To access documents and media in a site, open the _Site Menu_ (![Site Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-product-menu.png)) and go to _Content & Data_ → _Documents and Media_.

![Click on Documents and Media under Content & Data in the Site Menu.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference/images/01.png)

To access documents and media in an asset library, navigate to any library where it’s enabled, and click on _Documents and Media_.

![Click on Documents and Media in the asset library.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference/images/02.png)

The Documents and Media application has three main tabs: [Files](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference#files-tab), [Document Types](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference#document-types-tab), and [Metadata Sets](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference#metadata-sets-tab).

You can access additional settings by clicking on _Actions_ (![Actions button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) in the [Application Bar](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference#application-bar-settings).

NOTE

The documents and media UI is the same for asset libraries and sites.

### [Files Tab](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference#files-tab) <a href="#files-tab" id="files-tab"></a>

![The Files tab provides access to the application's primary features.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference/images/03.png)

The Files tab provides access to the application’s primary features. Here you can view, search, add, and manage all digital assets, folders, and connected repositories.

NOTE

The Home folder serves as the root folder for the documents and media application.

Click _Add_ (![Add button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-add.png)) to access these actions: file upload, multiple files upload, folder, repository, shortcut, external video shortcut. See [Using Folders](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/uploading-and-managing/using-folders) and [Uploading Files](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/uploading-and-managing/uploading-files) for more information.

![Click Add to create a new folder or digital asset.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference/images/04.png)

If you’ve created custom [document types](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference#document-types-tab), they appear here as available options.

Click a file or folder’s _Actions_ (![Actions button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) to download, edit, move, or remove it. You can also check out or check files in to create file versions.

### [Document Types Tab](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference#document-types-tab) <a href="#document-types-tab" id="document-types-tab"></a>

![Create custom templates for file uploads in the Document Types tab.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference/images/05.png)

Here you can create and manage custom templates used for adding new files to Documents and Media. _Document types_ are created using metadata fields and provide additional, searchable information for uploaded files.

To compose a new document type, drag and drop configurable metadata fields into the drop zone. You can also add a description, include custom [metadata sets](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference#metadata-sets-tab), and manage permissions.

![Create and configure custom document types.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference/images/06.png)

Once created, you can use a template to add new digital assets in the Documents and Media tab. See [Defining Document Types](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/uploading-and-managing/managing-metadata/defining-document-types) for more information.

### [Metadata Sets Tab](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference#metadata-sets-tab) <a href="#metadata-sets-tab" id="metadata-sets-tab"></a>

![Create custom groups of data fields in the Metadata Sets tab.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference/images/07.png)

Here you can define reusable groups of metadata fields that can be added to custom document types. _Metadata sets_ are composed in the same way as document types, by dragging and dropping metadata fields into the designated drop zone.

![Use fields to create reusable metadata sets.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference/images/08.png)

Once created, metadata sets can be added to custom document types. See [Defining Metadata Sets](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/uploading-and-managing/managing-metadata/defining-metadata-sets) for more information.

![Select a default workflow.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference/images/11.png)

#### [Home Folder Permissions](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference#home-folder-permissions) <a href="#home-folder-permissions" id="home-folder-permissions"></a>

Manage permissions for the Documents and Media home folder. To learn more about permissions, see [Understanding Roles and Permissions](https://learn.liferay.com/web/guest/w/dxp/users-and-permissions/roles-and-permissions/understanding-roles-and-permissions).

![Manage permissions for the documents and media home folder.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference/images/12.png)

#### [Export/Import](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference#exportimport) <a href="#exportimport" id="exportimport"></a>

Initiate [export or import](https://learn.liferay.com/web/guest/w/dxp/site-building/sites/exporting-importing-site-pages-and-content) operations for documents and media content. Content is exported as an `LAR` (Liferay archive) file. You can also view current and previous exports.

![Initiate export or import operations for documents and media.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference/images/13.png)

#### [Configuration](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference#configuration) <a href="#configuration" id="configuration"></a>

Configure email notifications for documents and media. When configuring email notifications, you can use default placeholders for parsing information (e.g., `[$COMPANY_ID$]`, `[$DOCUMENT_TYPE$]`, `[$TO_NAME$]`). Available placeholders appear in each tab under Definition of Terms.

NOTE

Using email notifications requires a connected mail server. See [Configuring Mail](https://learn.liferay.com/web/guest/w/dxp/installation-and-upgrades/setting-up-liferay/configuring-mail) for more information.

**Email From**: Enter a name and email address to use as the email’s sender.

![Enter the sender's name and email address.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference/images/14.png)

**Document Added Email**: Enable/Disable email notifications for when documents are added, and compose the email’s subject and content body.

![Compose the email sent when a document is added.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference/images/15.png)

**Document Updated Email**: Enable/Disable email notifications for when existing documents are updated, and compose the email’s subject and content body.

![Compose the email sent when existing documents are updated.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference/images/16.png)

**Document Needs Review Email**: Enable/Disable email notifications for when existing documents are submitted for review, and compose the email’s subject and content body.

![Compose the email sent when existing documents are submitted for review.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference/images/17.png)

**Document Expired Email**: Enable/Disable email notifications for when existing documents have reached their expiration date, and compose the email’s subject and content body.

![Compose the email sent when existing documents have expired.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/documents-and-media-ui-reference/images/18.png)
