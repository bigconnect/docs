# Creating and Editing Documents with Microsoft Office 365

You can use Office 365™ to create and edit text documents, spreadsheets, or presentations for storage in the Documents and Media library. When you finish your Office 365™ editing session, you must check in the document to save the changes in the Documents and Media Library.

Before starting, you must first enable your portal installation to connect with Microsoft Office 365™.

### Authentication <a href="#authentication" id="authentication"></a>

The first time you create or edit a Documents and Media file via Office 365™, you must authenticate with your Microsoft account. This links OneDrive™ to your portal account, so you only need to do this once.

Unlinking your account takes only three steps:

1. Click on _your profile_ → _Account Settings_.
2. On the _General_ tab, click _Apps_.
3.  Click _Revoke_ next to OneDrive™.

    ![You can unlink your account from the portal.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/uploading-and-managing/creating-documents/creating-and-editing-documents-with-microsoft-office-365/images/01.png)

OneDrive™ has been unlinked.

### Creating Files <a href="#creating-files" id="creating-files"></a>

1. Open the _Menu_ (![Product Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-menu.png)), click your Site’s name, and navigate to _Content & Data_ → _Documents and Media_.
2.  Click the _Add_ icon (![Add](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-add.png)) and select the type of Office 365™ document to add to the Document Library:

    * Word™
    * Excel™
    * PowerPoint™

    When you select one of these options, a new window opens for you to enter the document’s name.

    ![Select the type of document you want to create.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/uploading-and-managing/creating-documents/creating-and-editing-documents-with-microsoft-office-365/images/02.png)
3.  Enter the document’s name in the _Title_ field, and click _Save_. When you click _Save_, the portal creates a temporary Documents and Media file and links it to the new Office 365™ file. Your browser then opens a new window with that Office 365™ file so you can create its content.

    ![When you create a document, you must give it a name.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/uploading-and-managing/creating-documents/creating-and-editing-documents-with-microsoft-office-365/images/03.png)
4. Use the Office 365™ editor to create your document’s content.
5.  Save or discard your changes to the portal:

    **Check in:** Saves the Office 365™ file to Documents and Media, then deletes the file from Office 365™. The saved file’s format depends on the document type you selected in step two above.

    * Word: Microsoft Word™ (`.docx`)
    * PowerPoint: Microsoft PowerPoint™ (`.pptx`)
    * Excel: Microsoft Excel™ (`.xlsx`)

    **Cancel Checkout:** Deletes the Office 365™ file, discarding any changes.

### Editing Files <a href="#editing-files" id="editing-files"></a>

You can use Office 365™ to edit the following types of Documents and Media files:

* Text files (`.doc`, `.docx`, `.docm`, `.dot`, `.dotx`, `.dotm`, `.html`, `.txt`, `.rtf`, `.odt`)
* Presentation files (`.ppt`, `.pptx`, `.pptm`, `.pps`, `.ppsx`, `.ppsm`, `.pot`, `.potx`, `.potm`)
* Spreadsheet files (`.xls`, `.xlsx`, `.xlsm`, `.xlt`, `.xltx`, `.xltm`, `.ods`, `.csv`, `.tsv`, `.txt`, `.tab`)

Follow these steps to edit a Documents and Media file in Office 365™:

1. Navigate to the file in the Documents and Media Library.
2. Click the file’s Actions icon (![Actions](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) and select _Edit in Office 365_. This automatically [checks out](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/documents-and-media/publishing-and-sharing/managing-document-access/managing-document-changes-with-checkout) the file, transfers its content to a new Office 365™ file, and redirects you to that file Office 365™.
3.  Edit the file in Office 365™. The editing process is exactly the same as described above for creating files.

    ![To modify a document, select Edit in Office 365 from the file's Actions menu.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/uploading-and-managing/creating-documents/creating-and-editing-documents-with-microsoft-office-365/images/04.png)
