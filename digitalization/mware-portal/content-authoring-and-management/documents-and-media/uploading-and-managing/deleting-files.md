# Deleting Files

The _Documents and Media_ application allows for easy deletion of files.

### Deleting a Single File <a href="#deleting-a-single-file" id="deleting-a-single-file"></a>

1. Locate the file you wish to delete.
2. Click the file’s Actions icon (![Actions](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-options.png)) and select _Delete_.

![Deleting files requires a move to the recycle bin first.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/uploading-and-managing/deleting-files/images/01.png)

### Deleting Multiple Files <a href="#deleting-multiple-files" id="deleting-multiple-files"></a>

1. Check the checkbox for every file you wish to delete.
2. Click the Trash icon (![Trash](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-app-trash.png)) at the top menubar to _Delete_ files.

![You can select multiple files and delete them.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/uploading-and-managing/deleting-files/images/02.png)
