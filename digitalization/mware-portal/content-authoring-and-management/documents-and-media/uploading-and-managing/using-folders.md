# Using Folders

By default, uploaded files are stored in the Documents and Media root folder (i.e., _Home_), but you can create additional folders to organize and manage your files. Each folder can have its own workflow configuration, so you can define review and approval processes for its files. You can also configure a folder’s permissions to ensure only authorized users can access its files.

### Adding Folders <a href="#adding-folders" id="adding-folders"></a>

1. Open the _Documents and Media_ application in the desired Site or Asset Library.
2.  Click the _Add_ button (![Add Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-add.png)) and select _Folder_.

    ![Click on the Add button and select Folder.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/uploading-and-managing/using-folders/images/01.png)
3. Enter a name for your new folder.
4. (Optional) Enter a folder description.
5.  (Optional) Configure permissions for the folder.

    ![Enter a folder description and configure folder permissions.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/uploading-and-managing/using-folders/images/02.png)
6. Click _Save_ to create your new folder.

Once created, the folder appears in the Documents and Media application. You can create subfolders by opening the desired folder and repeating the above process.

### Folder Options <a href="#folder-options" id="folder-options"></a>

Once you have created a folder, you can click its _Actions_ button (![Actions Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) to access the following options.

| Action              | Description                                                                    |
| ------------------- | ------------------------------------------------------------------------------ |
| Download            | Download the folder as a zip file.                                             |
| Edit                | Edit the folder’s name, description, document type restrictions, and workflow. |
| Move                | Move the folder with its files to another folder.                              |
| Add Folder          | Add a subfolder to the selected folder.                                        |
| Access from Desktop | View the folder’s WebDAV URL.                                                  |
| Permissions         | Edit permissions for the folder.                                               |
| Delete              | Move the folder and its files to the Recycle Bin.                              |

![Click the folder's actions button to access the following options.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/uploading-and-managing/using-folders/images/03.png)

### Configuring Workflows for Folders <a href="#configuring-workflows-for-folders" id="configuring-workflows-for-folders"></a>

After creating a folder, you can configure its workflow settings to determine the approval process for all additions and edits made to the folder’s content. These options are available when editing the folder. See Using Workflow with Documents and Media for more information.

![Configure workflows for individual folders.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/uploading-and-managing/using-folders/images/04.png)

### Configuring Folder Permissions <a href="#configuring-folder-permissions" id="configuring-folder-permissions"></a>

If desired, you can configure folder permissions to restrict access to its files. See the Documents and Media Permissions Reference and Roles and Permissions for more information.

![Configure folder permissions.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/documents-and-media/uploading-and-managing/using-folders/images/05.png)
