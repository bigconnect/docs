# Enabling Workflows for Translations

You can enable a [custom workflow](https://learn.liferay.com/web/guest/w/dxp/process-automation/workflow/introduction-to-workflow) for translation processes to guide the review and publishing process.

Once you’ve defined your custom workflow, follow these steps:

1. Open the _Site Menu_ (![Site Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-product-menu.png)), expand _Configuration_, and go to _Workflow_.
2. Click the workflow drop down menu for _Translation_ and select the desired workflow.
3. Click _Save_.

![Click on the workflow drop down menu for Translation, and select the desired workflow.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/translating-pages-and-content/enabling-workflows-for-translations/images/01.png)

Once workflow is enabled, each published translation appears as an individual task that must be approved before the Content Page or Web Content is officially updated. Translation reviewers see a read-only, side-by-side preview of the original and translated texts.

If further edits are required, translators can return to the translation interface, edit the text, and resubmit it for further review.

If the translation is approved for a Content Page, the Page is saved as a draft with the language edits. If the translation is approved for Web Content, the changes are applied immediately.
