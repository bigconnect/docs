# Managing Web Content Articles

Once you’ve added articles to your web content library, you can manage them via the web content UI. To access management actions for an article, click its _Actions_ button (![Actions button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)).

![Click the article's actions button to access configuration options.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/web-content/web-content-articles/managing-web-content-articles/images/01.png)

| Option                                                                                                                | Description                                                                                                                                                                                                                                                                                                                |
| --------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Edit (![Edit](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-edit.png))                         | Edit the article’s content. Note that modifying the article increases its version number, but ownership remains with the user who initially created it.                                                                                                                                                                    |
| Preview (![Preview](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-view.png))                   | Show the rendered web content.                                                                                                                                                                                                                                                                                             |
| Translate (![Translate](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-translate.png))          | Translate the web content article to the desired language. See [Translating Web Content](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/translating-pages-and-content/translating-web-content) for more information.                                                                           |
| Expire (![Expire](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-time.png))                     | Deactivate the web content article.                                                                                                                                                                                                                                                                                        |
| Subscribe (![Subscribe](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-subscribe.png))          | Receive notifications on new and modified articles.                                                                                                                                                                                                                                                                        |
| View History (![View History](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-date-time.png))    | View web content version history.                                                                                                                                                                                                                                                                                          |
| View Usages (![View Usages](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-view-type-list.png)) | View the pages, page templates, and display page templates where the web content article is used.                                                                                                                                                                                                                          |
| Make a Copy (![Copy](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-copy.png))                  | Duplicate the web content article. The copy uses the same name with _Copy_ appended to the end.                                                                                                                                                                                                                            |
| Export for Translation (![Export](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-export.png))   | Export web content for translation as `.xliff` or `.xlf` files. See [Exporting Content for Translation](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/translating-pages-and-content/translating-web-content#exporting-content-for-translation) for more information.                          |
| Import Translation (![Import](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-download.png))     | Import the translations together as a `.zip` file or individually as `.xliff` or `.xlf` files. See [Importing Content Translations](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/translating-pages-and-content/translating-web-content#importing-content-translations) for more information. |
| Move (![Move](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-move-folder.png))                  | Relocate the article to a different folder.                                                                                                                                                                                                                                                                                |
| Permissions (![Permissions](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-permissions.png))    | Manage article permissions for user roles.                                                                                                                                                                                                                                                                                 |
| Delete (![Delete](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-app-trash.png))                | Move the file to the [Recycle Bin](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/recycle-bin/recycle-bin-overview).                                                                                                                                                                           |

TIP

Using folders can provide additional organization and article management capabilities, including workflow and permissions.

In the info panel, the article’s information is organized into two tabs: Details and Versions. To access an article’s info panel, select the article and click _Toggle Info Panel_ (![Toggle info panel](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-information.png)) on the Applications Menu.

![Select the article and click on the toggle info panel icon to access the info panel reference.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/web-content/web-content-articles/managing-web-content-articles/images/02.png)

### [Info Panel Details Tab](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/web-content/web-content-articles/managing-web-content-articles#info-panel-details-tab) <a href="#info-panel-details-tab" id="info-panel-details-tab"></a>

The Details tab includes the following information about web content articles.

| Field           | Description                         |
| --------------- | ----------------------------------- |
| ID              | The article’s id.                   |
| Title           | The article’s title.                |
| Template        | The template used in the article.   |
| Original Author | The article’s author.               |
| Priority        | The articles priority.              |
| Display Date    | The article’s display date.         |
| Expiration Date | When the article expires.           |
| Review Date     | When the article is set for review. |

### [Info Panel Versions Tab](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/web-content/web-content-articles/managing-web-content-articles#info-panel-versions-tab) <a href="#info-panel-versions-tab" id="info-panel-versions-tab"></a>

The Versions tab displays the 10 most recent versions of the selected web content article. To view all available versions, click the _View More_ button at the bottom of the versions tab or click the article’s _Actions_ button (![Actions button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) and select _View History_.

![Click the article's Actions button and select View History to access configuration options for the versions.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/web-content/web-content-articles/managing-web-content-articles/images/03.png)

| Option                                                                                                 | Description                                                                                                                                                          |
| ------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Preview (![Preview](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-view.png))    | Show the rendered web content article version.                                                                                                                       |
| Expire (![Expire](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-time.png))      | Deactivate the web content article version.                                                                                                                          |
| Compare to                                                                                             | Show the difference between the selected version and another version. This opens a new page that shows additions, deletions and formatting changes between versions. |
| Make a Copy (![Copy](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-copy.png))   | Creates a new web content article identical to the version selected. The copy uses the same name with _Copy_ appended to the end.                                    |
| Delete (![Delete](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-app-trash.png)) | Deletes the selected version.                                                                                                                                        |
