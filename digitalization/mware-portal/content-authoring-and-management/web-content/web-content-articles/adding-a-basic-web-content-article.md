# Adding a Basic Web Content Article

When you have a lot of content to publish on your site, Liferay’s content management system helps you with practical and essential ways to manage it. Web content articles can be displayed through [widgets](https://learn.liferay.com/web/guest/w/dxp/site-building/displaying-content/additional-content-display-options/using-the-web-content-display-widget), [fragments](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/page-fragments-and-widgets/using-fragments), or [display pages](https://learn.liferay.com/web/guest/w/dxp/site-building/displaying-content/using-display-page-templates/creating-and-managing-display-page-templates).

Each web content article is based on a structure that defines its available fields. Liferay includes the Basic Web Content structure out-of-the-box, but you can create your own. See [Understanding Web Content Structures](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/web-content/web-content-structures/understanding-web-content-structures) for more information.

### [Creating a Basic Web Content Article](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/web-content/web-content-articles/adding-a-basic-web-content-article#creating-a-basic-web-content-article) <a href="#creating-a-basic-web-content-article" id="creating-a-basic-web-content-article"></a>

1. Open the Site Menu (![Site Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-menu.png)) and navigate to _Content & Data_ → _Web Content_.
2.  Under the Web Content tab, click _Add_ (![Add icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-add.png)) and select _Basic Web Content_.

    ![The web content administration page.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/web-content/web-content-articles/adding-a-basic-web-content-article/images/01.png).
3.  Enter a _title_ (required) for the new article and add the desired _content_ to their respective fields.

    ![The edit screen for a new web content article.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/web-content/web-content-articles/adding-a-basic-web-content-article/images/02.png)
4. Click _Publish_.

Now your new article is created! If it’s inside a folder, an interactive path appears for easier navigation.

![An interactive path enables easy file navigation.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/web-content/web-content-articles/adding-a-basic-web-content-article/images/06.png)

You can now display your web content article on a page using the [Web Content Display widget](https://learn.liferay.com/web/guest/w/dxp/site-building/displaying-content/additional-content-display-options/using-the-web-content-display-widget), for example.

NOTE

The user who creates the first version of a web content article becomes its owner. If another user edits the content (which creates a new version), ownership isn’t transferred.

### [Previewing Web Content Articles](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/web-content/web-content-articles/adding-a-basic-web-content-article#previewing-web-content-articles) <a href="#previewing-web-content-articles" id="previewing-web-content-articles"></a>

You can preview your content using the selected default template or display page template before publishing, so you can make adjustments to ensure your content appears as intended to users.

#### [Previewing a Web Content Article Using a Template](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/web-content/web-content-articles/adding-a-basic-web-content-article#previewing-a-web-content-article-using-a-template) <a href="#previewing-a-web-content-article-using-a-template" id="previewing-a-web-content-article-using-a-template"></a>

1. In the properties tab, select a template to preview the web content article.
2.  Click _Preview_ ( ![Preview](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-preview.png) ).

    ![The default template has a preview button that looks like an eye.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/web-content/web-content-articles/adding-a-basic-web-content-article/images/04.png)

NOTE

Only web content articles that have been published or saved as a draft can be previewed.

#### [Previewing a Web Content Articles Using a Display Page](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/web-content/web-content-articles/adding-a-basic-web-content-article#previewing-a-web-content-articles-using-a-display-page) <a href="#previewing-a-web-content-articles-using-a-display-page" id="previewing-a-web-content-articles-using-a-display-page"></a>

You can preview web content using a display page template from any site or asset library.

1. In the properties tab, select a site and display page to preview the web content article.
2.  Click_Preview_ ( ![Preview](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-preview.png) ).

    ![When you've selected a display page template, use the preview button in the properties tab.](https://resources.learn.liferay.com/images/dxp/latest/en/content-authoring-and-management/web-content/web-content-articles/adding-a-basic-web-content-article/images/05.png)

NOTE

Selecting the Preview button saves a draft of the web content article before displaying the preview.

### [Properties Tab](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/web-content/web-content-articles/adding-a-basic-web-content-article#properties-tab) <a href="#properties-tab" id="properties-tab"></a>

When creating or editing a Basic Web Content article, the following options appear in the sidebar menu’s Properties tab:

| **Property**              | **Purpose**                                                                                                                                           | **Additional Notes**                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Basic Information**     | See basic information about the article including the web content structure it is based on, version and status, ID, and a short editable description. | The structure cannot be edited once the article is created. See [Web Content Structures](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/web-content/web-content-structures/understanding-web-content-structures) for more information.                                                                                                          |
| **Default Template**      | Select a default template to display this web content.                                                                                                | See [Creating Web Content Templates](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/web-content/web-content-templates/creating-web-content-templates) for more information.                                                                                                                                                                     |
| **Display Page Template** | Select a Display Page Template for this article, if one is desired.                                                                                   | See [Creating and Managing Display Page Templates](https://learn.liferay.com/web/guest/w/dxp/site-building/displaying-content/using-display-page-templates/creating-and-managing-display-page-templates) for more information.                                                                                                                                              |
| **Featured Image**        | Select a small image to use as the article’s thumbnail.                                                                                               | The image can come from a URL, uploaded from your system, or from files located in Documents and Media.                                                                                                                                                                                                                                                                     |
| **Categorization**        | Set any public or private categories, tags, or priority for the article.                                                                              | See [Tagging Content](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/tags-and-categories/tagging-content-and-managing-tags) and [Organizing Content with Categories and Tags](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/tags-and-categories/organizing-content-with-categories-and-tags) for more information. |
| **Friendly URL**          | Set a custom friendly URL for this article.                                                                                                           |                                                                                                                                                                                                                                                                                                                                                                             |
| **Schedule**              | Schedule a date to display or expire the article, if desired.                                                                                         | See [Scheduling Web Content](https://learn.liferay.com/web/guest/w/dxp/content-authoring-and-management/web-content/web-content-articles/using-expiration-and-review-dates-in-web-content) for more information.                                                                                                                                                            |
| **Search**                | Set whether this article will be indexed for search.                                                                                                  |                                                                                                                                                                                                                                                                                                                                                                             |
| **Related Assets**        | Select any related assets, if desired.                                                                                                                |                                                                                                                                                                                                                                                                                                                                                                             |
