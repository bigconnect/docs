# Adding Custom Fields to Users

Many of the portal’s assets and resources can be extended with new fields. This includes adding custom fields for Users:

1.  Navigate to _Control Panel_ → _Configuration_ → _Custom Fields_.

    ![Navigate to Custom Fields in the Control Panel](https://resources.learn.liferay.com/images/dxp/latest/en/users-and-permissions/users/adding-custom-fields-to-users/images/01.png)
2. Scroll down and click the link for _User_.
3. Click _Add_ (![Add icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-add.png)) to add a new custom field.
4. Choose a field type and click _Save_.

![There are different field types to choose.](https://resources.learn.liferay.com/images/dxp/latest/en/users-and-permissions/users/adding-custom-fields-to-users/images/02.png)

### Field Types <a href="#field-types" id="field-types"></a>

#### Text and Numbers <a href="#text-and-numbers" id="text-and-numbers"></a>

**Text Area:** Collect longer lines of text.

**Input Field:** Collect a string of text, a decimal number, or an integer.

#### Selection <a href="#selection" id="selection"></a>

**Dropdown:** Provide a dropdown list to select a single option. The list can be text, decimal numbers, or integers.

**Checkbox:** Provide a list of checkboxes to select one or more options.

**Radio:** Provide a list of radio buttons to toggle a single option.

#### Other Field Types <a href="#other-field-types" id="other-field-types"></a>

**Geolocation:** Collect the User’s geolocation information.

**Date:** Collect date and time information.

**True/False:** Provide a choice of True or False.

For example, you can select the _Dropdown_ field type to add a custom category for your users to select.

![For example, you can select the Dropdown field type for your users to select.](https://resources.learn.liferay.com/images/dxp/latest/en/users-and-permissions/users/adding-custom-fields-to-users/images/03.png)

### Using Your New Field <a href="#using-your-new-field" id="using-your-new-field"></a>

1. Navigate to _Control Panel_ → _Users_ → _Users and Organizations_.
2.  Click the _Add_ icon (![Add icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-add.png)) to add a new User. You should now see the newly added custom field at the bottom of the form.

    ![New custom field is now visible when adding a new user](https://resources.learn.liferay.com/images/dxp/latest/en/users-and-permissions/users/adding-custom-fields-to-users/images/04.png)
