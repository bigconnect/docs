# Translating Forms

Forms can be translated to any locale that the portal supports. The form builder specifies a translation of the form’s default language.

The form’s default language and the available translations are set in the site’s language configuration.

Follow these steps to create a form translation:

1. Go to _Site Administration_ (your site’s menu) → _Content & Data_ → _Forms_ and open the form to translate.
2.  Click the + icon next to the current translation language and choose from the available languages.

    <img src="https://liferay-support.zendesk.com/hc/article_attachments/360030194252/forms-add-translation.png" alt="Figure 1: Add a translation for the form." data-size="original">

    Figure 1: Add a translation for the form.
3. Translate the form’s title, field labels, field options, field placeholder text, and any other text visible to the user.
4. Save and publish the form.

![Figure 2: Translate as much of the form as possible into each language you expect users to need.](https://liferay-support.zendesk.com/hc/article\_attachments/360030162911/forms-translate2.png)

To fill out a translated form in a translated language,

1. Access the form. If a signed-in user accesses the form and a translation is available in the user’s language, the user sees the translated form by default.
2. To see the form in a different language, click the language icon and select a language.
3. Fill out the form as usual and click _Submit_.

**Note:** Translations work differently depending on how a User accesses a Form:

If accessed in the Form widget on a portal page, the Form is displayed in the User’s language automatically. If there’s no translation available for the User’s language, the default language of the Form is displayed.

If accessed via direct URL, the Form translation must be selected manually.
