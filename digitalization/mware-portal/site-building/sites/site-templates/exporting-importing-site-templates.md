# Exporting/Importing Site Templates

You can export and import site templates to share them between portal installations.

### Exporting Individual Site Templates <a href="#exporting-individual-site-templates" id="exporting-individual-site-templates"></a>

Follow these steps to export a site template:

1. Open the _Global Menu_ (![Global Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-applications-menu.png)), go to the _Control Panel_, and click _Site Templates_.
2. Click the site template you want to export.
3. Open the _Product Menu_ (![Product Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-product-menu.png)), expand _Publishing_, and click _Export_.
4.  Click _Add_ (![Add Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-add.png)) to create a new export process.

    This opens an export template.

    ![Name and configure the template export process.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/sites/site-templates/exporting-importing-site-templates/images/01.png)
5. Enter a title for the export process.
6. Configure the export process by selecting the template pages and content you want to export.
7. Click _Export_ to begin the export process.

Once finished, click the _Download_ button (![Download Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-download.png)) to download the generated LAR file.

![Download the generated LAR file.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/sites/site-templates/exporting-importing-site-templates/images/02.png)

### Importing Individual Site Templates <a href="#importing-individual-site-templates" id="importing-individual-site-templates"></a>

Follow these steps to import a site template:

1. Open the _Global Menu_ (![Global Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-applications-menu.png)), go to the _Control Panel_, and click _Site Templates_.
2. [Create](https://learn.liferay.com/web/guest/w/dxp/site-building/sites/site-templates/creating-site-templates) a site template.
3. Click the new site template.
4. Open the _Product Menu_ (![Product Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-product-menu.png)), expand _Publishing_, and click _Import_.
5. Click _Add_ (![Add Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-add.png)) to create a new import process.
6.  Add the desired LAR file and click _Continue_.

    ![Add the LAR file and click Continue.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/sites/site-templates/exporting-importing-site-templates/images/03.png)
7. Review and configure the import process.
8.  Click _Import_ to begin importing.

    ![Configure and begin the import process.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/sites/site-templates/exporting-importing-site-templates/images/04.png)

Once complete, you can use the imported site template to [create sites](https://learn.liferay.com/web/guest/w/dxp/site-building/sites/adding-a-site).

### Bulk Export/Import <a href="#bulk-exportimport" id="bulk-exportimport"></a>

If needed, follow these steps to perform bulk export/import operations for site templates:

1. Open the _Global Menu_ (![Global Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-applications-menu.png)), go to the _Control Panel_, and click _Site Templates_.
2.  Click _Options_ (![Options Icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-options.png)) in the Application Bar and select _Export/Import_.

    ![Click the Options icon in the Application Bar and select Export/Import.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/sites/site-templates/exporting-importing-site-templates/images/05.png)
3.  Go to the _Export_ or _Import_ tab to start the desired process.

    Configuration options for bulk export are mostly the same as when exporting individual site templates. However, you cannot configure the pages and content included for each template. Also unlike individual exports, you can determine whether page templates are included in your export.

    ![Go to the Export tab to export all site templates in your instance.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/sites/site-templates/exporting-importing-site-templates/images/06.png)

    Configuration options for bulk import are mostly the same as when importing individual site templates. However, you can determine whether page templates included in the LAR file are imported with the site templates.

    ![Go to the Import tab to import a LAR file with multiple site templates.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/sites/site-templates/exporting-importing-site-templates/images/07.png)
