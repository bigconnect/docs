# Creating and Managing Experiences

You can customize your content page for different groups of users using _Experiences_. See [Content Page Personalization](https://learn.liferay.com/web/guest/w/dxp/site-building/personalizing-site-experience/experience-personalization/content-page-personalization) to learn how experiences can contribute to site personalization.

### [Creating Experiences](https://learn.liferay.com/web/guest/w/dxp/site-building/personalizing-site-experience/experience-personalization/creating-and-managing-experiences#creating-experiences) <a href="#creating-experiences" id="creating-experiences"></a>

1. Open the _Site Menu_ (![Site Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-product-menu.png)) and go to _Site Builder_ → _Pages_.
2. Click _Actions_ (![Actions Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) for an content page and select _Edit_. Alternatively, [create a content page](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages).
3.  Open the _Experience_ drop-down menu and click _New Experience_.

    ![Open the Experience drop-down menu and click New Experience.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/personalizing-site-experience/experience-personalization/creating-and-managing-experiences/images/01.png)
4.  Enter a name for the experience and select the audience segment you want to target. Alternatively, [create a segment](https://learn.liferay.com/web/guest/w/dxp/site-building/personalizing-site-experience/segmentation/creating-and-managing-user-segments).

    By default, new experiences target the _Anyone_ segment (i.e., all site visitors).
5. Design the content page to determine the information and layout that appears for the targeted segment.
6.  Open the _Experience_ drop-down menu and click the _Up_ (![Up](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-angle-up.png)) or _Down_ (![Down](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-angle-down.png)) buttons to set the experience’s priority.

    Site visitors see the highest ranking experience for their segment. See [Understanding How Experiences Work](https://learn.liferay.com/web/guest/w/dxp/site-building/personalizing-site-experience/experience-personalization/content-page-personalization#understanding-how-experiences-work) for more information.
7. Click _Publish_.

TIP

If users are logged in and have permission to edit the page, and there are multiple experiences in place, they can [view/preview the page](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/adding-pages/adding-a-page-to-a-site#previewing-pages) based on the experience they select.

### [Managing Experiences](https://learn.liferay.com/web/guest/w/dxp/site-building/personalizing-site-experience/experience-personalization/creating-and-managing-experiences#managing-experiences) <a href="#managing-experiences" id="managing-experiences"></a>

When you edit a content page, you can click the experience to manage the options for that page.

![You can add, edit, delete, or change priority for Experiences.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/personalizing-site-experience/experience-personalization/creating-and-managing-experiences/images/03.png)

1. Open the _Site Menu_ (![Site Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-product-menu.png)) and go to _Site Builder_ → _Pages_.
2. Click _Actions_ (![Actions Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) for a content page and select _Edit_.
3.  Open the _Experience_ drop-down menu. From here,

    * Set the experience priority, using the Up (![Up](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-angle-up.png)) and Down (![Down](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-angle-down.png)) controls.
    * Edit (![Edit](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-edit.png)) the experience’s name or the selected segment.
    * Duplicate (![Duplicate](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-copy.png)) the experience.
    * Delete (![Delete](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-delete.png)) the Experience.

    IMPORTANT

    The order of experiences in the drop-down menu determines their priority. See [Understanding How Experiences Work](https://learn.liferay.com/web/guest/w/dxp/site-building/personalizing-site-experience/experience-personalization/content-page-personalization#understanding-how-experiences-work) for more information.
