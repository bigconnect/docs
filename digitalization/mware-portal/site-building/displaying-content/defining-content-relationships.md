# Defining Content Relationships

When creating new content, you can define relationships between assets even if they don’t share any tags and aren’t in the same category. Related Assets puts related content at your users’ fingertips.

Before creating a relationship, you must create web content first:

1. Go to _Product Menu_(![Product Menu icon.](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-product-menu.png)) → _Web Content_.
2. Click _New_ (![Add icon.](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-add.png)), then _Basic Web Content_.
3. Give your new web content a name and a short description.

Now you can create relationships to this content.

1. Go to _Product Menu_ (![Product Menu icon.](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-product-menu.png)) and navigate to _Blogs_.
2. Click _Add Blog Entry_ (![Add icon.](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-add.png)).
3. Give your new blog entry a title and fill in the _Content_ field.
4. Now define the relationship with the web content you just created. Click _Related Assets_.
5. Click _Select_. From here you can choose from any asset category that Liferay provides.

![Click Related Assets and the drop-down menu appears.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/displaying-content/defining-content-relationships/images/01.png)

1. Click _Basic Web Content_. The content you created previously appears.
2. Check the box next the web content, then click _Done_.
3. The relationship is now established! Click _Publish_.

### [Using the Related Assets Widget](https://learn.liferay.com/web/guest/w/dxp/site-building/displaying-content/defining-content-relationships#using-the-related-assets-widget) <a href="#using-the-related-assets-widget" id="using-the-related-assets-widget"></a>

Once relationships are created, you can display them with the Related Assets Widget. By default, the Related Assets widget shows assets related to the asset displayed in the Asset Publisher. If you don’t want to show every related asset, you can configure what content relationships to display. To do this, follow these steps:

1. Go to the page editor, then click _Widgets_ and search for the Asset Publisher widget on _Fragments and Widgets_. After adding it to the page, configure it to display the blog entry created previously. If you need more information, see [Using the Asset Publisher Widget](https://learn.liferay.com/web/dxp/latest/en/site-building/displaying-content/using-the-asset-publisher-widget)
2. Add the Related Assets widget to the page, next to the Asset Publisher widget.
3. Select _Options_ (![Options icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) in the upper right corner of the Related Assets widget and click _Configuration_.
4. Under the Asset Selection tab, set the type of asset(s) to display using the Asset Type menu. The default value is set to Any.
5. You can narrow the scope of the app to display any single category of asset type or select multiple assets from the menu.

Filter options set minimum requirements for displaying assets by their categories, tags, and custom fields. Ordering and Grouping organizes assets using the same criteria. Display settings customize how the widget shows assets: by title, in a table, by abstract, or full content. You can convert assets to different document types like ODT, PDF, and RTF. You can choose to show metadata fields such as author, modification date, tags, and view count. You can even enable RSS subscriptions and customize their display settings.

1. When you’re finished setting the Source and Filter options, click _Save_.
2. Click _Publish_. The Related assets to the entry appear when you click it.

![Click on the entry and the related assets appear.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/displaying-content/defining-content-relationships/images/02.png)
