# Getting Started with Site Building

Sites are a fundamental component of Liferay DXP. Essentially, a site is a collection of pages that contains content applications that provide additional functionality.

When you first start and configure your Liferay DXP instance, a default site is included. By default the instance name is _Liferay_, but this value can be changed through the configuration of the Setup Wizard or the [Instance Settings](https://learn.liferay.com/web/guest/w/dxp/system-administration/configuring-liferay/virtual-instances/instance-configuration) in the Control Panel.

![You can build powerful sites with Liferay DXP.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/getting-started-with-site-building/images/01.png)

### [Creating Sites](https://learn.liferay.com/web/guest/w/dxp/site-building/getting-started-with-site-building#creating-sites) <a href="#creating-sites" id="creating-sites"></a>

Liferay DXP includes all the tools you need to [build your site](https://learn.liferay.com/web/guest/w/dxp/site-building/sites/adding-a-site) and [create pages](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/adding-pages/adding-a-page-to-a-site). You can create a site from an existing [site template](https://learn.liferay.com/web/guest/w/dxp/site-building/sites/site-templates), which includes a predefined set of pages with applications, or you can create a blank site and build it from the ground up.

Pages are just as flexible. There are multiple page types. Create a page from an existing [page type](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/understanding-pages/understanding-pages) or create one from one of the default [page templates](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/adding-pages/creating-a-page-template), or a page template you’ve created yourself.

Sites and pages can be organized hierarchically. You can add as many nested pages (child pages) and [nested sites](https://learn.liferay.com/web/guest/w/dxp/site-building/sites/site-hierarchies) (child sites) as you like for the parent site or page. It is possible to have multiple sites across your Liferay DXP instance for various organizations, employees, etc. You can also share content and pages between sites with the [import and export options](https://learn.liferay.com/web/guest/w/dxp/site-building/sites/exporting-importing-site-pages-and-content).

Configuring pages and site [navigation](https://learn.liferay.com/web/guest/w/dxp/site-building/site-navigation/using-the-navigation-menus-application) behavior is intuitive and flexible. Pages can be automatically added to a navigation menu when they’re created. You can hide pages if you prefer, or configure page permissions to enable/restrict user access to pages.

Liferay DXP also provides tools to enable you to make changes to your site without disrupting the user experience. Liferay sites can be staged, allowing changes to be made and tested on a site before being published to users. Liferay DXP’s [publications](https://learn.liferay.com/web/guest/w/dxp/site-building/publishing-tools/publications) feature handles this for you. You can use Publications to develop, track, and update your site in a safe environment, without affecting the live site that your users see.

### [Displaying Content](https://learn.liferay.com/web/guest/w/dxp/site-building/getting-started-with-site-building#displaying-content) <a href="#displaying-content" id="displaying-content"></a>

Liferay DXP’s Content Management System (CMS) offers a variety of tools to create, manage and display content of many types (e.g. blogs, images, web content articles). You can use the [Web Content Display widget](https://learn.liferay.com/web/guest/w/dxp/site-building/displaying-content/additional-content-display-options/using-the-web-content-display-widget) to display web content articles of your choosing.

If you want to publish a mix of content types you can use the [Asset Publisher](https://learn.liferay.com/web/guest/w/dxp/site-building/displaying-content/using-the-asset-publisher-widget/displaying-assets-using-the-asset-publisher-widget) or [Collections](https://learn.liferay.com/web/guest/w/dxp/site-building/displaying-content/collections-and-collection-pages/displaying-collections). You can manually select the content the Asset Publisher displays, or you can have it display assets dynamically based on specific criteria, giving you a great deal of control over the experience your users have. You can also embed content from other websites with the [Iframe widget](https://learn.liferay.com/web/guest/w/dxp/site-building/displaying-content/additional-content-display-options/using-the-iframe-widget) or by creating an [embedded page](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/understanding-pages/other-page-types#embedded).

You can create and edit content in line with [Fragments](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/page-fragments-and-widgets/using-fragments). Fragments are individual pieces of code (CSS, HTML, and JavaScript) that you can arrange and combine to build a page. Liferay provides many out-of-the-box fragments. If you need a customized solution, you can modify or [create your own fragments](https://learn.liferay.com/web/guest/w/dxp/site-building/developer-guide/developing-page-fragments/developing-fragments-intro).

Each piece of content has a default landing page, but you can create a [Display Page Template](https://learn.liferay.com/web/guest/w/dxp/site-building/displaying-content/using-display-page-templates) to customize it. A Display Page Template maps portions of the web content (title, main body, image, etc.) to fragments, so you can create the look you want.

![Display Page Templates let you map web content to page fragments to display your content with the design and layout you want.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/getting-started-with-site-building/images/02.png)

### [Personalizing User Experiences](https://learn.liferay.com/web/guest/w/dxp/site-building/getting-started-with-site-building#personalizing-user-experiences) <a href="#personalizing-user-experiences" id="personalizing-user-experiences"></a>

Liferay DXP’s [personalization and segmentation](https://learn.liferay.com/web/guest/w/dxp/site-building/personalizing-site-experience) framework lets you build site experiences that respond to and meet your user’s interests and needs. You can [create user segments](https://learn.liferay.com/web/guest/w/dxp/site-building/personalizing-site-experience/segmentation/creating-and-managing-user-segments) based on specific criteria, such as the organizations they belong to or their role in the site, and then use it to display [personalized page layouts and content](https://learn.liferay.com/web/guest/w/dxp/site-building/personalizing-site-experience/experience-personalization/content-page-personalization) for the user demographic, or you can [integrate with Analytics Cloud](https://learn.liferay.com/analytics-cloud/latest/en/connecting-data-sources/connecting-liferay-dxp-to-analytics-cloud.html) to analyze the behavior of the users within the segment to see how they interact with your site. You can even [recommend content based on a user’s behavior](https://learn.liferay.com/web/guest/w/dxp/site-building/personalizing-site-experience/experience-personalization/understanding-content-recommendations).

### [Customizing and Configuring Sites](https://learn.liferay.com/web/guest/w/dxp/site-building/getting-started-with-site-building#customizing-and-configuring-sites) <a href="#customizing-and-configuring-sites" id="customizing-and-configuring-sites"></a>

There are many [settings](https://learn.liferay.com/web/guest/w/dxp/site-building/site-settings/site-settings-ui-reference) available to modify the look, behavior, and functionality of your site. [Sites and their content can be easily localized](https://learn.liferay.com/web/guest/w/dxp/site-building/site-settings/site-localization) to multiple languages as needed.

The look and feel of your site can be [changed by using different themes](https://learn.liferay.com/web/guest/w/dxp/getting-started/changing-your-sites-appearance). Themes can be downloaded and deployed from [Liferay Marketplace](https://learn.liferay.com/web/guest/w/dxp/system-administration/installing-and-managing-apps/using-marketplace), or you can [create a theme yourself](https://learn.liferay.com/web/guest/w/dxp/site-building/site-appearance/themes/theme-development/getting-started/setting-up-an-environment-and-creating-a-theme). Themes determine the overall look and feel of a site and define the CSS, JavaScript, and HTML for the page (via FreeMarker templates). FreeMarker combines standard HTML elements and provides the added benefit of variables, conditional statements, looping, and more. See [Developing Themes](https://learn.liferay.com/web/guest/w/dxp/site-building/developer-guide) for more information.

### [Optimizing Sites](https://learn.liferay.com/web/guest/w/dxp/site-building/getting-started-with-site-building#optimizing-sites) <a href="#optimizing-sites" id="optimizing-sites"></a>

Liferay DXP provides multiple tools and features for optimizing your site, from increasing your site’s [search engine optimization (SEO) ranking](https://learn.liferay.com/web/guest/w/dxp/site-building/displaying-content/using-display-page-templates/configuring-seo-and-open-graph), to [building a responsive site](https://learn.liferay.com/web/guest/w/dxp/site-building/optimizing-sites/building-a-responsive-site) optimized for each device, to honing your messaging campaigns with [A/B testing](https://learn.liferay.com/web/guest/w/dxp/site-building/optimizing-sites/ab-testing/ab-testing). A/B testing compares the current default variation of a page with the page variant(s) to see which pages perform better for a given goal (bounce rate, clicks, etc.). This enables you to make better, data-driven decisions about your site, so you can serve users and customers faster than ever before.
