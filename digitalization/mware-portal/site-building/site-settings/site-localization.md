# Site Localization

### Configuring Site Languages <a href="#configuring-site-languages" id="configuring-site-languages"></a>

You can set your Site’s default language. You can also define a Site’s enabled languages:

1.  In the Site Settings UI, click on the Languages tab.

    ![In the Site settings, click on the Languages tab.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/site-settings/site-localization/images/01.png)
2.  Click _Define a custom default language and additional available languages for this site_.

    ![Click on Define a custom default language and additional available languages for this site.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/site-settings/site-localization/images/02.png)
3. You can change the default language to any language in the list.
4.  You can also choose which additional languages are enabled or disabled.

    ![Choose which additional languages are enabled](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/site-settings/site-localization/images/03.png)
5. Use the left and right arrow buttons to enable or disable additional languages.
6. Click the _Save_ button to save any changes.

### Modifying Localizable Site Fields <a href="#modifying-localizable-site-fields" id="modifying-localizable-site-fields"></a>

Some fields have an appended language flag button. These fields can be translated into other languages.

![Localizable fields are marked with a language flag.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/site-settings/site-localization/images/04.png)

1.  Click the language flag beside the field.

    ![Click the language flag next to the localizable field to enter a new value.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/site-settings/site-localization/images/05.png)
2.  Enter the new value in the selected language. The default value is displayed beneath the field for reference.

    ![Enter the new value for the selected language.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/site-settings/site-localization/images/06.png)

The portal automatically saves the translation for each language and displays the translated value when that language is selected for the instance. If a translation for the field is not provided, the default instance language’s value for that field is displayed.
