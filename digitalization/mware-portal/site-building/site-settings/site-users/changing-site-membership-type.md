# Changing Site Membership Type

A Site’s membership type determines how freely users may join your Site. There are three types of site membership:

* **Open:** Users can join and leave whenever they want. The Site is visible to all users in the My Sites app.
* **Restricted:** Site is visible in the My Sites application, and users must request membership to join.
* **Private:** A Site Administrator must explicitly invite Users to join and then add them to the Site. Private membership Sites don’t appear in the My Sites app.

### Setting Site Membership Type <a href="#setting-site-membership-type" id="setting-site-membership-type"></a>

To change your Site’s membership type, follow these steps:

1. Access the Membership Type option:
   *   In version 7.4+

       1. From the Site Menu, go to _Configuration_ → _Site Settings_.
       2. In the Platform section, click _Site Configuration_ and then click _Details_.

       ![In version 7.4+, change the Site membership type from the Site Settings section.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/site-settings/site-users/changing-site-membership-type/images/02.png)
   *   In previous versions

       1. From the Site Menu, go to _Configuration_ and click the _General_ section.
       2. Find the Membership Type option under the Details area.

       ![In previous versions, change the Site membership type from the Settings section.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/site-settings/site-users/changing-site-membership-type/images/01.png)
2. Open the _Membership Type_ selector and choose an option.
3. Click _Save_.
