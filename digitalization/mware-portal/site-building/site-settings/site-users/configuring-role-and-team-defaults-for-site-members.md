# Configuring Role and Team Defaults for Site Members

You can configure the default Roles and Teams you assign to new Site members.

1. Access the Default User Associations option:
   *   In version 7.4+

       1. From the Site Menu, go to _Configuration_ → _Site Settings_.
       2. In the Platform section, click _Users_ and then click _Default User Associations_.

       ![In version 7.4+, change the Default User Association from the Site Settings section.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/site-settings/site-users/configuring-role-and-team-defaults-for-site-members/images/03.png)
   *   In previous versions

       1. From the Site Menu, go to _Configuration_ → _Settings_.
       2. Under the Advanced area, find the Default User Associations option.

       ![In previous versions, change the Default User Associations from the Settings section.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/site-settings/site-users/configuring-role-and-team-defaults-for-site-members/images/01.png)
2. In the Default User Associations area, click _Select_ under either the _Site Roles_ label to define default Roles or the _Teams_ label to define default Teams (if any exist) for your Site members.
3. Choose the default Site Roles and Teams for new Site members.
4. Click _Save_.

NOTE

The default Site Roles and Teams you configure do not affect existing Site members.
