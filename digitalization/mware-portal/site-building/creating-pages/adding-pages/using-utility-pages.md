# Using Utility Pages

Utility pages serve specific operational tasks and actions and are usually essential for users to interact with a website or application effectively. Utility pages can be configured for a site’s 500 and 404 error pages. In the future, this capability will expand to include other common pages (e.g. sign-in and terms of use pages).

Liferay provides [out-of-the-box utility pages](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/adding-pages/using-utility-pages#viewing-utility-pages) that are easily customizable. You can also [create utility pages](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/adding-pages/using-utility-pages#creating-a-new-utility-page) from scratch.

![Liferay provides out-of-the-box solutions that you can use or customize to fit your needs.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/adding-pages/using-utility-pages/images/01.png)

### [Viewing Utility Pages](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/adding-pages/using-utility-pages#viewing-utility-pages) <a href="#viewing-utility-pages" id="viewing-utility-pages"></a>

You can edit, preview, or copy utility pages.

1.  Open the _Site Menu_ (![Site Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-product-menu.png)) and navigate to _Site Builder_ → _Pages_ → _Utility Pages_ tab.

    The out-of-the-box pages are marked with a `PROVIDED BY LIFERAY` tag.
2. Choose a page and click _Actions_ (![Actions Icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) to view and select one of the [available actions](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/adding-pages/using-utility-pages#utility-pages-actions-menu-reference).

TIP

Edit the utility page the same way you would edit a [content page](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/adding-elements-to-content-pages).

### [Creating a New Utility Page](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/adding-pages/using-utility-pages#creating-a-new-utility-page) <a href="#creating-a-new-utility-page" id="creating-a-new-utility-page"></a>

1. Open the _Site Menu_ (![Site Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-product-menu.png)) and navigate to _Site Builder_ → _Pages_ → _Utility Pages_ tab.
2. Select _Add_ (![Actions Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-add.png)).
3. Choose the type of utility page you want to create.
4. Select _Blank_ for an empty content page or choose an available master page template.
5. Name the utility page and click _Save_.

You can edit the newly created utility page the same way you would edit a [content page](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/adding-elements-to-content-pages).

### [Utility Page Permissions](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/adding-pages/using-utility-pages#utility-page-permissions) <a href="#utility-page-permissions" id="utility-page-permissions"></a>

Utility pages have permissions that govern their use.

1. Open the _Global Menu_ (![Global Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-applications-menu.png)), go to the _Control Panel_ tab, and click _Roles_ under Users.
2.  Click _Actions_ (![Actions Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) for the desired role and select _Edit_.

    Alternatively, you can click the name of the role you want to manage.
3. Click the _Define Permissions_ tab and go to _Site and Asset Library Administration_ → _Site Builder_ → _Pages_ in the permissions sidebar menu.
4. You can find the utility pages permissions under Resource Permissions → Site.
5.  Use the checkboxes to assign the desired language permissions to the selected role.

    | Permission Name             | Description                                       |
    | --------------------------- | ------------------------------------------------- |
    | Add Utility Page            | Required to add a utility page.                   |
    | Assign Default Utility Page | Required to assign a utility page a default page. |
6.  Click _Change_ (![Edit icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-edit.png)) under the Scope column to adjust the permission’s scope. By default, the change applies to all sites and asset libraries, but you can customize the list.

    Browse recently used sites in the Recent tab, all sites in My Sites, and asset libraries in Asset Libraries to select the scope.

    You can repeat this process to select additional sites or asset libraries, expanding the scope of permissions.
7. Click _Save_ at the bottom of the page.
