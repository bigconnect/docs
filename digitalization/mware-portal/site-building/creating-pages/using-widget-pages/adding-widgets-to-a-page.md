# Adding Widgets to a Page

Widgets are applications. They can be simple and only used to display content, or they can be full-featured collaboration applications, like the Message Boards widget.

NOTE

Widgets are rendered according to render-weight on widget pages.

Follow these steps to add a widget to a widget page:

1.  Navigate to the widget page and click _Add_ (![Add](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-add-app.png)) in the application bar.

    ![Click the add button in the application bar.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/using-widget-pages/adding-widgets-to-a-page/images/01.png)
2.  Open the _Widgets_ panel and search or browse through the categories of available widgets to find the one you want.

    ![The widgets panel contains several default widgets that you can use to add functionality to the page.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/using-widget-pages/adding-widgets-to-a-page/images/02.png)
3. Drag the widget to the column and row of the page layout where you want to place it.

TIP

You can click the eye icon at the top of any widget page to toggle the widget controls for all widgets. When disabled, the widget controls do not pop up when you hover your cursor over them.
