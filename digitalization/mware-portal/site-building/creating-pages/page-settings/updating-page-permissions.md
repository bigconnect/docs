# Updating Page Permissions

By default, when users join a site, they can see all of its pages. However, you can configure permissions for individual pages to restrict access based on user [roles](https://learn.liferay.com/web/guest/w/dxp/users-and-permissions/roles-and-permissions/understanding-roles-and-permissions).

NOTE

Individual page permissions take priority over site level configurations.

Follow these steps to update page permissions:

1. Open the _Site Menu_ (![Site Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-product-menu.png)), expand _Site Builder_, and click _Pages_.
2.  Click _Actions_ ( ![Actions Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-options.png) ) for the desired page and select _Permissions_.

    ![The page permissions are found in the Control Panel's Site Builder menu.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/page-settings/updating-page-permissions/images/01.png)
3.  Update the permissions for each role.

    ![The permissions offer many options for each role.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/page-settings/updating-page-permissions/images/02.png)
4. Click _Save_ to apply the changes.

### [Copying a Page with Permissions](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/page-settings/updating-page-permissions#copying-a-page-with-permissions) <a href="#copying-a-page-with-permissions" id="copying-a-page-with-permissions"></a>

To copy a page with its permissions,

1. Open the _Site Menu_ ( ![Product Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-product-menu.png) ) and select _Site Builder_ → _Pages_.
2. Click _Actions_ ( ![Actions Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png) ) for the desired page and select _Copy_ → _Page With Permissions_.
3. Enter a page name and click _Add_.
