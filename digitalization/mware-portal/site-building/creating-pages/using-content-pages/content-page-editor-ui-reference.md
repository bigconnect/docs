# Content Page Editor UI Reference

Using the content page editor, you can [add](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/adding-elements-to-content-pages) and configure elements in a content page. To open the content page editor, go to a content page and click _Edit_ (![Edit icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-edit.png)). This reveals the editing toolbar and sidebar, which contain tools and components for building content pages.

* [Editing Toolbar](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#editing-toolbar)
* [Editing Sidebar](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#editing-sidebar)

![Click the Edit button to access the editing toolbar and sidebar.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference/images/01.png)

### [Editing Toolbar](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#editing-toolbar) <a href="#editing-toolbar" id="editing-toolbar"></a>

The content page toolbar contains tools for creating unique user experiences, setting localized translations, switching between edit modes, and more.

![Click the Edit button to access the editing toolbar.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference/images/02.png)

#### [Experiences](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#experiences) <a href="#experiences" id="experiences"></a>

Using the Experience drop-down menu, you can create copies of the current page to customize for a specific audience. See [Content Page Personalization](https://learn.liferay.com/web/guest/w/dxp/site-building/personalizing-site-experience/experience-personalization/content-page-personalization) for more information.

#### [Translations](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#translations) <a href="#translations" id="translations"></a>

Click the language flag to access the translation drop-down menu. Here, you can view the status of active languages for a page, as well as switch between languages to view and edit translations directly. See [Configuring Site Languages](https://learn.liferay.com/web/guest/w/dxp/site-building/site-settings/site-localization) for more information.

If you use [experiences](https://learn.liferay.com/web/guest/w/dxp/site-building/personalizing-site-experience/experience-personalization/content-page-personalization) for content page personalization, you can configure the experience using the languages available for your site. See [Managing Experience Localization](https://learn.liferay.com/web/guest/w/dxp/site-building/personalizing-site-experience/experience-personalization/content-page-personalization#managing-experience-localization) for more information.

#### [Device Display](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#device-display) <a href="#device-display" id="device-display"></a>

Click the device icons to access Liferay’s responsive layout editor. Here you can configure your page for different screen sizes. Available display options include desktop ( ![Desktop](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-display.png) ), tablet ( ![Tablet](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-tablet-portrait.png) ), landscape phone ( ![Landscape Phone](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-mobile-landscape.png) ), and portrait phone ( ![Portrait Phone](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-mobile-portrait.png) ). While editing the tablet and phone layouts, you can adjust the screen size manually using the resize handlebar. See [Building Responsive Layouts](https://learn.liferay.com/web/guest/w/dxp/site-building/optimizing-sites/building-a-responsive-site/building-responsive-layouts-with-the-grid-fragment) for more information.

NOTE

The [fragments and widgets](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#fragments-and-widgets) and [page design options](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#page-design-options) panel are only available in the desktop layout.

#### [Edit History](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#edit-history) <a href="#edit-history" id="edit-history"></a>

Click _History_ ( ![History Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-time.png) ) to view changes made during your current edit session. You can use this history to reserve or restore changes. Alternatively, you can click the Undo and Redo buttons.

![Revert your changes using the Undo, Redo, and History buttons.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference/images/03.png)

#### [Toggle Sidebars](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#toggle-sidebars) <a href="#toggle-sidebars" id="toggle-sidebars"></a>

#### [Convert to Page Template](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#convert-to-page-template) <a href="#convert-to-page-template" id="convert-to-page-template"></a>

Click _Actions_ ( ![Actions Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png) ) in the application bar and select _Convert to Page Template_ (![Page Template](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-page-template.png)) to create a [page template](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/adding-pages/creating-a-page-template) based on the current page design.

#### [Publish](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#publish) <a href="#publish" id="publish"></a>

By default, publishing makes your changes live immediately. However, if [workflow process](https://learn.liferay.com/web/guest/w/dxp/process-automation/workflow/introduction-to-workflow) is configured to direct the review and publishing process, clicking Publish initiates your defined procedure.

### [Editing Sidebar](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#editing-sidebar) <a href="#editing-sidebar" id="editing-sidebar"></a>

Depending on your selected editing mode, you can access these panels in the editing sidebar:

* ![Fragments and Widgets](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-plus.png) - [Fragments and Widgets](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#fragments-and-widgets)
* ![Browser](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-hierarchy.png) - [Browser](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#browser) (previously _Selection_)
* ![Page Design Options](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-format.png) - [Page Design Options](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#page-design-options)
* ![Page Content](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-paperclip.png) - [Page Content](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#page-content) (previously _Contents_)
* ![Comments](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-message.png) - [Comments](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#comments)

![The editing sidebar includes these panels.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference/images/05.png)

#### [Fragments and Widgets](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#fragments-and-widgets) <a href="#fragments-and-widgets" id="fragments-and-widgets"></a>

In the Fragments and Widgets panel ( ![Fragments and Widgets icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-plus.png) ), you can access both out-of-the-box and custom page elements.

**Fragments**: Fragments are extensible, reusable, drag-and-drop elements that serve as the primary building blocks for content pages. Examples include layout elements, videos, and banner images with text overlay. See [Using Fragments](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/page-fragments-and-widgets/using-fragments) to learn more about the out-of-the-box fragments or [Developing Fragments](https://learn.liferay.com/web/guest/w/dxp/site-building/developer-guide/developing-page-fragments/developing-fragments-intro) to learn how to create your own.

**Widgets**: Widgets are [applications](https://learn.liferay.com/web/guest/w/dxp/building-applications) that add dynamic functionality to a page. Examples include blogs, message boards, and calendars. See [Using Widgets on Content Pages](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/using-widgets-on-a-content-page) for more information.

TIP

Beginning with Liferay 7.4 U37/GA37, click the Order button (![Order Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-order.png)) to reorder sets of fragments and widgets. Click the Star button (![Star Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-star.png)) to add a fragment or widget to your list of favorite elements.

#### [Browser](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#browser) <a href="#browser" id="browser"></a>

Use the Browser panel ( ![Browser](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-hierarchy.png) ) to view, organize, and manage all elements in the page. Elements are displayed in a hierarchy. For Liferay 7.4 U37/GA37+, you can drag and drop elements in the Browser panel to reorganize them or double click elements to rename them. Selecting an element opens its settings in the configuration side panel. Select a fragment’s sub-elements to access additional settings. See [Configuring Fragments](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/page-fragments-and-widgets/using-fragments/configuring-fragments) for more information.

NOTE

When editing a content page, header and footer elements are not included in the Browser panel. You can only edit these elements in [master page templates](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/defining-headers-and-footers/master-page-templates).

#### [Page Design Options](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#page-design-options) <a href="#page-design-options" id="page-design-options"></a>

Open the _Page Design Options panel_ (![Page Design Options](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-format.png)) to change the page’s [master page template](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/defining-headers-and-footers/managing-master-page-templates) or [style book](https://learn.liferay.com/web/guest/w/dxp/site-building/site-appearance/style-books/using-a-style-book-to-standardize-site-appearance). Click _Options_ (![Options button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-cog3.png)) to access additional page design options, including [front-end client extensions](https://learn.liferay.com/web/guest/w/dxp/building-applications/client-extensions/front-end-client-extensions).

#### [Page Content](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#page-content) <a href="#page-content" id="page-content"></a>

In the Page Content panel ( ![Page Content](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-paperclip.png) ), you can view and edit content directly added to the page. This can include inline text, images, web content articles, and more. While viewing content, you can search for content items and filter by type. If the page includes a [collection](https://learn.liferay.com/web/guest/w/dxp/site-building/displaying-content/collections-and-collection-pages/about-collections-and-collection-pages), you can view its items and add new items. See [Managing Content in Content Pages](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/managing-content-in-content-pages) for more information.

NOTE

Besides collections, mapped content is not listed in the Page Content panel. The panel only includes content added directly to the page.

#### [Comments](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#comments) <a href="#comments" id="comments"></a>

In the Comments panel ( ![Comments](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-message.png) ), you can comment on fragments and widgets to collaborate with page contributors. You can also view, edit, delete, or reply to open comments. If [mentions](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/notifications-and-requests/user-guide/mentioning-users) are enabled, you can tag users with page update permissions as part of your comment. To add a comment, open the Comments panel and select the desired page element.

#### [Browser](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#browser-1) <a href="#browser-1" id="browser-1"></a>

For Liferay 7.3

In the Selection panel (![Selection](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-pages-tree.png)), you can view a hierarchical outline of all page elements, as well as select, configure, or remove those elements. Similarly, clicking any element on the page while in the design mode opens the Selection panel and highlights the selected page element in the hierarchy. When an element is selected, you can access its general, styles, and link options, if it has any. See [Configuring Fragments](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/page-fragments-and-widgets/using-fragments/configuring-fragments) for more information.

![Selection shows you a hierarchy of your page and contents.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference/images/06.png)

NOTE

A page’s header and footer are not listed in the Selection panel hierarchy, because you can only modify them in the [master page template](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/defining-headers-and-footers/master-page-templates).

#### [Contents](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/content-page-editor-ui-reference#contents) <a href="#contents" id="contents"></a>

For Liferay 7.3

In the Contents panel (![Contents](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-list-ul.png)), you can view, edit, and manage all web content on the page. This includes content displayed in widgets and mapped to content fields. See [Managing Content in Content Pages](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/managing-content-in-content-pages) for more information.
