# Using Page Comments

When building content pages, you and your team can collaborate using Liferay’s page comments feature. Comments are enabled out-of-the-box in Liferay DXP 7.3+.

![Use page comments to collaborate with your teammates.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/using-content-pages/using-page-comments/images/01.png)

### [Adding Page Comments](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/using-page-comments#adding-page-comments) <a href="#adding-page-comments" id="adding-page-comments"></a>

1. Navigate to a content page that includes page elements (i.e., fragments or widgets) and click the _Edit_ button (![Edit Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-edit-pencil.png)) to begin editing the page.
2.  Open the _Comments_ panel (![Comments Icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-comments-w.png)) in the sidebar menu and select the desired fragment or widget.

    Alternatively, you can select the desired page element and click its _Comments_ icon. This opens the comments panel.

    ![Click the Comments icon for the page element.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/using-content-pages/using-page-comments/images/02.png)

    NOTE

    Comments cannot be added to [fragment sub-elements](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/page-fragments-and-widgets/using-fragments/configuring-fragments/fragment-sub-elements-reference), containers, or grids.
3. Enter your comment in the side panel and click _Comment_.

After a comment is added, you can edit or delete the comment via its _Actions_ button (![Actions Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)). Users can also add replies to it.

![Edit, delete, or reply to comments.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/using-content-pages/using-page-comments/images/03.png)

NOTE

Deleting a comment removes all replies to it.

### [Reviewing Page Comments](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages/using-page-comments#reviewing-page-comments) <a href="#reviewing-page-comments" id="reviewing-page-comments"></a>

Once comments are added to a page fragment or widget, you can review them in the comments side panel.

![Review page comments in the comments side panel.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/using-content-pages/using-page-comments/images/04.png)

When collaborating, you can mark a comment as resolved by clicking on its _Resolve_ button (![Resolve Button](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-resolve.png)). By default, resolved comments and their replies are hidden. However, you can view resolved comments by checking _Show Resolved Comments_.

![Resolve comments.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/using-content-pages/using-page-comments/images/05.png)

While viewing resolved comments, you can reopen a comment by clicking its green _Resolve_ button.

![View and reopen resolved comments.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/using-content-pages/using-page-comments/images/06.png)
