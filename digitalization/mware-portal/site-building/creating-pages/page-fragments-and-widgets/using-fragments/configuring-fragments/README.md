# Configuring Fragments

You can configure fragments and their sub-elements. Available options can vary, though some are common to all. To view available configuration options, begin editing a page or template and open the _Browser_ panel (![Browser](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-hierarchy.png)) in the sidebar menu. Then click the fragment or sub-element to configure. Available configuration options appear in three tabs: General, Styles, and Advanced.

![Available configuration options are grouped into three tabs.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/page-fragments-and-widgets/using-fragments/configuring-fragments/images/01.png)

Some configurations are scoped to the specific viewport where they’re made, so you can configure fragments for specific devices to ensure page content is displayed in the most suitable way. See Building a Responsive Site for more information.

You can localize some fragment configuration fields. See Localizing Fragment Configuration Fields for more information.

### General <a href="#general" id="general"></a>

The General tab includes both standard configuration options (e.g., visibility and frame) and options unique to each fragment. See General Settings Reference for more information.

### Styles <a href="#styles" id="styles"></a>

The Styles tab includes standard options for configuring a fragment’s style, including a fragment’s dimensions, background, borders, and more. See Styles Reference for more information on available style configurations.

### Advanced <a href="#advanced" id="advanced"></a>

The Advanced tab includes more advanced or technical configurations. This includes hiding fragments from search results, changing the HTML generated on a page, or adding custom CSS. See Advanced Settings Reference for more information.

### Fragment Sub-Element Settings <a href="#fragment-sub-element-settings" id="fragment-sub-element-settings"></a>

Many fragments include sub-elements with their own configuration options. Available options depend on the sub-element’s type and are organized into tabs: Mapping, Image Source, and Link. See Fragment Sub-Elements Reference for more information.

#### Mapping <a href="#mapping" id="mapping"></a>

In the Mapping tab, you can map page elements to available assets by selecting the desired item (e.g., web content article, document, blog) and specifying which of its fields to display in the element (e.g., title, author, name).

#### Image Source <a href="#image-source" id="image-source"></a>

In the Image Source tab, you can select an element’s image, view its resolution, and provide its alt text.

#### Link <a href="#link" id="link"></a>

In the Link tab, you can either manually add a URL to a page element, or select from an available content field. You can also specify the desired target (e.g., self, parent).
