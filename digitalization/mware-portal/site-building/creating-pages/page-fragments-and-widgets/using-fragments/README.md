# Using Fragments

Page fragments are extensible and reusable drag-and-drop elements for building [content pages](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/using-content-pages) and their related templates (i.e., [masters](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/defining-headers-and-footers/master-page-templates), [pages](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/adding-pages/creating-a-page-template), and [display pages](https://learn.liferay.com/web/guest/w/dxp/site-building/displaying-content/using-display-page-templates)). They are built using HTML, CSS, and JavaScript and can provide both structure and functionality to your pages.

![Build content pages and templates with fragments.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/page-fragments-and-widgets/using-fragments/images/01.png)

Liferay provides a variety of fragments out-of-the-box, but you can develop custom fragments using the [page fragment editor interface](https://learn.liferay.com/web/guest/w/dxp/site-building/developer-guide/reference/fragments/page-fragment-editor-interface-reference) or the [Fragments Toolkit](https://learn.liferay.com/web/guest/w/dxp/site-building/developer-guide/developing-page-fragments/using-the-fragments-toolkit). Additionally, you can [embed Liferay widgets](https://learn.liferay.com/web/guest/w/dxp/site-building/developer-guide/reference/fragments/fragment-specific-tags-reference#including-widgets-within-a-fragment) into fragments or add [editable fields](https://learn.liferay.com/web/guest/w/dxp/site-building/developer-guide/reference/fragments/fragment-specific-tags-reference). See [Developing Page Fragments](https://learn.liferay.com/web/guest/w/dxp/site-building/developer-guide/developing-page-fragments/developing-fragments-intro) to learn more.

If you are working with forms, you can personalize your form fields by [mapping them to custom form fragments](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/page-fragments-and-widgets/using-fragments/personalizing-custom-forms-using-form-fragments).

All page fragments are organized into _sets_, which group related fragments for easier management and use. Each fragment set can include common resources accessible to all the fragments. See [Including Default Resources in Fragments](https://learn.liferay.com/web/guest/w/dxp/site-building/developer-guide/developing-page-fragments/including-default-resources-with-fragments) for more information.

After adding fragments to a page or template, you can configure and customize them and their sub-elements. These options can vary, though some are common to all. See [Configuring Fragments](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/page-fragments-and-widgets/using-fragments/configuring-fragments) to learn more about available options.
