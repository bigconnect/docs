# Default Widgets Reference

Liferay provides a variety of widgets out-of-the-box, so you can start building your solution right away. Widgets can be placed on content pages, widget pages, and page templates. To view available widgets on a content page, begin editing a page and select _Fragments and Widgets_ (![Fragments and Widgets](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-plus.png)) in the editing sidebar menu and select the _Widgets_ tab. To view available widgets on a widget page, click _Add_ (![add](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-plus.png)).

Widgets are organized into these sections:
