# Using Widgets

Widgets are full-blown web applications that must be deployed to a portal instance. Built on the Portlet specification, widgets provide a way to create customized web experiences for users. MWARE Portal provides out-of-the-box widgets with a lot of functionality, such as Message Boards, a Wiki, and a host of others. You can develop new Java-based widgets of your own or use Objects, a portal framework for building custom Object definitions that integrate with portal frameworks without requiring the writing of code or deployment of modules. With custom object definitions, widgets can be enabled, allowing you to place object definitions directly on widget or content pages.
