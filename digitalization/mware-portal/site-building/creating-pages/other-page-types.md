# Other Page Types

Content pages are the most commonly used page type, but there are uses for the other page types.

### Utility Pages <a href="#utility-pages" id="utility-pages"></a>

Utility pages are content pages you can apply to system-level pages, like 404 error pages. See Using Utility Pages for more information.

![You can create 404 error page like this one using a utility page.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/understanding-pages/other-page-types/images/01.png)

### Full Page Application <a href="#full-page-application" id="full-page-application"></a>

The Full Page application page type displays a single application that fills the entire page. See Using the Full Page Application Page for more information.

![A full page application page displays a single application that spans the entire width of the page.](<../../../../.gitbook/assets/02 (4).png>)

### Page Set <a href="#page-set" id="page-set"></a>

The Page Set option creates a container for subpages that is not actually a page itself.

![A page set page acts as a container for other pages.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/understanding-pages/other-page-types/images/03.png)

### Link to a Page <a href="#link-to-a-page" id="link-to-a-page"></a>

The Link to a Page of This Site option links to a page within the same site. This is often used to make a page available in multiple parts of a site’s hierarchy.

### Panel <a href="#panel" id="panel"></a>

The Panel option creates a page containing several applications as selected by an administrator, but only one is displayed at a time. Users select the widget they want to display from a menu on the left side of the page. The selected application takes up the entire page on the right side.

![A panel page shows a list of configured applications on the left and the chosen application on the right.](<../../../../.gitbook/assets/04 (2).png>)

### Embedded <a href="#embedded" id="embedded"></a>

The Embedded option uses an iframe widget to show content from another website. The website appears in context and within the navigation of your portal instance.

### Link to URL <a href="#link-to-url" id="link-to-url"></a>

The Link to URL option adds a link to the provided URL. This can be an external page or a link across sites in the same Portal instance.

### Collection Pages <a href="#collection-pages" id="collection-pages"></a>

Collection pages are linked to a collection. These pages simplify the process of displaying and personalizing collections. See Displaying Collections for more information.
