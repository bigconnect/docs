# Site Appearance

The design and functionality of a Liferay site can be adjusted and customized through a variety of complementary mechanisms. This table summarizes and contrasts which Liferay functions and tools can be used to achieve common tasks and goals:

| Features                                | Style Books | Master Page Templates | Themes |
| --------------------------------------- | :---------: | :-------------------: | :----: |
| Embed common fragments/widgets          |             |           ✓           |    ✓   |
| Define common layouts for pages         |             |           ✓           |    ✓   |
| Managed through the UI                  |      ✓      |           ✓           |        |
| Customize styles, spacing, colors, etc. |      ✓      |                       |    ✓   |
| Add extra functionality                 |             |                       |    ✓   |

### [Master Page Templates](https://learn.liferay.com/web/guest/w/dxp/site-building/site-appearance/site-appearance#master-page-templates) <a href="#master-page-templates" id="master-page-templates"></a>

[Master Page Templates](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/defining-headers-and-footers/master-page-templates) allow you to define common elements for your pages using Fragments, especially headers and footers. You can use them to conform any number of pages on your Site to the look and feel you design.

![Master Page Templates are a simple way to define elements common to all of your pages, such as headers and footers.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/site-appearance/site-appearance/images/01.png)

### [Style Books](https://learn.liferay.com/web/guest/w/dxp/site-building/site-appearance/site-appearance#style-books) <a href="#style-books" id="style-books"></a>

[Style Books](https://learn.liferay.com/web/guest/w/dxp/site-building/site-appearance/style-books/using-a-style-book-to-standardize-site-appearance) are sets of visual standards that apply to a Site, such as standard colors and spacing. This allows you to design every page’s layout independently while maintaining a consistent experience between each of them.

![Style Books define the rules for your Site's appearance, such as text colors.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/site-appearance/site-appearance/images/02.png)

### [Widget/Fragment Appearance](https://learn.liferay.com/web/guest/w/dxp/site-building/site-appearance/site-appearance#widgetfragment-appearance) <a href="#widgetfragment-appearance" id="widgetfragment-appearance"></a>

Fragments and widgets are the building blocks of your Site. There are many ways to customize them to suit your Site’s appearance.

* [Fragment customizations](https://learn.liferay.com/web/guest/w/dxp/site-building/developer-guide/developing-page-fragments/developing-fragments-intro) can be used to tailor the look and feel of your Site’s Fragment Pages
* Application Display Templates allow you to customize the appearance and behavior of the widgets on your Site

### [Themes](https://learn.liferay.com/web/guest/w/dxp/site-building/site-appearance/site-appearance#themes) <a href="#themes" id="themes"></a>

[Themes](https://learn.liferay.com/web/guest/w/dxp/site-building/site-appearance/themes/introduction-to-themes) are a highly flexible tool for customizing the default look and feel of your Site. They provide a foundation that your [Style Books](https://learn.liferay.com/web/guest/w/dxp/site-building/site-appearance/site-appearance#style-books) and [Page Templates](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/adding-pages/creating-a-page-template) build on top of. Widgets can also be embedded in the themes themselves to ensure a particular arrangement.

![Choosing a theme for your Site's pages can significantly alter the look and feel of your Site.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/site-appearance/site-appearance/images/03.png)
