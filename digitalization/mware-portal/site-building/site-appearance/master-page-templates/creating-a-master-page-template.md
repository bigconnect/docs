# Creating a Master Page Template

Although there are default master page templates you can use to define the look and feel of the headers and footers for your site’s pages, you may want a more custom solution. You can create custom master page templates for this.

Follow these steps to create a master page templates:

1. Open the _Site Menu_ (![Site Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-product-menu.png)) and navigate to _Design_ → _Page Templates_.
2. Under the Masters tab, click _Add_ (![Add](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-add.png)) to create a new Master Page Template.
3. Enter the _Name_ of your new master page template.
4.  In Fragments and Widgets (![Fragments and Widgets](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-add-widget.png)) on the sidebar, add fragments for the common elements that you require.

    ![Add the master page template's common elements from the footers and navigation bars sections.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/defining-headers-and-footers/creating-a-master-page-template/images/01.png)
5.  (Optional) Drag and drop the Drop Zone to a new location in the layout. For example, you can add a grid with two modules and move the drop zone to one module, so users can only add page fragments to that portion of the grid.

    ![You can move the Drop Zone to control where users can add page fragments.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/defining-headers-and-footers/creating-a-master-page-template/images/02.gif)
6.  (Optional) Specify which page fragments can be added to the Drop Zone by clicking the _Configure Allowed Fragments_ button.

    Check the page fragments you want to allow in this master page template.

    Check the _Select New Fragments Automatically_ box to include new fragment types in the list of allowed fragments.

    ![Check and uncheck fragments from the allowed fragments dialog to specify whether they can be added to a page that uses this master page template.](https://resources.learn.liferay.com/images/dxp/latest/en/site-building/creating-pages/defining-headers-and-footers/creating-a-master-page-template/images/03.png)

    Click _Save_ to close the Allowed Fragments dialog.
7. (Optional) To preview your content page, click _Options_ (![Options](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-options.png)) at the top right corner → _Preview in a New Tab_.
8. Click _Publish Master_ to create the master page template.

You can revert any action using the _Undo_ (![Undo icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-undo.png)) or _Redo_ (![Redo icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-redo.png)) buttons, or you can return to a previous version of your edits using the _History_ (![History icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-time.png)) button.

NOTE

If a custom master page template is used for a page, the theme for the page is defined through the master page template and can’t be changed through the page’s settings. See [Changing a Master Page Template’s Design](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/defining-headers-and-footers/managing-master-page-templates#changing-a-master-page-templates-design) for more information.
