# Message Boards

Liferay DXP’s Message Boards app is a forum application that can be added to any DXP site page. A Message Board on DXP can be [scoped to a site](https://learn.liferay.com/web/guest/w/dxp/system-administration/configuring-liferay/understanding-configuration-scope), including a regular site, an organization’s site, or a user’s profile site or dashboard site.

### [Adding Message Boards to a Site](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/message-boards/user-guide/getting-started-with-message-boards#adding-message-boards-to-a-site) <a href="#adding-message-boards-to-a-site" id="adding-message-boards-to-a-site"></a>

The fastest way to begin using the _Message Boards_ app is to deploy the widget to a [Site Page](https://help.liferay.com/hc/articles/360029132211-Creating-Pages).

1.  Navigate to the site and page desired (e.g. _Forum Page_).

    ![New Forum Page](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/message-boards/user-guide/getting-started-with-message-boards/images/03.png)
2. Click the _Add_ button.
3.  Click _Widgets_ then _Collaboration_ to expand the menu.

    ![Adding the Message Boards Widget to using the Add Application menu.](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/message-boards/user-guide/getting-started-with-message-boards/images/06.png)
4.  Drag and drop the _Message Boards_ widget to the desired location on the page.

    ![Deploying the Message Boards app to the forum page.](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/message-boards/user-guide/getting-started-with-message-boards/images/04.png)

Site members are able to create forum posts using the _Message Boards_ widget. Note that there can be only one _Message Boards_ widget per page.
