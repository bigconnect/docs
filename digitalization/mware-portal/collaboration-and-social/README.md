# Collaboration and Social

Liferay DXP empowers users to build robust communities with flexible, social, and extensible collaborative applications.

Out-of-the-box features include:

* [Message Boards](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/collaboration-and-social-overview#message-boards)
* [Wiki](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/collaboration-and-social-overview#wiki)
* [Social Tools](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/collaboration-and-social-overview#social-tools)
* [Invitations](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/collaboration-and-social-overview#invitations)
* [Knowledge Base](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/collaboration-and-social-overview#knowledge-base)

### [Message Boards](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/collaboration-and-social-overview#message-boards) <a href="#message-boards" id="message-boards"></a>

The Message Boards app is a platform for content-rich discussions and provides tools for moderation, subscriptions, and thread management.

![Figure 1: The Message Boards app is fantastic for facilitating discussions.](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/collaboration-and-social-overview/images/01.png)

To begin using the Message Board app to build a forum, see the [Getting Started with Message Boards](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/message-boards/user-guide/getting-started-with-message-boards) article.

### [Wiki](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/collaboration-and-social-overview#wiki) <a href="#wiki" id="wiki"></a>

DXP includes a full-featured Wiki application that provides a rich writing environment, article versioning, and support for multiple wiki nodes. Wikis in DXP are completely integrated with the portal’s [user management](https://help.liferay.com/hc/articles/360029131931-Introduction-to-Managing-Users), [tagging](https://help.liferay.com/hc/articles/360028820472-Tagging-Content), and [security](https://help.liferay.com/hc/articles/360028711192-Introduction-to-Securing-Liferay-DXP) features.

![Figure 2: The Wiki widget displays your wiki on a Site page.](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/collaboration-and-social-overview/images/02.png)

To begin creating a wiki, see the [Getting Started with Wikis](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/wiki/getting-started-with-wikis) article.

### [Social Tools](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/collaboration-and-social-overview#social-tools) <a href="#social-tools" id="social-tools"></a>

The following social applications are included with Liferay DXP:

* [Activities](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/social-tools/user-guide/using-the-activities-widget)
* [Contacts Center](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/social-tools/user-guide/using-the-contacts-center-widget)

These tools are building blocks for building an integrated, social experience for users. Activities provides a configurable feed of the actions users take on a site. Contacts Center allows users to search, view, and establish social relations with other users.

![Figure 3: The Activities widget tracks user activities.](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/collaboration-and-social-overview/images/03.png)

### [Invitations](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/collaboration-and-social-overview#invitations) <a href="#invitations" id="invitations"></a>

The [_Invite Members_ widget](https://learn.liferay.com/web/guest/w/dxp/site-building/sites/site-membership/inviting-members-to-your-site) lets Site Administrators send invitations to join the Site. When Users confirm such invitations, they become Site members assigned to the Roles defined by the site administrator. Click to learn more about [Site Membership](https://learn.liferay.com/web/guest/w/dxp/site-building/sites/site-membership/adding-members-to-sites).

![Figure 4: Inviting members to a site.](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/collaboration-and-social-overview/images/04.png)

Once the user has been invited, they can confirm or ignore the request.

![Figure 5: Confirming a request to join a site.](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/collaboration-and-social-overview/images/05.png)

### [Knowledge Base](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/collaboration-and-social-overview#knowledge-base) <a href="#knowledge-base" id="knowledge-base"></a>

The _Knowledge Base_ app can be used to display professional product documentation or form complete books or guides. Content writers can use multiple formats, including markdown. Furthermore, Knowledge Base are integrated with the [workflow engine](https://help.liferay.com/hc/articles/360028721732-Introduction-to-Workflow) so content editors can review and approve articles before publication.

![Figure 6: The Knowledge Base widget can also be used to publish articles.](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/collaboration-and-social-overview/images/06.png)
