# Wiki

The _Wiki_ application includes a rich-text WYSIWYG editor, version tracking, and the ability to create multiple wiki nodes. Wikis are integrated with the portal’s users and permissions.

### Adding a Wiki Widget to a Site <a href="#adding-a-wiki-widget-to-a-site" id="adding-a-wiki-widget-to-a-site"></a>

The fastest way to begin using the _Wiki_ widget is deploying it on a Site Page.

1. Navigate to the site page where the wiki will be created (for example, the portal _Guest_ site’s _Wiki page_).
2. Click the _Add_ button.
3.  Click _Widgets_ then _Wiki_ to expand the menu.

    ![Select a Wiki widget from the Widgets menu](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/getting-started-with-wikis/images/01.png)
4.  Drag and drop the _Wiki_ widget to the desired location on the page.

    ![The widget is now on the site page.](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/getting-started-with-wikis/images/02.png)

Site members are now able to create and edit wiki pages. Note that there can be only one _Wiki_ widget per page.

### Complementary Wiki Widgets <a href="#complementary-wiki-widgets" id="complementary-wiki-widgets"></a>

The portal offers three additional widgets to be used in conjunction with the _Wiki_ widget which makes it easier to navigate to and view the other wiki pages on the same portal instance. This is because the _Wiki_ widget displays only the _FrontPage_.

* Page Menu
* Tree Menu
* Wiki Display
