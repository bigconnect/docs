# Knowledge Base

Knowledge Base provides tools for creating and managing product documentation. You can write articles in the Liferay UI or import existing Markdown files. Additionally, you can create [templates](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/knowledge-base/knowledge-base-templates) to standardize article structures and content. Enabling [workflow](https://learn.liferay.com/web/guest/w/dxp/process-automation/workflow/introduction-to-workflow) ensures articles go through an approval process before publishing.

![Create and manage product documentation.](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/knowledge-base/images/01.png)

Once published, you can use [Knowledge Base widgets](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/knowledge-base/knowledge-base-display-widget) to display your documentation hierarchy or individual sections and articles. Alternatively, you can display and style Knowledge Base articles using [display page templates](https://learn.liferay.com/web/guest/w/dxp/site-building/displaying-content/using-display-page-templates), [information templates](https://learn.liferay.com/web/guest/w/dxp/site-building/displaying-content/using-information-templates), and [fragments](https://learn.liferay.com/web/guest/w/dxp/site-building/creating-pages/page-fragments-and-widgets/using-fragments). With built-in comments, users can leave article [feedback](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/knowledge-base/responding-to-knowledge-base-feedback) that you can manage and track within Knowledge Base.

Additionally, if you’re importing Markdown files and hosting them on a service like GitHub, you can enable [source URLs](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/knowledge-base/importing-knowledge-base-articles#setting-a-source-url) for imported articles. Once configured, Knowledge Base adds an Edit on GitHub button to each article so users can view the article’s Markdown in the source repository.
