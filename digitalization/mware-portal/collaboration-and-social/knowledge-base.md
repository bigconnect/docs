# Knowledge Base

Knowledge Base provides tools for creating and managing product documentation. You can write articles in the portal UI or import existing Markdown files. Additionally, you can create templates to standardize article structures and content. Enabling workflow ensures articles go through an approval process before publishing.

![Create and manage product documentation.](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/knowledge-base/images/01.png)

Once published, you can use Knowledge Base widgets to display your documentation hierarchy or individual sections and articles. Alternatively, you can display and style Knowledge Base articles using display page templates, information templates, and fragments. With built-in comments, users can leave article feedback that you can manage and track within Knowledge Base.

Additionally, if you’re importing Markdown files and hosting them on a service like GitHub, you can enable source URLs for imported articles. Once configured, Knowledge Base adds an Edit on GitHub button to each article so users can view the article’s Markdown in the source repository.
