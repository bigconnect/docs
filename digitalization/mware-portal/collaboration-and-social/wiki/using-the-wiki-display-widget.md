# Using the Wiki Display Widget

Users can use the _Wiki Display_ widget to highlight a specific wiki page regardless of whether it is a top level page or a child page. To use the _Wiki Display_ widget:

1. Navigate to the site page where the _Wiki_ widget has been deployed.
2. Click _Add_ → _Widgets_.
3.  Expand _Wiki_.

    ![Adding the Wiki Display widget](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/using-the-wiki-display-widget/images/01.png)
4.  Drag and drop the _Wiki Display_ widget to the desired location on the site page. Note that unlike the _Wiki_ widget, multiple _Wiki Display_ widgets can be deployed on a page.

    ![Multiple Wiki Display widgets on a site page](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/using-the-wiki-display-widget/images/02.png)
5. Click _Please configure this portlet to make it visible to all users._
6. On the _Setup_ tab, select **Main** from the _Node_ dropdown menu.
7.  Select the wiki page from the _Page_ dropdown menu. Wiki pages can be either a top-level page or a child page.

    ![Wiki Display widget configuration](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/using-the-wiki-display-widget/images/03.png)
8. Click _Save_ and close the window.

![Wiki Display widget displays an article.](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/using-the-wiki-display-widget/images/04.png)

The _Wiki Display_ widget now displays the selected _Wiki Page_.
