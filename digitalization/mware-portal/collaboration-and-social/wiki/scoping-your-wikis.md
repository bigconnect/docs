# Scoping Your Wikis

Besides using [Wiki Nodes](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/wiki/creating-a-node) to organize your content, you can scope a wiki to the [Global, Site, or Page Scopes](https://help.liferay.com/hc/articles/360028819992-Widget-Scope).

### [Global](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/wiki/scoping-your-wikis#global) <a href="#global" id="global"></a>

Wiki pages created at the global site scope level are available on all other sites. However, content will not be automatically published. Administrators must configure the _Wiki_ widget’s scope to _Global_.

#### [Creating Globally Scoped Wiki Pages](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/wiki/scoping-your-wikis#creating-globally-scoped-wiki-pages) <a href="#creating-globally-scoped-wiki-pages" id="creating-globally-scoped-wiki-pages"></a>

1. Navigate to the site page where the _Wiki_ widget is deployed.
2.  Mouse over the _Wiki_ widget’s name and click _Options_ ![Icon Options](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-widget-options.png) then _Configuration_.

    ![Wiki Options](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/scoping-your-wikis/images/10.png)
3. Click _Scope_.
4.  Select **Global** from the _Scope_ dropdown menu.

    ![Selecting the Global scope](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/scoping-your-wikis/images/01.png)
5. Click _Save_ and close the window.

The _Wiki_ widget has been configured to display content for the _Global_ scope.

![Viewing the Global scope](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/scoping-your-wikis/images/02.png)

#### [Managing Globally Scoped _Wiki_ Pages](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/wiki/scoping-your-wikis#managing-globally-scoped-wiki-pages) <a href="#managing-globally-scoped-wiki-pages" id="managing-globally-scoped-wiki-pages"></a>

1. Open the _Product Menu_ (![Product Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-product-menu.png)), then click the compass icon (![Compass](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-compass.png)) on the Site Administration menu. This opens the Select Site dialog.
2.  Select the _My Sites_ tab, then select _Global_.

    ![Selecting the Global site](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/scoping-your-wikis/images/06.png)
3. Click _Content & Data_ → _Wiki_.

![Global Scoped Wiki](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/scoping-your-wikis/images/07.png)

Any changes made here apply to the global scope.

### [Site](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/wiki/scoping-your-wikis#site) <a href="#site" id="site"></a>

By default, the _Wiki_ app is scoped to the current selected Site. Wikis scoped to a particular site are not visible when viewing wikis that may be created on another site in the same instance.

### [Page](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/wiki/scoping-your-wikis#page) <a href="#page" id="page"></a>

Creating page scoped message boards allows forum members to view different wikis on different pages housed on the same site.

#### [Creating a Page Scoped Wiki](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/wiki/scoping-your-wikis#creating-a-page-scoped-wiki) <a href="#creating-a-page-scoped-wiki" id="creating-a-page-scoped-wiki"></a>

1.  Navigate to the page that which will be scoped (_Second Wiki_).

    ![Two pages before scoping](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/scoping-your-wikis/images/03.png)
2. Click the _Options_ icon (![Options](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-widget-options.png)) in the widget’s title bar and select _Configuration_.
3. Click the _Scope_ tab.
4.  Select the page’s name or _\[YOUR-PAGE] (Create New)_ if the page scope doesn’t exist yet.

    ![Selecting the page scope](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/scoping-your-wikis/images/04.png)
5. Click _Save_ then close the dialog window.

The second page has been configured for page scope.

![Viewing the new page scoped wiki](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/scoping-your-wikis/images/05.png)

#### [Managing Page Scoped Wikis](https://learn.liferay.com/web/guest/w/dxp/collaboration-and-social/wiki/scoping-your-wikis#managing-page-scoped-wikis) <a href="#managing-page-scoped-wikis" id="managing-page-scoped-wikis"></a>

Note that administrators must still use the _Site Administration_ menu to administer a page scoped Wiki widget by setting the _Site Administration menu_’s active scope. Follow these steps:

1. Open the _Product Menu_ (![Product Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-product-menu.png)), expand the menu for your Site, and then click _Content & Data_.
2.  The current scope appears just below the Content & Data heading. Default Scope is the current Site. To change this, click the gear icon (![Gear](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-control-menu-gear.png)) and then select your desired scope. This changes the Site Administration menu to reflect scope you selected. To work in a page’s scope, for example, select that page from the gear icon. That page’s name then becomes the Site Administration menu’s title.

    ![Selecting the new page scoped wiki](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/scoping-your-wikis/images/08.png)
3. Click _Wiki_.

Any changes you make here apply to the scope that you selected in the previous step.

![Selecting the new page scoped wiki](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/scoping-your-wikis/images/09.png)
