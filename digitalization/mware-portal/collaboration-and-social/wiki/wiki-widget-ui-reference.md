# Wiki Widget UI Reference

### FrontPage <a href="#frontpage" id="frontpage"></a>

The _FrontPage_ tab is the landing page for the _Wiki_ widget. From here, content creators can add a child page, edit the existing _FrontPage_ page, view the _FrontPage_’s page details, print the page, add a rating, or add a comment to the wiki.

![FrontPage](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/wiki-widget-ui-reference/images/01.png)

#### Details <a href="#details" id="details"></a>

Clicking the _Details_ link on the _FrontPage_ tab displays information about that wiki page.

**Content Tab**

This is similar to the _Edit_ function; users can edit the wiki page.

![Content Tab](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/wiki-widget-ui-reference/images/11.png)

**Details Tab**

The _Details_ function displays the _FrontPage_’s metadata:

![Details Tab](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/wiki-widget-ui-reference/images/06.png)

**History**

The _History_ tab displays the wiki page’s revision history.

![History](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/wiki-widget-ui-reference/images/07.png)

**Incoming Links**

The _Incoming Links_ tab lists all pages that link to this wiki page.

![Incoming Links](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/wiki-widget-ui-reference/images/08.png)

**Outgoing Links**

The _Outgoing Links_ tab lists all links found in the wiki page.

![Outgoing Links](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/wiki-widget-ui-reference/images/09.png)

**Attachments**

The _Attachments_ tab lists all of the wiki page’s attachments.

![Attachments](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/wiki-widget-ui-reference/images/10.png)

### Recent Changes <a href="#recent-changes" id="recent-changes"></a>

The _Recent Changes_ tab lists all the pages in the selected node, starting from the most recent.

![Recent Changes](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/wiki-widget-ui-reference/images/02.png)

### All Pages <a href="#all-pages" id="all-pages"></a>

The _All Pages_ tab lists all the pages created in the selected wiki node.

![All Pages](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/wiki-widget-ui-reference/images/03.png)

### Orphan Pages <a href="#orphan-pages" id="orphan-pages"></a>

Orphan Pages are wiki pages existing on a site without any other pages linking to them.

![Orphan Pages](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/wiki-widget-ui-reference/images/04.png)

### Draft Pages <a href="#draft-pages" id="draft-pages"></a>

The _Draft Pages_ tab lists all _Wiki pages_ that have been saved as a draft.

![Draft Pages](https://resources.learn.liferay.com/images/dxp/latest/en/collaboration-and-social/wiki/wiki-widget-ui-reference/images/05.png)
