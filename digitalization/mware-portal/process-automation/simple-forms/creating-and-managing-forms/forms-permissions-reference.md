# Forms Permissions Reference

This article serves as a guide for all permissions associated with the Forms application.

### [Form Widget Permissions](https://learn.liferay.com/web/guest/w/dxp/process-automation/forms/creating-and-managing-forms/forms-permissions-reference#form-widget-permissions) <a href="#form-widget-permissions" id="form-widget-permissions"></a>

Navigate to the site page where the _Form_ widget has been deployed. Click the Options icon (![Options](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-options.png)) next to the widget name then _Permissions_.

![View the Form Widget Permissions](https://resources.learn.liferay.com/images/dxp/latest/en/process-automation/forms/creating-and-managing-forms/forms-permissions-reference/images/01.png)

| Permission    | Description                                                                    |
| ------------- | ------------------------------------------------------------------------------ |
| Permissions   | Grants the ability to view and widget permissions for other users              |
| Preferences   | Grants the ability to view and set widget preferences                          |
| Configuration | Grants the ability to configure the widget; can select which form is displayed |
| View          | Grants the ability to view the _Form_ widget                                   |
| Add to Page   | Grants the ability to add the _Form_ widget to a site page                     |

### [Forms Permissions](https://learn.liferay.com/web/guest/w/dxp/process-automation/forms/creating-and-managing-forms/forms-permissions-reference#forms-permissions) <a href="#forms-permissions" id="forms-permissions"></a>

1. Open the _Product Menu_ (![Product Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-product-menu.png)) then click the compass icon (![Compass](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-compass.png)) on the _Site Administration_ menu. Select the site that contains the form.
2. Click _Content & Data_ → _Forms_.
3.  Click the _Actions_ button (![Actions](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) next to the form.

    ![View a form's specific Permissions.](https://resources.learn.liferay.com/images/dxp/latest/en/process-automation/forms/creating-and-managing-forms/forms-permissions-reference/images/02.png)
4. Click _Permissions_.

![View the Form's Permissions](https://resources.learn.liferay.com/images/dxp/latest/en/process-automation/forms/creating-and-managing-forms/forms-permissions-reference/images/03.png)

| Permission               | Description                                                              |
| ------------------------ | ------------------------------------------------------------------------ |
| Delete                   | Grants the ability to delete the form                                    |
| Permissions              | Grants the ability to view and set the form’s permissions                |
| Update                   | Grants permission to make changes to the form, and to edit form entries. |
| Add Form Instance Record | Grants the ability to add an entry                                       |
| View                     | Grants the ability to view the form                                      |
