# Linking and Embedding

"Linking" refers to using URLs or paths to point to Advanced Forms pages.

"Embedding" refers to a deployment option where Advanced Forms pages or forms appear _embedded_ or _nested_ within another application's page. This is in contrast to the default standalone deployment setup where Advanced Forms produces entire web pages, and you link to those page from your application.

Advanced Forms supports several embedding methods:

* Form Runner server-side Java embedding API
* Form Runner Portal Widget
* Form Runner JavaScript Embedding API
* Form Runner offline embedding API
