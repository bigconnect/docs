# Exporting and Importing Forms

You can export all your forms as a `LAR` file and then import them into a different Site for reuse.

See Exporting/Importing Site Pages and Content to learn about the Import/Export process.

### Exporting Forms as a LAR File <a href="#exporting-forms-as-a-lar-file" id="exporting-forms-as-a-lar-file"></a>

1. Navigate to _Site Administration_ → _Content and Data_ → _Forms_.
2. Click the ![Options](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-options.png) icon in the upper right then _Export / Import_.
3. Enter a different name for the `LAR` file.
4.  Select the desired configuration and content:

    * **Configuration**: Checked
    * **Content**: All
    * **Deletions**: Unchecked
    * **Permissions**: Unchecked.

    ![Export your forms as a LAR file.](https://resources.learn.liferay.com/images/dxp/latest/en/process-automation/forms/creating-and-managing-forms/exporting-and-importing-forms/images/01.png)
5. Click _Export_.
6.  Click the `LAR` file to download it to your local machine.

    ![Download the LAR.](https://resources.learn.liferay.com/images/dxp/latest/en/process-automation/forms/creating-and-managing-forms/exporting-and-importing-forms/images/02.png)
7. Choose the desired folder then click _OK_ in the confirmation box.

The Forms `LAR` file has been downloaded. You can import this to another Site.

### Importing Forms into a Site <a href="#importing-forms-into-a-site" id="importing-forms-into-a-site"></a>

1. Navigate to another Site.
2. Navigate to _Site Administration_ → _Content and Data_ → _Forms_.
3. Click the ![Options](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-options.png) icon in the upper right → _Export / Import_.
4. Click the _Import_ tab.
5. Drag and drop the `LAR` file or click _Select File_ to browse its location.
6. Click _Continue_.
7. Expand the _Update Data_ section.
8.  Click _Mirror_ (recommended).

    ![Import the LAR using the recommended setting.](https://resources.learn.liferay.com/images/dxp/latest/en/process-automation/forms/creating-and-managing-forms/exporting-and-importing-forms/images/03.png)
9. Click _Import_.
10. Click the _Export / Import_ window.

The Forms from the Guest Site are imported into this Site.
