# Notifications

MWARE Portal provides integrated notification tools, so you can ensure users are alerted to platform events. This includes email and website notifications for the following default applications:

| Application          | Email | Website |
| -------------------- | ----- | ------- |
| Blogs                | ✔     | ✔       |
| Comments             | ✔     | ✔       |
| Contact Center       |       | ✔       |
| Documents and Media  | ✔     | ✔       |
| Import/Export Center |       | ✔       |
| Invite Members       |       | ✔       |
| Mentions             | ✔     | ✔       |
| Message Boards       | ✔     | ✔       |
| My Workflow Tasks    | ✔     | ✔       |
| Publications         |       | ✔       |
| Segments Experiment  | ✔     | ✔       |
| Sharing              | ✔     | ✔       |
| Web Content          | ✔     | ✔       |
| Wiki                 | ✔     | ✔       |

To use email notifications, you must configure a mail server for your instance. Once configured, you can access additional email notification settings at the instance level. Beginning with version 7.4, you can also create notification templates to design and dynamically populate email notifications for Objects. See Notification Actions for more information.

In the Commerce context, notifications are supported for Channel events. See Sending Emails to learn more.
