# Notifications

Liferay provides integrated notification tools, so you can ensure users are alerted to platform events. For Liferay DXP, this includes email and website notifications for the following default applications:

| Application          | Email | Website |
| -------------------- | ----- | ------- |
| Blogs                | ✔     | ✔       |
| Comments             | ✔     | ✔       |
| Contact Center       |       | ✔       |
| Documents and Media  | ✔     | ✔       |
| Import/Export Center |       | ✔       |
| Invite Members       |       | ✔       |
| Mentions             | ✔     | ✔       |
| Message Boards       | ✔     | ✔       |
| My Workflow Tasks    | ✔     | ✔       |
| Publications         |       | ✔       |
| Segments Experiment  | ✔     | ✔       |
| Sharing              | ✔     | ✔       |
| Web Content          | ✔     | ✔       |
| Wiki                 | ✔     | ✔       |

To use email notifications, you must [configure a mail server](https://learn.liferay.com/web/guest/w/dxp/installation-and-upgrades/setting-up-liferay/configuring-mail) for your instance. Once configured, you can access additional [email notification settings](https://learn.liferay.com/web/guest/w/dxp/system-administration/configuring-liferay/virtual-instances/email-settings) at the instance level. Beginning with Liferay 7.4 U33+/GA33+, you can also create [notification templates](https://learn.liferay.com/web/guest/w/dxp/process-automation/notifications/creating-notification-templates) to design and dynamically populate email notifications for Objects. See [Notification Actions](https://learn.liferay.com/web/guest/w/dxp/building-applications/objects/creating-and-managing-objects/actions/defining-object-actions#notification-actions) for more information.

In the Commerce context, notifications are supported for Channel events. See [Sending Emails](https://learn.liferay.com/w/commerce/store-management/sending-emails) to learn more.
