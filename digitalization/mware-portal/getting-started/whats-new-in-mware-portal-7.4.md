# What's New in MWARE Portal 7.4

MWARE DXP 7.4 comes with enhanced functionality and exciting improvements that make it even easier for both technical and non-technical users to deliver and optimize digital experiences.

### Optimizing Digital Experiences with Data-Driven Insight

#### Set Any Element as a Click Target in A/B Testing

You can now run AB tests on any element on the page. Before 7.4, you could only select buttons and links as a Click Goal. With MWARE Portal 7.4, you can now select any page element by including its element ID.

![](../../../.gitbook/assets/image.png)

#### More Insightful Content Audit Tool

In the Content Audit Tool in the Content Dashboard, you can now click on the bars to zoom in on the results; and content assigned to only one vocabulary category is now represented in the graph. Marketers can now easily spot miscategorized content using this new set of enhancements.

<figure><img src="../../../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

#### Content Audit Tool UX Improvements&#x20;

We’ve also made several usability improvements to the Content Audit Tool in the Content Dashboard. For example, now it is much easier to select the vocabularies to be audited, and it is possible to flip the bar chart axes with a click.

<figure><img src="../../../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>

#### Traffic Acquisition Channels in the Content Performance Tool

The traffic acquisition channels in the Content Performance Tool include measurements for organic and paid search, social traffic, and referrals. A channel’s detail view reveals all referring URLs and domains.

![Traffic acquisition channels include search, social and referral data.](https://resources.learn.liferay.com/images/dxp/latest/en/getting-started/whats-new-74/images/09.png)

#### Content Performance Analytics for All Types of Pages <a href="#content-performance-analytics-for-all-types-of-pages" id="content-performance-analytics-for-all-types-of-pages"></a>

The Content Performance Panel is now available for all pages: display pages templates of all assets, content, and widget pages. Before 7.4, the Content Performance Too was only available for web content rendered through a display page template.

![The Content Performance Panel can be used for all page types.](https://resources.learn.liferay.com/images/dxp/latest/en/getting-started/whats-new-74/images/06.png)

### Empowering Practitioners to Build Rich Digital Experiences

Starting with 7.4, you can use the Page Audit tool for auditing your pages’ SEO and accessibility. The Page Audit tool uses the Google PageSpeed Insights service, providing specific recommendations for the portal. With the new Page audit tool, you can check your page’s compliance with the best performance, accessibility, search engine metadata, and SEO practices.

![Google PageSpeed Insights integration provides recommendations.](https://resources.learn.liferay.com/images/dxp/latest/en/getting-started/whats-new-74/images/02.png)

#### More Flexibility to Replicate and Draft Experiences <a href="#more-flexibility-to-replicate-and-draft-experiences" id="more-flexibility-to-replicate-and-draft-experiences"></a>

You can now draft and duplicate Experiences and replace the default experience with another. These enhancements provide much more flexibility when creating and managing Experiences.

![Replicate and Draft Experiences easily.](https://resources.learn.liferay.com/images/dxp/latest/en/getting-started/whats-new-74/images/07.png)

#### Documents Now Visible in the Content Dashboard <a href="#documents-now-visible-in-the-content-dashboard" id="documents-now-visible-in-the-content-dashboard"></a>

Documents now appear in the Content Dashboard, with new filters based on asset type or MIME type. You can access these filters in the Filter and Order drop-down menu in the Content Dashboard.

![There are new filters in the Content Dashboard.](https://resources.learn.liferay.com/images/dxp/latest/en/getting-started/whats-new-74/images/01.png)

#### Account Management Widget <a href="#account-management-widget" id="account-management-widget"></a>

Account Users can view and/or administer their company’s details, addresses, assigned users, associated Organizations, Groups, and Roles without needing to leave their website, as well as minimize the need for assistance from a Portal administrator to administer Accounts on their behalf.

### Create a Seamless B2B Buying Experience: Commerce 4.0 Provides Added Stability and Improvements <a href="#create-a-seamless-b2b-buying-experience-commerce-40-provides-added-stability-and-improvements" id="create-a-seamless-b2b-buying-experience-commerce-40-provides-added-stability-and-improvements"></a>

#### Optimized Product Images for Specific Devices <a href="#optimized-product-images-for-specific-devices" id="optimized-product-images-for-specific-devices"></a>

Page load speed is optimized by changing the quality of a picture depending on the device it’s being rendered on.

#### Different Pricing and Discounts Based on Order Types <a href="#different-pricing-and-discounts-based-on-order-types" id="different-pricing-and-discounts-based-on-order-types"></a>

Sellers can change pricing and discounts depending on order conditions, such as when an order is marked as urgent vs a stock order.

#### Improved Organization Management Widget <a href="#improved-organization-management-widget" id="improved-organization-management-widget"></a>

The Org Chart widget is now the Organization Management widget, and it makes it easy to manage your sales network within the same platform that you are serving your buyers.

### Business Users Can Build Applications Without Writing Code <a href="#business-users-can-build-applications-without-writing-code" id="business-users-can-build-applications-without-writing-code"></a>

With Portal Objects, you can build and deliver applications without having to write code or deploy modules, yet these applications are built on and integrated with Portal’s core frameworks. Quickly develop and manage flexible solutions that adapt the portal to your business needs while maintaining a seamless user experience.

#### Manage Custom Objects Though the UI <a href="#manage-custom-objects-though-the-ui" id="manage-custom-objects-though-the-ui"></a>

You can define objects, adding fields and object layouts, and choose how entries are displayed through the UI. You can also define the scope for each custom object.

#### Object Integration with Experience Management <a href="#object-integration-with-experience-management" id="object-integration-with-experience-management"></a>

Objects are integrated with the Display Pages through Info Framework. When creating an object, a collection provider is generated automatically, allowing you to create experiences with object entries through Collection Display Fragment.

#### Object Integration with Forms <a href="#object-integration-with-forms" id="object-integration-with-forms"></a>

All the capabilities from Forms can be leveraged to insert data into specific objects by changing the storage type of a form to objects.

#### Objects Relationships <a href="#objects-relationships" id="objects-relationships"></a>

You can solve complex use cases with object relationships, easy way to relate objects with not only custom objects, but also native objects shipped with MWARE Portal, such as Blog entries or web content.

#### Objects Integration with Portal Frameworks <a href="#objects-integration-with-dxp-frameworks" id="objects-integration-with-dxp-frameworks"></a>

Portal Objects are fully integrated with existing Portal frameworks, such as Asset, Workflow, Permission, Blueprints and Headless. When an object is created, its specific Headless APIs are created automatically and can be accessed through the API Explorer.

#### Objects Support in Search Widgets <a href="#objects-support-in-search-widgets" id="objects-support-in-search-widgets"></a>

The Type Facet widget supports searchable Portal Object types, and the Search Results widget can display Object entries.

#### Pagination Support in the Collection Display Fragment <a href="#pagination-support-in-the-collection-display-fragment" id="pagination-support-in-the-collection-display-fragment"></a>

You can now paginate the collection items in Collection Display Fragments. This new functionality is especially useful for Collections containing a large number of items. Large Collections become more readable, improving usability and overall experience.

![You can now paginate collections in Collection Display Fragments.](https://resources.learn.liferay.com/images/dxp/latest/en/getting-started/whats-new-74/images/11.png)

#### Search and Filtering Fragments to Collection Displays <a href="#search-and-filtering-fragments-to-collection-displays" id="search-and-filtering-fragments-to-collection-displays"></a>

7.4 includes two new fragments: Collection Filter and Applied Filter.

Using these filters with Collection Display Fragments in your page, you can filter Collections based on different criteria and display what filters have been applied to your Collection.

![New filters help users find data in collections.](https://resources.learn.liferay.com/images/dxp/latest/en/getting-started/whats-new-74/images/05.png)

#### Display Items Related to One Specific Item with Related Item Collections <a href="#display-items-related-to-one-specific-item-with-related-item-collections" id="display-items-related-to-one-specific-item-with-related-item-collections"></a>

When working with the Collection Display Fragment, you can now choose and display items from related Collections using the new Related Items Collection Providers tab.

![Now it's easy to choose related items.](https://resources.learn.liferay.com/images/dxp/latest/en/getting-started/whats-new-74/images/14.png)

#### Define Pre-Filtering Options for the Collection Providers <a href="#define-pre-filtering-options-for-the-collection-providers" id="define-pre-filtering-options-for-the-collection-providers"></a>

Developers can now customize Collection Providers using specific configuration fields. This way, users can pre-filter a Collection Provider and have more flexibility to choose items in the Collection Display Fragment. Users can access the filter from the Actions Menu in the Collection Display Fragment.

![Now you can pre-filter Collection providers.](https://resources.learn.liferay.com/images/dxp/latest/en/getting-started/whats-new-74/images/12.png)

#### Specify Sub-Type Fields for Collection Providers as Mapping Elements <a href="#specify-sub-type-fields-for-collection-providers-as-mapping-elements" id="specify-sub-type-fields-for-collection-providers-as-mapping-elements"></a>

When building a Collection Provider with the Info Framework, developers can now include a sub-type field. This allows end users to map fields on the Page to sub-types when using the Collection Provider in a Collection Display Fragment.

#### Show/Hide Fragments Based on Viewport <a href="#showhide-fragments-based-on-viewport" id="showhide-fragments-based-on-viewport"></a>

You can hide a Fragment on one Viewport while keeping it visible on another. This new capability allows you to further customize your content’s responsiveness for a specific user platform.

![You can hide a Fragment on one Viewport while keeping it visible on another.](https://resources.learn.liferay.com/images/dxp/latest/en/getting-started/whats-new-74/images/08.png)

#### Native Support for Adaptive Media in Content Pages and Display Page Templates <a href="#native-support-for-adaptive-media-in-content-pages-and-display-page-templates" id="native-support-for-adaptive-media-in-content-pages-and-display-page-templates"></a>

You can now use adaptive media in Content Page images to adjust the image resolution dynamically, based on the target screen size. After you add an image resolution in Adaptive Media, the resolution appears in the Resolution drop-down menu for your Content Page image.

![Adaptive Media can now adjust image resolutions dynamically based on screen size.](https://resources.learn.liferay.com/images/dxp/latest/en/getting-started/whats-new-74/images/13.gif)

### Reducing the Cost and Effort to Launch and Maintain Digital Experiences <a href="#reducing-the-cost-and-effort-to-launch-and-maintain-digital-experiences" id="reducing-the-cost-and-effort-to-launch-and-maintain-digital-experiences"></a>

#### Automatic Translation for Web Content <a href="#automatic-translation-for-web-content" id="automatic-translation-for-web-content"></a>

This feature helps accelerate the process of translating web content articles. This continues the efforts made in 7.3 to help streamline the translation process of content. With this feature, translators can focus on polishing a translation instead of starting from scratch.

#### Expiration Dates for Documents <a href="#expiration-dates-for-documents" id="expiration-dates-for-documents"></a>

This feature helps content managers control outdated documents and prevent them from being published, for example, due to a temporary license.

#### Improved WYSIWYG Editor <a href="#improved-wysiwyg-editor" id="improved-wysiwyg-editor"></a>

A new balloon editor has been created by leveraging native CKEditor features. This is a lighter alternative to its predecessor, Alloy Editor, reducing the complexity and maintenance. It also provides some UX improvements, preserving the user-facing features.

#### Asset Libraries Can Be Connected with Staging-Enabled Sites <a href="#asset-libraries-can-be-connected-with-staging-enabled-sites" id="asset-libraries-can-be-connected-with-staging-enabled-sites"></a>

This feature improves the organization and reuse of content for customers in highly regulated sectors where data isolation is key.

Implementing Staging support in Asset Libraries will help customers reduce the amount of effort and cost dedicated to organizing content for multiple sites using the same content while keeping data isolation. This has been backported to 7.3 as well.

#### Advanced File Uploader Options When Uploading Documents and Media <a href="#advanced-file-uploader-options-when-uploading-documents-and-media" id="advanced-file-uploader-options-when-uploading-documents-and-media"></a>

Customers use Documents and Media as a media repository to store elements that later are used to create content. However there are situations, for example a blog post or something informal, where the assets used during content creation are uploaded during the content creation process.

To accelerate this process, content creators can now create folders as well as upload files with all the metadata needed from the item selector in order to reduce time and effort in the content creation process.

#### Collaborate on Publications <a href="#collaborate-on-publications" id="collaborate-on-publications"></a>

Publications often involves multiple content editors working on a single project. You can now invite teammates to join your publication to view, edit, or publish. You can also discuss changes through the new comment system. Items that are still going through workflow must be approved before they can be published.

#### Improved Staging Performance <a href="#improved-staging-performance" id="improved-staging-performance"></a>

Publishing Pages in Staging can now be streamlined by publishing only the Page needed without reference to its parent or children. You can also choose whether Asset Links are published along with the Pages.

#### Elasticsearch 7.15.x Compatibility Out-of-the-Box <a href="#elasticsearch-715x-compatibility-out-of-the-box" id="elasticsearch-715x-compatibility-out-of-the-box"></a>

7.4 comes with support for Elasticsearch 7.15.x; the Elasticsearch Sidecar (for development and testing only, not supported) server is version 7.10.2 of the open source Elasticserch distribution.

#### Enterprise Search (LES) Applications Are Now Bundled <a href="#liferay-enterprise-search-les-applications-are-now-bundled" id="liferay-enterprise-search-les-applications-are-now-bundled"></a>

Starting 7.4, the Enterprise Search (LES) applications are included with all Portal bundles and Docker containers. LES is enabled by default and requires no additional installation steps.&#x20;

### Leverage MWARE Portal as the Foundation in Your Interconnected Enterprise Landscape <a href="#leverage-liferay-as-the-foundation-in-your-interconnected-enterprise-landscape" id="leverage-liferay-as-the-foundation-in-your-interconnected-enterprise-landscape"></a>

#### Portal Accounts <a href="#dxp-accounts" id="dxp-accounts"></a>

Portal Accounts can model respective entities (companies, employees, and the responsibilities pertaining to their job), facilitate the interactions between these entities (such as purchasing of goods and services), and enable you to document relevant information to support these interactions (Tax ID, Billing and Shipping addresses, personnel structures).

#### APIs Everywhere <a href="#apis-everywhere" id="apis-everywhere"></a>

MWRAE Portal includes REST and GraphQL APIs for user management, Site pages and experience, languages, permissions, structured content, and more.

#### OAuth2 Enhancements <a href="#oauth2-enhancements" id="oauth2-enhancements"></a>

You can configure registered OAuth 2 applications as trusted applications to avoid manual authorization when obtaining a token.

You can also register OAuth 2 applications so users can have their devices remember their manual authorization (i.e., “remember me”).

You can now revoke all existing authorizations of a registered OAuth 2 application with a single click at the OAuth 2 applications’ list screen.

#### FIDO2 Based Hardware Key Factor Support in Multi-Factor-Authentication <a href="#fido2-based-hardware-key-factor-support-in-multi-factor-authentication" id="fido2-based-hardware-key-factor-support-in-multi-factor-authentication"></a>

Users can now use the built in multi-factor authentication to leverage common devices (fingerprint readers, USB keys) to authenticate to online services in both mobile and desktop environments.

#### Better Data Management in and Maintenance of SAML <a href="#better-data-management-in-and-maintenance-of-saml" id="better-data-management-in-and-maintenance-of-saml"></a>

Improved attribute mapping user experience gives better control to model the scope and tracking of identifiers used for matching SP users. Changing users’ `emailAddress` on the IDP side is not a problem anymore. Custom field mapping became an option also.

There is also a full backwards compatibility: the existing behavior is maintained until you re-configure the SAML integration, and we do not use the SP user’s UUID field for any other than the user’s purpose for it.

#### Click to Chat Integration <a href="#click-to-chat-integration" id="click-to-chat-integration"></a>

An out-of-the-box integration with a number of chat platforms is available. Enabling the integration under Instance Settings enables users to chat with representatives at their own convenience. Please note that a separate subscription with the chat provider is required. The following chat providers are available for OOTB integration:

* Chatwoot
* Crisp
* Hubspot
* JivoChat
* LiveChat
* LivePerson
* Smartsupp
* Tawk.to
* Tidio
* Zendesk

#### DocuSign Integration <a href="#docusign-integration" id="docusign-integration"></a>

An out-of-the-box integration with DocuSign is available. Enabling the integration under Instance Settings enables users to send Digital Signature Envelopes with documents to DocuSign from Documents and Media and the Digital Signature module in the Control Panel. Users can view previously sent Digital Signature Envelopes to see their status and download signed documents. A separate subscription with DocuSign is required.
