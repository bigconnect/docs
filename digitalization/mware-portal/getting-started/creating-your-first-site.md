# Creating Your First Site

Sites are collections of pages that contain and display content. This article walks through creating a new Site based on an existing out-of-the-box template.

### Creating a Site <a href="#creating-a-site" id="creating-a-site"></a>

To create a new Community Site, follow these steps:

1.  Open the _Global Menu_ and navigate to the _Control Panel_ and select _Sites_.

    ![Select Sites from the Control Panel.](https://resources.learn.liferay.com/images/dxp/latest/en/getting-started/creating-your-first-site/images/01.png)
2. Click the Add icon (![Add Icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-add.png)) at the top right of the page.
3.  Select the _Community Site_ Template. The Site Template you choose determines what default pages and applications the new Site is populated with.

    ![Select a Site Template.](https://resources.learn.liferay.com/images/dxp/latest/en/getting-started/creating-your-first-site/images/02.png)
4. Enter a name for the Site.
5. Click _Save_.

A new Site is created and ready for use with two pages: _Home_ and _Wiki_. Each page has several applications already deployed that you may begin exploring.

Users are presented a variety of Site Settings options to further configure their new Site. Click to learn more about Site Settings.

### Viewing the Site <a href="#viewing-the-site" id="viewing-the-site"></a>

To view a newly created Site:

1.  Verify that the Site selector shows the name of the _Community Site_ you created. Otherwise, click on the compass icon (![compass icon](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-compass.png)) to select the new Site.

    ![The Site selector in the Site Menu should display the new Site's name](https://resources.learn.liferay.com/images/dxp/latest/en/getting-started/creating-your-first-site/images/03.png)
2. Click _Home_ beneath the Site selector.

You are taken to the Site’s _Home_ page.

![Community Site - Home Page](https://resources.learn.liferay.com/images/dxp/latest/en/getting-started/creating-your-first-site/images/04.png)
