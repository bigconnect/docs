# Navigating the Portal

The Portal’s out-of-the-box navigation is organized into three major areas: _Site Menu_, _Personal Menu_, and _Global Menu_.

### Site Menu <a href="#site-menu" id="site-menu"></a>

The Portal _Site Menu_ on the left side of the screen contains actions, content, and configurations that are scoped to the specific site currently being viewed. You can click on the _Site Menu_ (![Site Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-menu.png)) in the application bar to expand or hide it.

![Expand the site menu so that all options are visible.](https://resources.learn.liferay.com/images/dxp/latest/en/getting-started/navigating-dxp/images/01.png)

The site menu indicates the selected site. You can change what site you are working with by clicking the _Compass_ (![Compass](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-compass.png)) in the site menu.

These are some common site building and management activities that can be done in the site menu:

* Adding pages
* Creating content
* Managing site memberships
* Configuring and optimizing site behavior and functionality

### Applications Bar <a href="#applications-bar" id="applications-bar"></a>

The _Application Bar_ appears at the top of each page and Site Menu application. The application bar shows an Actions menu (![Actions](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-actions.png)) with different options depending on the application that is currently open.

![The actions available in the application bar depend on the application open at the moment.](https://resources.learn.liferay.com/images/dxp/latest/en/getting-started/navigating-dxp/images/02.png)

When you open a page in view mode, the available tools in the application bar change depending on the page type.

![Content pages and widget pages show a different set of tools in the application bar.](https://resources.learn.liferay.com/images/dxp/latest/en/getting-started/navigating-dxp/images/03.png)

### Personal Menu <a href="#personal-menu" id="personal-menu"></a>

The _Personal Menu_ is the hub for information and activities for a user that is logged in.

![](https://resources.learn.liferay.com/images/dxp/latest/en/getting-started/navigating-dxp/images/04.png)

These are several common actions that users can perform from the personal menu:

* Change account information
* See what sites they are members of
* Review site notifications
* Sign out

### Global Menu <a href="#global-menu" id="global-menu"></a>

The _Global Menu_ contains the Applications, Commerce, and Control Panel menus. Click the _Global Menu_ (![Global Menu](https://resources.learn.liferay.com/images/dxp/latest/en/images/icon-applications-menu.png)) at the top right corner of the screen to access it.

**NOTE**

By default, users with the _Guest_ or _User_ roles are not able to access the global menu.

You can also navigate to other sites available to you from either the Applications, Commerce, or Control Panel tabs in the global menu, on the right side of the interface.

#### Applications Menu <a href="#applications-menu" id="applications-menu"></a>

The _Applications Menu_ contains a variety of links to manage many different applications within your Portal server.

![The applications menu contains many global settings and important functions applicable to all sites.](https://resources.learn.liferay.com/images/dxp/latest/en/getting-started/navigating-dxp/images/05.png)

Here are some of the applications that can be managed from the applications menu:

* Content Dashboard
* Workflow
* Remote Apps

#### Commerce Menu <a href="#commerce-menu" id="commerce-menu"></a>

![The Commerce Menu contains all store functions.](https://resources.learn.liferay.com/images/dxp/latest/en/getting-started/navigating-dxp/images/06.png)

Here are some functions that can be managed from Commerce:

* Creating a New Catalog
* Creating a New Channel
* Manage Inventory
* Process Orders

#### Control Panel <a href="#control-panel" id="control-panel"></a>

The _Control Panel_ contains general administrative actions and configurations that can be scoped globally to the Portal installation or to a particular instance.

![The control panel is now part of the global menu.](https://resources.learn.liferay.com/images/dxp/latest/en/getting-started/navigating-dxp/images/07.png)

Here are some common administrative activities that can be done in the control panel:

* Manage users, permissions, and roles
* Change how users login
* Create new sites
* Add new custom fields to applications on the site
