# Verify the HDFS components

**Steps**

1. Browse to **Ambari Web UI &gt; Services &gt; HDFS**. 
2. Check the Summary panel and ensure that the first three lines look like this:

   * NameNode
   * SNameNode
   * DataNodes 

   You should _not_ see a line for JournalNodes.

**After you finish**  
Start HDFS service.
