# View service summary

Use **Services &gt; Summary** to view the status of service components and metrics.

**About this task**  
In Ambari Web, the **Services &gt; Summary** pane displays basic information about the operational status of that service, including any current alerts.

**Steps**

1. In **Ambari Web**, click a service name from the list of displayed services. In **Summary**, basic information about the operational status of that service, including any alerts displays. ![](https://docs.cloudera.com/HDPDocuments/Ambari-2.7.3.0/managing-and-monitoring-ambari/reuse-library/images/amb_services_summary.png) 
2. In **Ambari Web**, click a different service name from the list of displayed services.  
   **Summary** refreshes to display information about the different service.  
  
   After you finish  
    click one of the **View Host** links.  
   ![](https://docs.cloudera.com/HDPDocuments/Ambari-2.7.3.0/managing-and-monitoring-ambari/how-to/images/amb_view_hosts_links.png)  


   to view components and the host FQDN on which the selected service is running.
