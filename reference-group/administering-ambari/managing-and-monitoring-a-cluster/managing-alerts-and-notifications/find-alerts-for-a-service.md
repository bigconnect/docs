# Find alerts for a service

A service with current alerts displays red, numbered indicators next to the service name, and on the service's **Summary** page.

**About this task**  
The **Summary** tab provides access to all alerts and their status for the selected service. Critical alerts cause a red indicator to display on **Summary**.  
![](https://docs.cloudera.com/HDPDocuments/Ambari-2.7.3.0/managing-and-monitoring-ambari/how-to/images/amb_service_alert_open.png)

**Steps**

1. For a service, in **Summary**, click the bell icon next to the alert indicator. For example, in **Services &gt; HDFS** click the bell icon. Alerts for HDFS opens. ![](https://docs.cloudera.com/HDPDocuments/Ambari-2.7.3.0/managing-and-monitoring-ambari/how-to/images/amb_alerts_hdfs.png) 
2. Click the text title of each alert message in the list to see the alert definition.

**After you finish**  
Modify the alert definition, if necessary.
