# Move files or folders within your file system

You can move files or folders within your HDFS file system.

**Before you begin**  
Ensure that you have the necessary folder permissions to move files from a source to a target directory within your HDFS file system.

**Steps**

1. In the Ambari dashboard, browse to **Views &gt; Files View**. 
2. Select a file or a folder that you want to move, and then click **Move**.  ![file view move](https://docs.cloudera.com/HDPDocuments/Ambari-2.7.3.0/using-ambari-views/how-to/images/amb_file_view_move.png)  The **Move to** window appears. 
3. Select a destination folder, and then click **Move**.
