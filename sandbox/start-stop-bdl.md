# Start/Stop Services

## Starting Services

1.Login as the **bdl** user

2. Start BDL services:

```text
/opt/bdl/sbin/start-infra.sh
```

3.Start BDL apps:

```text
/opt/bdl/sbin/start-apps.sh
```

## Stopping Services

1.Login as the **bdl** user

2. Stop BDL apps:

```text
/opt/bdl/sbin/stop-apps.sh
```

3. Stop BDL infra:

```text
/opt/bdl/sbin/stop-infra.sh
```
