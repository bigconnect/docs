# Sandbox

The Sandbox is a straightforward, pre-configured, learning environment that contains the latest developments from BigConnect Data Lake. The Sandbox comes packaged as a tgz file that can be deployed in the cloud or on your personal machine. 

The Sandbox allows you to learn and explore BDL on your own. It includes the following components:

* BigConnect Explorer
* BigConnect Discovery
* BigConnect Cypher Lab
* Jupyter Notebook
* Data Collector
* HDFS, YARN
* Accumulo
* Hive
* Druid
* Presto
* Kafka
* Elasticsearch
* Spark
* ZooKeeper
