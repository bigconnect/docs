# Stop all services

**About this task**  
In **Ambari Web &gt; Services** you can stop all listed services simultaneously.In Services, click ... and then click **Stop All**.  
  
![](https://docs.cloudera.com/HDPDocuments/Ambari-2.7.3.0/managing-high-availability/how-to/images/amb_services_stop_all.png)  
  
All listed services stop.

**After you finish**  
Prepare the Ambari server host for NameNode rollback.
