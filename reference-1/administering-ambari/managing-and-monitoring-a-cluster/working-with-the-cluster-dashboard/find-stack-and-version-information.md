# Find  stack and version information

Use the **Stack and Versions** tabs add services to the stack, and register new version information before performing an upgrade.

The **Stack** tab includes information about the services installed and available in the cluster stack. The **Versions** tab includes information about which versions of software are currently installed and running in the cluster.

1.In Ambari Web, browse to **Cluster Admin &gt; Stack and Versions**

2.Click **Stack** to browse all services installed in your current stack.

3.As an Ambari administrator you can click **Add Service** to start the wizard that installs each service into your cluster.

4.Click **Versions** to see specific version information about each service.
