# Decommission a NodeManager

Use **Ambari Web &gt; Hosts &gt; Actions** to decommission a NodeManager component.  
  
**Steps**

1. Using Ambari Web, browse the Hosts page. ****
2. Find and click the FQDN of the host on which the NodeManager component resides. 
3. Using the **Actions** menu, click **Selected Hosts &gt; NodeManagers &gt; Decommission.** ![](https://docs.cloudera.com/HDPDocuments/Ambari-2.7.3.0/managing-and-monitoring-ambari/how-to/images/amb_decommission_dnode.png) The UI shows Decommissioning status while in process.

**Result**  
When this NodeManager decommissioning process is finished, the Action option shows Recommission.  
![](https://docs.cloudera.com/HDPDocuments/Ambari-2.7.3.0/managing-and-monitoring-ambari/how-to/images/amb_recomission_component.png)
