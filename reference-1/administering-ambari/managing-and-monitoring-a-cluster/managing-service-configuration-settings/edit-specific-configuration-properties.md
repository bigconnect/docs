# Edit specific configuration properties

Use **Configs &gt; Advanced** for each service to access groups of individual properties that affect performance of that service.

**Steps**

1. For a service, click **Configs &gt; Advanced**, and expand a category. 
2. Edit the value for any property. Edited values, also called _stale configs_, show an Undo option. 
3. Click **Save**. 
4. Enter a description for this configuration version that includes your current changes. 
5. Review and confirm each recommended change.

**After you finish**  
Restart all affected services.
