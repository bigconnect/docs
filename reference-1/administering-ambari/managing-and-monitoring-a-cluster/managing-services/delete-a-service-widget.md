# Delete a service widget

Use the **Widget Browser** or the edit widget icon options to delete service widgets from a service **Metrics** tab.

**About this task**  
The **Widget Browser** displays the widgets available to add to your **Metrics** tab, widgets already added to your dashboard, shared widgets, and widgets you have created. Multiple users can view widgets identified by the **Shared** icon.   
**The Widget Browser** also supports creating and deleting new service widgets.

**Steps**

1. On the **Metrics** tab, either click **+** to launch the **Widget Browser**, or click **Metrics &gt; Actions &gt; Create Widget**. The **Widget Browser** displays all current service widgets. ![](https://docs.cloudera.com/HDPDocuments/Ambari-2.7.3.0/managing-and-monitoring-ambari/how-to/images/amb_widget_browser.png) 
2. In the **Widget Browser**, click a green, Added checkmark for any widget that displays one. This removes the widget from the **Metrics** tab. This does not delete the widget from the **Widget Browser**.The widget disappears from the the **Metrics** tab and no longer shows a green, Added checkmark in the **Widget Browser**. 
3. Only for a widget that you created, you can click **More... &gt; Delete**. For a shared widget, only an Ambari Admin or Cluster Operator has the **Delete** option. Deleting a shared widget removes the widget from all users. Deleting a shared widget cannot be undone. The widget disappears from the **Widget Browser**.

**After you finish**  
 To remove a widget from the **Metrics** tab, click the edit widget icon ![](https://docs.cloudera.com/HDPDocuments/Ambari-2.7.3.0/managing-and-monitoring-ambari/how-to/images/amb_edit_widget_icon.png), then click **Delete**.
