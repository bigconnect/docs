# Using the Map

BigConnext Explorer provides a map tool for visualising data that has spatial information associated \(latitude and longitude\).

There is a special property predefined in the system named **Geolocation**. This is a pair of latitude and longitude in the WGS84 Coordinate Reference System. If an item has the Geolocation property set, it can be displayed on the map.

There are numerous ways to get data onto the map:

* Copy & Paste search results from the search page
* Copy & Paste items from another Graph or Map
* Load all elements from a saved search

![](../../.gitbook/assets/image%20%28284%29.png)

All items added on the map are automatically clustered based on the zoom level. 

You can change the type of cluster by choosing Layers from the toolbar and selecting Heatmap for example.

{% hint style="info" %}
You can add layers from existing online or GIS systems that are WMS/WFS compatible.
{% endhint %}
