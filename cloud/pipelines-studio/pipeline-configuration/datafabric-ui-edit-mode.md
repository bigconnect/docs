# Data Pipelines Studio - Edit Mode

The following image shows the Data Pipelines Studio when you configure a pipeline:

![](<../../../.gitbook/assets/image (237).png>)

| AREA / ICON                                                                                                                        | NAME                       | DESCRIPTION                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ---------------------------------------------------------------------------------------------------------------------------------- | -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1                                                                                                                                  | Pipeline canvas            | Displays the pipeline. Use to configure the pipeline data flow.                                                                                                                                                                                                                                                                                                                                                                                      |
| 2                                                                                                                                  | Pipeline Creation Help Bar | <p>Offers lists of stages to help complete the pipeline.</p><p>You can use the help bar to connect a stage to an open node. You can also add a stage between linked stages by clicking the link.</p>                                                                                                                                                                                                                                                 |
| 3                                                                                                                                  | Stage list                 | Lists the stages in the pipeline. Use to select a stage to configure. You can also select the stage in the canvas.                                                                                                                                                                                                                                                                                                                                   |
| 4                                                                                                                                  | Properties panel           | Displays the properties of the pipeline or selected stage when you configure a pipeline.                                                                                                                                                                                                                                                                                                                                                             |
| 5                                                                                                                                  | Stage library panel        | <p>List of available stages. Use to add stages to the pipeline. You can drag a stage to a location on canvas or click a stage to add it to the end of the pipeline.</p><p>You can view all stages, stages by type, or stages by library. You can also search for a stage by name.</p>                                                                                                                                                                |

| ![](https://streamsets.com/documentation/datacollector/latest/help/datacollector/UserGuide/Graphics/icon\_MonAlert.png)            | Notifications icon         | Displays notifications.                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ![](https://streamsets.com/documentation/datacollector/latest/help/datacollector/UserGuide/Graphics/icon\_OverAdministration.png)  | Administration icon        | Provides access to Data Pipelines Studio configuration properties, directories, and log.                                                                                                                                                                                                                                                                                                                                                             |
| ![](https://streamsets.com/documentation/datacollector/latest/help/datacollector/UserGuide/Graphics/icon\_OverUser.png)            | User icon                  | Displays the active user and the roles assigned to the user. | ![](https://streamsets.com/documentation/datacollector/latest/help/datacollector/UserGuide/Graphics/icon\_PipelineList.png)        | Link to a pipeline list    | Link to a pipeline list on the Home page. | ![](https://streamsets.com/documentation/datacollector/latest/help/datacollector/UserGuide/Graphics/icon\_ConfigMore.png)          | More icon                  | Provides additional actions for the pipeline. Or to view or delete snapshot data.                                                                                                                                                                                                                                                                                                                          |

On Windows, you can use Ctrl+Z.                                                                                                                                                                                                                                                                                                                                                          |
| ![](https://streamsets.com/documentation/datacollector/latest/help/datacollector/UserGuide/Graphics/icon\_ConfigRedo.png)          | Redo icon                  | Restores changes that were reverted. On Windows, you can use Ctrl+Y.                                                                                                                                                                                                                                                                                                                                       |
| ![](https://streamsets.com/documentation/datacollector/latest/help/datacollector/UserGuide/Graphics/icon\_ConfigDelete.png)        | Delete icon                | Deletes the selected stage or link.                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ![](https://streamsets.com/documentation/datacollector/latest/help/datacollector/UserGuide/Graphics/icon\_ConfigCopy.png)          | Duplicate Stage icon       | <p>Duplicates the selected stage. Because a pipeline can include only one origin, you cannot duplicate an origin stage.</p><p>You can also use keyboard shortcuts to copy and paste the selected stage, i.e. Ctrl+C and Ctrl+V for Windows and Command+C and Command+V for Macintosh.</p><p>Stages can be copied and pasted to other pipelines only if the pipelines are in the same browser tab.</p> |
| ![](https://streamsets.com/documentation/datacollector/latest/help/datacollector/UserGuide/Graphics/icon\_ConfigArrange.png)       | Auto Arrange icon          | Arranges the stages in the pipeline.                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ![](https://streamsets.com/documentation/datacollector/latest/help/datacollector/UserGuide/Graphics/icon\_ConfigDataPreview.png)   | Preview icon               | Starts a data preview.                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ![](https://streamsets.com/documentation/datacollector/latest/help/datacollector/UserGuide/Graphics/icon\_ConfigValidate.png)      | Validate icon              | Validates the pipeline. | ![](https://streamsets.com/documentation/datacollector/latest/help/datacollector/UserGuide/Graphics/icon-Share.png)                | Share icon                 | Shares the pipeline with users and groups. | ![](https://streamsets.com/documentation/datacollector/latest/help/datacollector/UserGuide/Graphics/icon\_ConfigStartPipeline.png) | Start icon                 | Starts the pipeline.                                                                                                                                                                                                                                                                                                                                                                                                                                 |

| ![](https://streamsets.com/documentation/datacollector/latest/help/datacollector/UserGuide/Graphics/icon\_ConfigMaximize.png)      | Maximize Pane icon         | Maximizes the configuration panel.                                                                                                                                                                                                                                                                                                                                                                                                                   |

{% hint style="info" %}
Some icons and options might not display. The items that display are based on the task that you are performing and roles assigned to your user account.

For example, the Copy icon displays only when you select stage that can be copied, it does not display when you select a link or an origin. Or, if you log in with the Manager role, most configuration-related icons are not available.
{% endhint %}
