# Configuring BigConnect Pipelines

You can customize BigConnect Pipelines by editing the BigConnect Pipelines configuration file, `sdc.properties`.

Use a text editor to edit the BigConnect Pipelines configuration file, `$SDC_CONF/sdc.properties`. To enable the changes, restart BigConnect Pipelines.

**Important**: Instead of entering sensitive data such as passwords in clear text in the configuration file, you can protect the sensitive data by storing the data in an external location and then using functions to retrieve the data.\
\

The BigConnect Pipelines configuration file includes properties with a "java.security." prefix which you can use to configure Java security properties. Do not modify the Java security properties when running multiple BigConnect Pipelines instances within the same JVM.

The BigConnect Pipelines configuration file includes Security Manager properties that allow you to enable the BigConnect Pipelines Security Manager for enhanced security. The BigConnect Pipelines Security Manager does not allow stages to access files in BigConnect Pipelines configuration, data, and resource directories.

By default, BigConnect Pipelines uses the Java Security Manager that allows stages to access files in all BigConnect Pipelines directories.

The BigConnect Pipelines configuration file includes record sampling properties that indicate the size of the sample set chosen from a total population of records.BigConnect Pipelines uses the sampling properties when you run a pipeline that writes to a destination system using the SDC Record data format and then run another pipeline that reads from that same system using the SDC Record data format. BigConnect Pipelines uses record sampling to calculate the time that a record stays in the intermediate destination.

By default, BigConnect Pipelines uses 1 out of 10,000 records for sampling. If you modify the sampling size, simplify the fraction for better performance. For example, configure the sampling size as 1/40 records instead of 250/10000 records. The following properties specify the sampling size:

| Record Sampling Property            | Description                                                          |
| ----------------------------------- | -------------------------------------------------------------------- |
| sdc.record.sampling.sample.size     | <p>Size of the sample set.</p><p>Default is 1.</p>                   |
| sdc.record.sampling.population.size | <p>Size of the total number of records.</p><p>Default is 10,000.</p> |

The BigConnect Pipelines configuration file includes properties that define how BigConnect Pipelines caches pipeline states. BigConnect Pipelines can cache the state of pipelines for faster retrieval of those states in the Home page. If BigConnect Pipelines does not cache pipeline states, it must retrieve pipeline states from the pipeline data files stored in the `$SDC_DATA` directory. You can configure the following properties that specify how BigConnect Pipelines caches pipeline states:

| Pipeline State Cache Property                  | Description                                                                                                                                                                                               |
| ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| store.pipeline.state.cache.maximum.size        | <p>Maximum number of pipeline states that BigConnect Pipelines caches. When the maximum number is reached, BigConnect Pipelines evicts the oldest states from the cache.<br></p><p>Default is 100.</p>    |
| store.pipeline.state.cache.expire.after.access | <p>Amount of time in minutes that a pipeline state can remain in the cache after the entry's creation, the most recent replacement of its value, or its last access.<br></p><p>Default is 10 minutes.</p> |
