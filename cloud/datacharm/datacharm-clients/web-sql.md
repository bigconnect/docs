# Web SQL Editor

DataCharm provides a graphical SQL editor to run queries against a DataCharm instance. 

The editor can be found in your [Cloud Console](https://console.cloud.bigconnect.io), under the DataCharm service.

![](../../../.gitbook/assets/image%20%28646%29.png)

The first time you open the SQL editor, you will need to authenticate against your DataCharm instance to start executing SQL queries.
