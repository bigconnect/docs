# Download and Installation

This topic describes how to download and install **osscli**.

### Download URLs

* [Linux x86 64-bit](http://bits.bigconnect.io/cloud/osscli/osscli64)
* [Linux x86 32-bit](http://bits.bigconnect.io/cloud/osscli/osscli32)
* [Linux PPC 64-bit](http://bits.bigconnect.io/cloud/osscli/ossclippc64)
* [Linux ARM 32-bit](http://bits.bigconnect.io/cloud/osscli/osscliarm32)
* [Linux ARM 64-bit](http://bits.bigconnect.io/cloud/osscli/osscliarm64)
* [FreeBSD x86 64-bit](http://bits.bigconnect.io/cloud/osscli/ossclibsd64)
* [FreeBSD x86 32-bit](http://bits.bigconnect.io/cloud/osscli/ossclibsd32)
* [Windows x86 64-bit](http://bits.bigconnect.io/cloud/osscli/osscli64.exe)
* [Windows x86 32-bit](http://bits.bigconnect.io/cloud/osscli/osscli32.exe)
* [MacOS x86 64-bit](http://bits.bigconnect.io/cloud/osscli/ossclimac64)

### Installation

Download the package based on your operating system and run the corresponding binary file.
