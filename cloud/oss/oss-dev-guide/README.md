# Developer Guide

Application developers can develop applications against OSS using the MinIO SDKs:

* [JavaScript SDK](oss-js-sdk.md)
* [Java SDK](oss-java-sdk-quickstart.md)
* [Python SDK](oss-python-sdk-quickstart.md)
* [.NET SDK](oss-dotnet-sdk-quickstart.md)

For instructions, quick-start guides and examples, please visit each SDK.
