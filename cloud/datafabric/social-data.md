# Social Network Data

BigConnect has data extractors for Social Networks as well. Extraction can be made either using publicly available information or by authenticating in the respective social network.

{% hint style="warning" %}
Social Network data should be extracted in accordance with each platform's Terms and Conditions.

Plase be aware that massive scraping of data from some platforms \(eg. Facebook\) might get your account blocked or even have the platform engage in legal actions.
{% endhint %}

### Facebook

The following information can be collected from Facebook:

* Pages
* Groups
* Users
* Posts \(with all associated data eg. hashtags, links, images etc.\)
* Reactions
* Comments

### Instagram

The following information can be collected from Instagram:

* Media items
* Users
* Posts \(with all associated data eg. hashtags, links, images etc.\)
* Stories
* Reactions
* Comments

### Twitter

The following information can be collected from Twitter:

* Tweets \(hashtags, links, images etc.\)
* Users
* Reactions
* Comments

### VKontakte

The following information can be collected from VKontakte:

* Posts \(hashtags, links, images etc.\)
* Communities
* Users
* Reactions
* Comments

### TikTok

The following information can be collected from TikTok:

* Posts
* Users
* Reactions
* Comments
