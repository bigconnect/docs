# DataFabric

Pipelines is a central point of control for all of your dataflow pipelines. It allows teams to build and execute large numbers of complex dataflows at scale.

Teams of data engineers use the shared pipeline repository provided with the Pipelines service to collaboratively build pipelines. The pipeline repository also includes pre-built pipelines for [social network crawling](social-data.md) and [data workers](data-workers.md).

Once deployed, the Pipelines service is available at `https://pipelines-NNNNNNN.cloud.bigconnect.io/dashboard` 

When logging in the Pipelines you are presented with the main dashboard where you can see manage the deployed pipelines.
