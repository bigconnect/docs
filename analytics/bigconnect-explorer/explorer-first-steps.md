# Explorer First Steps

If you are using the default installation you can introduce any username and click the "Log In" button. There is no security configured yet. 

This will bring you to the welcome page called **Dashboard**.

![](../../.gitbook/assets/image%20%2889%29.png)

The first thing you need to do is load some data. The easiest way to do it is to drag & drop some documents. Go to the **Analyze** tab and create a **Graph** tool. After that drop some documents and you should be ready to go.
