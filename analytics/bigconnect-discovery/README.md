# BigConnect Discovery

BigConnect Discovery is a solution that analyzes data ingested into the Druid server cluster in a simple, sophisticated manner, and visualizes the results in the user PC in the form of charts and reports. A web-based application, it is highly accessible such that it can be remotely accessed by from any PC.

This section introduces the technical background and structure of BigConnect Discovery, and the Druid engine powering it.
