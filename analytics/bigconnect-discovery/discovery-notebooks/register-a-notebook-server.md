# Register a notebook server

To analyze data in a workspace using a notebook, initial settings are required for the notebook server. The procedure for initial settings for a notebook server is as follows:

1. ![icon\_more](https://metatron-app.github.io/metatron-doc-discovery/en/_images/icon_more.png)Click the button in the upper right corner of the workspace and select Notebook Server Settings .

   ![Setting Up a Notebook Server from the Workspace Administration Home Screen](https://metatron-app.github.io/metatron-doc-discovery/en/_images/register_a_notebook_server_01.en.png)

2. From the list of Jupyter and Zeppelin servers registered in advance by the administrator, select the notebook server you want to connect and use in your workspace and click the Finish button.

* If you do not want to select any server, select the **\(none\)** item.
