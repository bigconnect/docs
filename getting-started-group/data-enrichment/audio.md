# Audio

The following data workers are available for extracting information from videos:

* Metadata
* Speech Recognition

## Metadata extractor

This data worker receives an image and extracts all available metadata from the audio file:

* Codecs
* Duration
* Author
* etc.

## Speech Recognition

This data worker receives an audio file, performs speech recognition and returns the extracted text for further processing by other data workers.

## Speaker Identification

This data worker receives an audio file and return the identified Speaker ID
