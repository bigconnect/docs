# App Server Documentation

Documentation of MWARE App Server features includes full documentation of the features added on top of _GlassFish Server 5 Open Source Edition_ as well as features shared with GlassFish Server or their improvements specific to MWARE App Server.

All documentation for _GlassFish Server 5_ is also valid for MWARE App Server 6.2023.10 unless stated otherwise in the MWARE App Server documentation.
