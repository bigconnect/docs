# People

User accounts, groups, and authentication. For permissions, see Permissions overview.

### Editing your account settings <a href="#editing-your-account-settings" id="editing-your-account-settings"></a>

Edit your profile and password, and view your login history.

### Managing people and groups <a href="#managing-people-and-groups" id="managing-people-and-groups"></a>

Admin controls for setting up user accounts and organizing them into groups.

### Changing password complexity <a href="#changing-password-complexity" id="changing-password-complexity"></a>

Make people use longer and more complex passwords.

### Changing session expiration <a href="#changing-session-expiration" id="changing-session-expiration"></a>

Tell Answers how long it should wait before asking people to log in again.

### Authentication

Answers offers several options for single sign-on (SSO) authentication.

* Google Sign-in
* LDAP
* JWT
* LDAP advanced features
  * Group membership filter
  * Syncing user attributes
* SAML
  * Auth0
  * Azure AD
  * Google
  * Keycloak
  * Okta
