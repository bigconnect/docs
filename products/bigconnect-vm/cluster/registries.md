# Registries

**Registries** lets you manage access to each of the registries that are currently available.&#x20;

{% hint style="warning" %}
Registry access assigned here only applies to the selected environment. It is not global.
{% endhint %}

## Adding a new registry

From the menu select **Swarm**, select **Registries** then click **Add registry**.&#x20;

## Managing access

To configure access to a registry, from the menu select **Swarm** then select **Registries**. Find the registry you want to manage then select **Manage access**.&#x20;

![](<../../../.gitbook/assets/image (777).png>)

From the dropdown, select the users or teams that you would like to have access then click **Create access**.

![](<../../../.gitbook/assets/image (737).png>)
