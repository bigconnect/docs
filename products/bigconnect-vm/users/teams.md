# Teams

Use teams to control user access to environments, container and service enablement, and volume control.

## Add a new team

From the menu select **Users** then select **Teams**.  Enter the name of the team and optionally select a team leader. Team leaders can add and remove existing users to and from their team, as well as promote existing team members to co-team leaders.

{% hint style="warning" %}
If your BigConnect VM installation uses external authentication and teams are synced from your external authentication provider, the team leader role is disabled.
{% endhint %}

![](<../../../.gitbook/assets/image (709).png>)

When you're ready, click **Create team**.

## Add a user to a team

From the menu select **Users** then select **Teams**.  Select the team you want to add users to then click **Add** next to the user.
