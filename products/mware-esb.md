# MWARE ESB

MWARE ESB is a is a fully open-source API management solution built on the WSO2 API Manager platform. It supports API designing, API publishing, lifecycle management, application development, API security, rate limiting, viewing statistics of APIs, as well as connecting APIs, API Products, and endpoints.

The MWARE ESB product documentation has been moved to [https://esb-docs.m-ware.eu](https://esb-docs.m-ware.eu)
