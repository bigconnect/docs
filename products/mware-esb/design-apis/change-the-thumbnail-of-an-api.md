# Change the Thumbnail of an API

The thumbnail of an API can be changed by uploading an image for the thumbnail or by designing a new thumbnail image via the Publisher.

## Upload new API thumbnail <a href="#upload-new-api-thumbnail" id="upload-new-api-thumbnail"></a>

1.  Sign in to API Publisher and click on the API that you want to change the thumbnail.&#x20;

    <figure><img src="https://apim.docs.wso2.com/en/4.2.0/assets/img/learn/change-thumbnail-api-publisher-view.png" alt=""><figcaption></figcaption></figure>
2.  Click **Basic Info** and click the API Thumbnail image.&#x20;

    <figure><img src="https://apim.docs.wso2.com/en/4.2.0/assets/img/learn/change-thumbnail-click-on-thumbnail.png" alt=""><figcaption></figcaption></figure>
3.  Click **Upload** and click on the Drop Zone to select an image for the thumbnail.&#x20;

    <figure><img src="https://apim.docs.wso2.com/en/4.2.0/assets/img/learn/change-thumbnail-click-upload.png" alt=""><figcaption></figcaption></figure>
4.  Click **Upload** to save the newly uploaded thumbnail.&#x20;

    The newly added image appears as the API thumbnail.

    ![](https://apim.docs.wso2.com/en/4.2.0/assets/img/learn/change-thumbnail-api-updated.png)

    <figure><img src="https://apim.docs.wso2.com/en/4.2.0/assets/img/learn/change-thumbnail-image-click-upload.png" alt=""><figcaption></figcaption></figure>

## Design a new API Thumbnail <a href="#design-a-new-api-thumbnail" id="design-a-new-api-thumbnail"></a>

1. Follow [steps 1 - 3 under Upload new API thumbnail](https://apim.docs.wso2.com/en/latest/design/create-api/change-api-thumbnail/#Upload-new-API-thumbnail).
2.  Click **Design**.&#x20;

    <figure><img src="https://apim.docs.wso2.com/en/4.2.0/assets/img/learn/change-thumbnail-design.png" alt=""><figcaption></figcaption></figure>
3. Select an icon, color, and background for the thumbnail.
   *   **Category**

       Select the icon category. Currently, the API Publisher supports the following categories.

       <div align="left">

       <img src="https://apim.docs.wso2.com/en/4.2.0/assets/img/learn/change-thumbnail-icon-types.png" alt="" height="300">

       </div>
   *   **Icon Color**

       Select the icon color from the color picker.

       <div align="left">

       <img src="https://apim.docs.wso2.com/en/4.2.0/assets/img/learn/change-thumbnail-select-color.png" alt="" height="250">

       </div>
   *   **Background**

       Select the thumbnail background from the designs.

       ![](https://apim.docs.wso2.com/en/4.2.0/assets/img/learn/change-thumbnail-select-background.png)
4.  Click **SAVE** to save the thumbnail.&#x20;

    The designed thumbnail appears as the API thumbnail.

    ![](https://apim.docs.wso2.com/en/4.2.0/assets/img/learn/change-thumbnail-design-icon-changed.png)

    </div>
