# View Generated Documentation

Follow the instructions below to view the generated documentation to a REST API. This feature does not support other API types.

1.  Sign in to the API Publisher.

    `https://<hostname>:9443/publisher`
2.  Click on the API (e.g., `PizzaShackAPI 1.0.0` ) for which you want to view the documentation.

    ![Select API in API Publisher](https://apim.docs.wso2.com/en/4.2.0/assets/img/learn/select-api.png)
3. View the generated documentation.
   1.  Click **Documents** and click **View Document** under Generated Document.



       <figure><img src="https://apim.docs.wso2.com/en/4.2.0/assets/img/learn/view-generated-document.png" alt=""><figcaption></figcaption></figure>
   2.  A document will be generated from the swagger document.



       <figure><img src="https://apim.docs.wso2.com/en/4.2.0/assets/img/learn/generated-document.png" alt=""><figcaption></figcaption></figure>
