# Export Projects

With WSO2 Integration Studio, you can export projects from your workspace and later [import them](https://apim.docs.wso2.com/en/4.2.0/integrate/develop/importing-projects).

For example, consider the following [**Maven Multi Module** project](https://apim.docs.wso2.com/en/4.2.0/integrate/develop/create-integration-project) in your project explorer. This is a project solution that includes several project types.

![](https://apim.docs.wso2.com/en/4.2.0/assets/img/integrate/create\_project/proj\_explorer\_mmm\_proj\_2.png)

Follow the steps given below to export the project.

1.  Right-click the project and click **Export**.

    ![](https://apim.docs.wso2.com/en/4.2.0/assets/img/integrate/create\_project/export\_project\_option.png)
2.  In the **Export** wizard, open the **WSO2** folder as shown below.

    ![](https://apim.docs.wso2.com/en/4.2.0/assets/img/integrate/create\_project/export\_dialog\_1.png)
3.  You can choose to export the project as an **archive file** or as a **file system**. Select the required option from the list and click **Next**.

    | Projects Export as Archive File | Select this option to export the project as a ZIP archive.                       |
    | ------------------------------- | -------------------------------------------------------------------------------- |
    | Projects Export as File System  | Select this option to export the project folders without creating a ZIP archive. |
4.  In the next page, see that your root project folder is selected. Click **Browse** and give the path to the export location.

    Tip

    If you have other projects in your workspace, you can also select them if required.

    ![](https://apim.docs.wso2.com/en/4.2.0/assets/img/integrate/create\_project/export\_dialog\_2.png)
5. Click **Finish** to export the project.
