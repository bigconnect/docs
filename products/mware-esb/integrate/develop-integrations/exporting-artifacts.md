# Exporting Artifacts

Once you have [packaged your artifacts](https://apim.docs.wso2.com/en/4.2.0/integrate/develop/packaging-artifacts) into a composite application, you can export it into a CAR file (.car file):

1. Select the Composite Exporter module in the project explorer, right-click, and click **Export Composite Application Project** .\
   [![](https://apim.docs.wso2.com/en/4.2.0/assets/img/integrate/create\_project/export\_esb\_artifacts.jpg)](https://apim.docs.wso2.com/en/4.2.0/assets/img/integrate/create\_project/export\_esb\_artifacts.jpg)
2. In the dialog that opens, give a name for the CAR file, the destination where the file should be saved, and click **Next**.
3. You can select the artifacts that should be packaged in the CAR file.
4. Click **Finish** to generate the CAR file.
