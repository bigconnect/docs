# System Wide Settings

It can be hard to keep track of all the configuration interfaces. The Control Panel’s Configuration section houses a lot of the higher level (for example, system and instance scoped) configuration options. This section considers the configuration options dealing with the _System_ scope. Configuration at the system level affects all the Virtual Instances of the Portal in the system.

* System Settings is the primary location for system configuration.
* Server Administration contains some lower-level server configuration options, such as logging.

Get started by learning about System Settings.
