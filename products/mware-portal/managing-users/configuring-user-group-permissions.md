# Configuring User Group Permissions

Administrators commonly create User Groups so the group’s Users can take some specific action in a Site. This is done by assigning the permissions for that action to a Role, and then assigning that Role to the User Group. This grants the Role’s permissions to the User Group’s Users.

Follow these steps to grant permissions to Users in a User Group:

1. Create the User Group.
2. Assign the User Group to a Site.
3. Create the Site Role and define its permissions.
4. Assign the Role to the User Group.

For instructions on the first three steps, click those links above. This article shows you how to assign a Role to a User Group:

1. Open the Menu (![Menu](https://liferay-support.zendesk.com/hc/article\_attachments/360030157131/icon-menu.png)), select the Site to work in, then open its Site Administration menu.
2.  In the Site Administration menu, select _People_ → _Memberships_. This opens the Memberships screen.

    <img src="https://liferay-support.zendesk.com/hc/article_attachments/360030157091/site-memberships.png" alt="Figure 1: Select Memberships from the Site Administration menu." data-size="original">

    Figure 1: Select \*Memberships\* from the Site Administration menu.
3. In Memberships, select the _User Groups_ tab. This tab displays User Groups currently assigned to the Site.
4.  Click the _Actions_ button (![Actions](https://liferay-support.zendesk.com/hc/article\_attachments/360030157071/icon-actions.png)) for the User Group you want to assign to a Role, and select _Assign Site Roles_. This opens the Assign Site Roles dialog.

    <img src="https://liferay-support.zendesk.com/hc/article_attachments/360030157111/user-groups-site-role.png" alt="Figure 2: Select Assign Site Roles for the user group." data-size="original">

    Figure 2: Select \*Assign Site Roles\* for the user group.
5. In the Assign Site Roles dialog, select the Role from the list and click _Done_.
