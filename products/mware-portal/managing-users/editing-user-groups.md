# Editing User Groups

You can access User Groups from _Control Panel_ → _Users_ → _User Groups_. Managing membership is the most common action you’ll likely perform on a User Group.

![Figure 1: The user groups appear in a table.](https://liferay-support.zendesk.com/hc/article\_attachments/360030188052/user-groups-table.png)

Figure 1: The user groups appear in a table.

Follow these steps to add/remove users to/from a User Group:

1. Click the User Group’s name or description. Alternatively, you can click the User Group’s _Actions_ button (![Actions](https://liferay-support.zendesk.com/hc/article\_attachments/360030157151/icon-actions.png)) and select _Assign Members_. This presents a list of the User Group’s users.
2. To remove a User from the User Group, click the `X` button next to that User. To remove multiple Users at once, check each User’s checkbox and then click the trash icon (![Trash](https://liferay-support.zendesk.com/hc/article\_attachments/360030188032/icon-trash.png)) that appears in the Management Bar above the User list.
3. To add Users to the User Group, click the _Add_ button (![Add](https://liferay-support.zendesk.com/hc/article\_attachments/360030188072/icon-add.png)). In the dialog that appears, select the Users and click _Add_.

![Figure 2: The list of Users lets you manage the User Groups membership.](https://liferay-support.zendesk.com/hc/article\_attachments/360030188012/user-groups-users.png)

Figure 2: The list of Users lets you manage the User Group's membership.

Other options are available in each User Group’s Actions button (![Actions](https://liferay-support.zendesk.com/hc/article\_attachments/360030157151/icon-actions.png)):

**Edit:** Modify the User Group’s name or description, or choose Site templates to use for the User Group’s Sites.

**Permissions:** Assign permissions for viewing and managing the User Group.

**User Group Pages Permissions:** Assign permissions for managing the User Group’s Site pages.

**Manage Pages:** Manually manage the User Group’s Site pages. See the documentation on user group Sites for details.

**Assign Members:** Add/remove Users to/from the User Group. This is described in detail above.

**Delete:** Remove the User Group. Note that you can’t delete a User Group that contains Users. You must first remove the Users from the group.

If your User Group has public and private Site pages, the options _Go to Profile Pages_ and _Go to Dashboard Pages_ also appear in your User Group’s Actions menu. Clicking one of these links opens that Site in a new browser window. See the documentation on user group Sites for details.
