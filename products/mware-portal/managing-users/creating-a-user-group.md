# Creating a User Group

Follow these steps to create a user group:

1. Open the Menu (![Menu](https://liferay-support.zendesk.com/hc/article\_attachments/360030157031/icon-menu.png)) and select _Control Panel_ → _Users_ → _Users Groups_. Any existing user groups appear here in a table.
2. Click the _Add_ button (![Add](https://liferay-support.zendesk.com/hc/article\_attachments/360030157011/icon-add.png)). This opens the _New User Group_ form.
3. Give your user group a name and description.
4. If you want to create My Profile and/or My Dashboard pages for the user group’s members, select a Site Template to use from the _My Profile_ and _My Dashboard_ selector menus.
5. Click _Save_. The new user group then appears in the table.

Note that new User Groups don’t have any Users. The next section shows you how to add members to a user group.

![Figure 2: The user group you just created now appears in the table.](https://liferay-support.zendesk.com/hc/article\_attachments/360030156991/user-groups-table.png)

### Assigning Members to a User Group <a href="#assigning-members-to-a-user-group" id="assigning-members-to-a-user-group"></a>

Follow these steps to add existing users to a user group:

1. If you’re not already there, open the Menu (![Menu](https://liferay-support.zendesk.com/hc/article\_attachments/360030157031/icon-menu.png)) and select _Control Panel_ → _Users_ → _Users Groups_. The available user groups appear here in a table.
2. Click _Actions_ (![Actions](https://liferay-support.zendesk.com/hc/article\_attachments/360030187792/icon-actions.png)) → _Assign Members_ for the user group you want to add users to. The group’s existing users appear in a table.
3. Click the _Add_ button (![Add](https://liferay-support.zendesk.com/hc/article\_attachments/360030157011/icon-add.png)). This opens a list of the users you can select.
4. Select one or more users from the list, then click _Add_. This adds the selected users to the group, and returns you to the table containing the group’s users. The users you added now appear in the table.

![Figure 3: Select the users to add to the user group.](https://liferay-support.zendesk.com/hc/article\_attachments/360030187852/user-group-add-users.png)
