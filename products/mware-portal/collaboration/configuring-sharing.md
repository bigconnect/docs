# Configuring Sharing

Administrators can choose whether file sharing is enabled at the global, instance, and Site levels.

### Global Configuration <a href="#global-configuration" id="global-configuration"></a>

Sharing is enabled globally by default. To configure sharing globally, follow these steps:

1. Go to _Control Panel_ → _Configuration_ → _System Settings_ → _Sharing_.
2. Under _SYSTEM SCOPE_, select _Sharing_.
3.  Configure sharing via these settings:

    **Expired Sharing Entries Check Interval:** The interval in minutes for how often expired sharing entries are checked for deletion.

    **Enabled:** Whether sharing is enabled globally.

![Figure 1: Configure sharing globally.](https://liferay-support.zendesk.com/hc/article\_attachments/360029909051/sharing-system.png)

When sharing is enabled globally, it’s also enabled by default for all portal instances. You can change this from _Virtual Instance Sharing_ under _VIRTUAL INSTANCE SCOPE_:

**Enabled:** Whether sharing is enabled by default for all instances in the portal.

### Instance Configuration <a href="#instance-configuration" id="instance-configuration"></a>

To enable or disable sharing on a per-instance basis, follow these steps:

1. Go to _Control Panel_ → _Configuration_ → _Instance Settings_ → _Sharing_.
2. Select _Virtual Instance Sharing_ under _VIRTUAL INSTANCE SCOPE_.
3. Check or uncheck the _Enabled_ checkbox to enable or disable sharing, respectively.

![Figure 2: You can enable or disable sharing for each instance.](https://liferay-support.zendesk.com/hc/article\_attachments/360029924452/sharing-instance.png)

Figure 2: You can enable or disable sharing for each instance.

### Site Configuration <a href="#site-configuration" id="site-configuration"></a>

To enable or disable sharing for a Site, follow these steps:

1. Go to Site Administration (your site’s menu) → _Configuration_ → _Settings_.
2. Select the _General_ tab.
3. Expand the _Sharing_ section and use the toggle to enable or disable sharing for the Site.

![Figure 3: You can enable or disable sharing for each Site.](https://liferay-support.zendesk.com/hc/article\_attachments/360029924472/sharing-toggle.png)
