# Creating and Editing Documents and Media Files with Office 365™

You can use Office 365™ to create and edit text documents, spreadsheets, or presentations for storage in the Documents and Media library. When you finish your Office 365™ editing session, you must check in the document to save the changes in the Documents and Media Library.

Here, you’ll learn how to do these things:

* Authenticate with OneDrive™
* Create Files
* Edit Files

### Authentication <a href="#authentication" id="authentication"></a>

The first time you create or edit a Documents and Media file via Office 365™, you must authenticate with your Microsoft account. This links OneDrive™ to your portal account, so you only need to do this once. You can unlink your account at any time by navigating to User Menu → _Account Settings_ → _General_ → _Apps_, and clicking _Revoke_ next to OneDrive™.

### Creating Files <a href="#creating-files" id="creating-files"></a>

Follow these steps to create a new Documents and Media file via Office 365™:

1. Open the _Menu_ (![Product Menu](https://liferay-support.zendesk.com/hc/article\_attachments/360040164231/icon-menu.png)), click your Site’s name, and navigate to _Content & Data_ → _Documents and Media_.
2.  Click the _Add_ icon (![Add](https://liferay-support.zendesk.com/hc/article\_attachments/360040164191/icon-add.png)) and select the type of Office 365™ document to add to the Document Library:

    * Word™
    * Excel™
    * PowerPoint™

    When you select one of these options, a new window opens for you to enter the document’s name.

    <img src="https://liferay-support.zendesk.com/hc/article_attachments/360040159032/office365-new.png" alt="Figure 2: Select the type of document you want to create." data-size="original">

    Figure 2: Select the type of document you want to create.
3.  Enter the document’s name in the _Title_ field, and click _Save_. When you click _Save_, the portal creates a temporary Documents and Media file and links it to the new Office 365™ file. Your browser then opens a new window with that Office 365™ file so you can create its content.

    <img src="https://liferay-support.zendesk.com/hc/article_attachments/360040159012/office365-creation-modal.png" alt="Figure 3: Give the document a name." data-size="original">

    Figure 3: Give the document a name.
4. Use the Office 365™ editor to create your document’s content.
5.  Save or discard your changes to the portal:\


    **Check in:** Saves the Office 365™ file to Documents and Media, then deletes the file from Office 365™. The saved file’s format depends on the document type you selected in step two above.

    * Word: Microsoft Word™ (`.docx`)
    * PowerPoint: Microsoft PowerPoint™ (`.pptx`)
    * Excel: Microsoft Excel™ (`.xlsx`)

    ****\
    **Cancel Checkout:** Deletes the Office 365™ file, discarding any changes.

### Editing Files <a href="#editing-files" id="editing-files"></a>

You can use Office 365™ to edit the following types of Documents and Media files:

* Text files (`.doc`, `.docx`, `.docm`, `.dot`, `.dotx`, `.dotm`, `.html`, `.txt`, `.rtf`, `.odt`)
* Presentation files (`.ppt`, `.pptx`, `.pptm`, `.pps`, `.ppsx`, `.ppsm`, `.pot`, `.potx`, `.potm`)
* Spreadsheet files (`.xls`, `.xlsx`, `.xlsm`, `.xlt`, `.xltx`, `.xltm`, `.ods`, `.csv`, `.tsv`, `.txt`, `.tab`)

Follow these steps to edit a Documents and Media file in Office 365™:

1. Navigate to the file in the Documents and Media Library.
2. Click the file’s Actions icon (![Actions](https://liferay-support.zendesk.com/hc/article\_attachments/360040159052/icon-actions.png)) and select _Edit in Office 365_. This automatically [checks out](https://help.liferay.com/hc/zh-cn/articles/360029040671-Checking-Out-and-Editing-Files) the file, transfers its content to a new Office 365™ file, and redirects you to that file Office 365™.
3.  Edit the file in Office 365™. The editing process is exactly the same as described above for creating files.
