# Using the Documents and Media Management Bar

The Documents and Media _Management Bar_ is where people who manage documents go to unwind after a long day at work. Just kidding. The Management Bar, as its name implies, contains tools for managing the files and folders in your Document Library. It appears above the files and folders in Documents and Media.

![Figure 1: The Management Bar is a great place to hang out if youre managing documents.](https://liferay-support.zendesk.com/hc/article\_attachments/360029908571/dm-management-bar.png)

Figure 1: The Management Bar is a great place to hang out if you're managing documents.

If you’ve added files or folders to your Document Library, then you’re already familiar with the Management Bar’s _Add_ button (![Add](https://liferay-support.zendesk.com/hc/article\_attachments/360029923832/icon-add.png)). The sections that follow describe the rest of the Management Bar.

**Note:** If a Document Library contains more items than it can display at once, you can use the navigation tool that appears at the bottom of the window to switch your view to another page or configure the page to display more items per page.

### View Types <a href="#view-types" id="view-types"></a>

The _View Types_ button is to the left of the Add button. It lets you choose how to display the Document Library’s items. The View Types button’s icon depends on the selected view type:

**Cards** (![Cards](https://liferay-support.zendesk.com/hc/article\_attachments/360029923872/icon-view-type-cards.png)): Shows a card-like rendering of the item. If the item isn’t an image, a generic image for the item’s type is displayed. For files, each card also contains the file’s suffix (e.g., JPG, PNG, etc.), timestamp, name, and workflow status (e.g., Approved, Draft, etc.).

**List** (![List](https://liferay-support.zendesk.com/hc/article\_attachments/360029923952/icon-view-type-list.png)): Shows the same information as the Cards view type, in a list with small file renderings.

**Table** (![Table](https://liferay-support.zendesk.com/hc/article\_attachments/360029923992/icon-view-type-table.png)): Shows the same information as the other view types, in a list with no file renderings. Also, the file information is in columns.

The items in all view types have an Actions menu (![Actions](https://liferay-support.zendesk.com/hc/article\_attachments/360029923912/icon-actions.png)). These actions are also available in when viewing each item separately.

![Figure 2: The Cards View type shows items in large card-like renderings.](https://liferay-support.zendesk.com/hc/article\_attachments/360029908531/dm-images-in-admin.png)

### The Info Panel <a href="#the-info-panel" id="the-info-panel"></a>

To display an info panel with the current folder’s details, click the _Information_ icon (![i](https://liferay-support.zendesk.com/hc/article\_attachments/360029923932/icon-information-dm.png)). The info panel slides out from the right side of the screen and contains the folder’s name and number of items. It also has these buttons:

**Subscribe** (![Subscribe](https://liferay-support.zendesk.com/hc/article\_attachments/360029924012/icon-star.png)): Get notifications about files added to or modified in the folder.

**Actions** (![Actions](https://liferay-support.zendesk.com/hc/article\_attachments/360029923912/icon-actions.png)): Lists actions you can perform on the current folder.

### Finding and Arranging Items <a href="#finding-and-arranging-items" id="finding-and-arranging-items"></a>

The Management Bar also contains tools that help you locate and arrange items in the Document Library. The most prominent of these tools is the _Search_ bar, where you can find files by keywords.

To the left of the Search bar, the Sort button (![Sort](https://liferay-support.zendesk.com/hc/article\_attachments/360029923852/icon-sort.png)) arranges items in ascending or descending order.

You can also arrange items via the _Filter and Order_ selector using these criteria:

**All:** Shows all of the current folder’s immediate subfolders and files (default).

**Mine:** Shows all the current user’s files (no matter their folder).

**Document Type:** Shows the files of the selected document type. Upon choosing this option, you must select the document type you want from a popup.

You can also select from the following criteria for ordering items:

* Size
* Downloads
* Modified Date (default)
* Create Date
* Title

### Selecting Items <a href="#selecting-items" id="selecting-items"></a>

The checkbox on the left-most side of the Management Bar selects all currently displayed items. Selecting multiple items lets you act on all of them at once. You can also select multiple items individually by using the checkboxes for each. When you select one or more items, the Management Bar changes to reflect the actions you can take on the selected items.

![Figure 3: With items selected, the Management Bar changes.](https://liferay-support.zendesk.com/hc/article\_attachments/360029923892/dm-management-bar-actions.png)

Here are the actions you can take on the selected items:

* Download (![Download](https://liferay-support.zendesk.com/hc/article\_attachments/360029908551/icon-download.png))
* Move (![Move](https://liferay-support.zendesk.com/hc/article\_attachments/360029923972/icon-move.png))
* Edit Tags
* Move to Recycle Bin (![Delete](https://liferay-support.zendesk.com/hc/article\_attachments/360029908591/icon-trash.png))

The Actions button (![Actions](https://liferay-support.zendesk.com/hc/article\_attachments/360029923912/icon-actions.png)) contains all the actions displayed in the Management Bar, plus actions for file checkin and checkout. File checkout and checkin is explained in Checking out and Editing Files.
