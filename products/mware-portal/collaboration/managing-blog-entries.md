# Managing Blog Entries

The Blogs app in Site Administration helps bloggers and blog administrators manage blog entries. To access this app, click the Menu button (![Menu](https://liferay-support.zendesk.com/hc/article\_attachments/360029925512/icon-menu.png)) to open the product menu, then expand the menu for your site and select _Content & Data_ → _Blogs_. The _Entries_ tab is selected by default, which lists the site’s blog entries.

![Figure 1: The Blogs app in Site Administration lists the sites blog entries.](https://liferay-support.zendesk.com/hc/article\_attachments/360029909911/blog-entries-site-admin.png)

You can use the Management Bar to manage your site’s blog entries. If you’ve added blog entries via your site’s Blogs app, then you’re already familiar with the Management Bar’s _Add_ button (![Add](https://liferay-support.zendesk.com/hc/article\_attachments/360029925412/icon-add.png)).

### View Types <a href="#view-types" id="view-types"></a>

The _View Types_ button is to the left of the Add button. It lets you choose how to display the blog entries in the Blogs app. The View Types button’s icon depends on the selected view type:

**Cards** (![Cards](https://liferay-support.zendesk.com/hc/article\_attachments/360029909891/icon-view-type-cards.png)): Shows a card-like rendering of the blog entry, with the author’s profile picture. If the entry doesn’t contain a cover image, a generic rendering of the entry is displayed. Each card also contains the entry’s timestamp, title, workflow status (e.g., Approved, Draft, etc.), and an Actions menu (![Actions](https://liferay-support.zendesk.com/hc/article\_attachments/360029925452/icon-actions.png)).

**List** (![List](https://liferay-support.zendesk.com/hc/article\_attachments/360029909931/icon-view-type-list.png)): Shows the same information as the Cards view type, in a list with the author’s profile picture instead of the blog entry’s cover image.

**Table** (![Table](https://liferay-support.zendesk.com/hc/article\_attachments/360029909971/icon-view-type-table.png)): Shows the same information as the other view types, in a list with no file renderings. Also, the blog entry information is in columns.

### Finding and Arranging Blog Entries <a href="#finding-and-arranging-blog-entries" id="finding-and-arranging-blog-entries"></a>

The Management Bar also contains tools that help you locate and arrange blog entries. The most prominent of these tools is the _Search_ bar, where you can find files by keywords.

To the left of the Search bar, the Sort button (![Sort](https://liferay-support.zendesk.com/hc/article\_attachments/360029909871/icon-sort.png)) arranges entries in ascending or descending order.

You can also arrange entries via the _Filter and Order_ selector using these criteria:

**All:** Shows all of the site’s entries.

**Mine:** Shows only the current user’s entries.

**Display Date:** Orders the entries by display date.

### Selecting Blog Entries <a href="#selecting-blog-entries" id="selecting-blog-entries"></a>

The checkbox on the left-most side of the Management Bar selects all currently displayed blog entries. Selecting multiple entries lets you act on all of them at once. You can also select multiple entries individually by using the checkboxes for each. When you select one or more entries, the Management Bar changes to reflect the actions you can take on the selected entries.

Click the _Trash_ button (![Trash](https://liferay-support.zendesk.com/hc/article\_attachments/360029925492/icon-trash.png)) to move the selected entries to the Recycle Bin. Unselect the checkbox to return the Management Bar to its normal view.

![Figure 2: With multiple blog entries selected, the management bar changes to reflect the actions you can take on the selected entries.](https://liferay-support.zendesk.com/hc/article\_attachments/360029925432/blog-management-bar-selected.png)

### Sharing Blog Entries <a href="#sharing-blog-entries" id="sharing-blog-entries"></a>

You can also share blog entries from the Blogs app in Site Administration. Sharing is enabled by default, as described in Configuring Sharing. Sharing blog entries works the same as sharing files.

When sharing is enabled and you have sharing permission, you can share a blog entry by clicking its _Actions_ menu (![Actions](https://liferay-support.zendesk.com/hc/article\_attachments/360029925452/icon-actions.png)) and selecting _Share_.

![Figure 3: You can share a blog entry via its Actions menu.](https://liferay-support.zendesk.com/hc/article\_attachments/360040159072/blog-share.png)
