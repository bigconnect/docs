# Using Social Bookmarks

Social bookmarks appear below content as buttons for sharing that content on social networks. For example, social bookmarks appear by default in the Blogs widget below each blog post.&#x20;

These social bookmarks are available by default:

* Twitter
* Facebook
* LinkedIn
* AddThis
* Delicious
* Digg
* Evernote
* Reddit
* Slashdot
