# Social Settings and Languages

The Social tab provides options for managing the social interactions on your Site. Languages lets you configure language options and change the default language options for the Site.

### Ratings <a href="#ratings" id="ratings"></a>

The _Ratings_ option lets you select the ratings type to use for applications like Documents and Media, Web Content, Comments, etc. Ratings types include Stars, Likes, and Thumbs.

### Mentions <a href="#mentions" id="mentions"></a>

At the bottom of the page is _Mentions_, which lets you enable/disable Mentioning functionality, which is used to _mention_ (notify and/or draw attention to) friends and colleagues by entering the “@” character followed by their user names.

### Languages <a href="#languages" id="languages"></a>

The _Languages_ tab lets you configure the language options for your Site.

![Figure 1: In the Languages tab, you can configure the site to use the instances default language or another supported language.](https://liferay-support.zendesk.com/hc/article\_attachments/360030158211/site-language.png)

You can use the default language or define another supported language as the default for your Site.
