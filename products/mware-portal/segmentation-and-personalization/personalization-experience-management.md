# Personalization Experience Management

There is no direct location for managing all aspects of Experience Personalization. All the different aspects are managed from whatever you’re personalizing. The key integration points of personalization are Content Pages and Content Sets. You can see an overview of their personalization options below.

### Managing Content Page Personalization <a href="#managing-content-page-personalization" id="managing-content-page-personalization"></a>

Before you can Personalize Content Pages, you first need to create Content Pages. When you edit a Content Page, you can click on the _Experience_ to manage the options for that page.

![Figure 1: You can add, edit, delete, or change priority for Experiences.](https://liferay-support.zendesk.com/hc/article\_attachments/360033274512/manage-content-page-experience.png)

1. Go to _Site Administration_ → _Site Builder_ → _Pages_.
2. Click the _Actions_ button ![Actions](https://liferay-support.zendesk.com/hc/article\_attachments/360033274472/icon-actions.png) → _Edit_ for any Content Page.
3. Click on the _Default_ Experience to manage experiences.

From here you have three options:

![Edit](https://liferay-support.zendesk.com/hc/article\_attachments/360029927932/icon-edit.png) changes the name or selected Segment for the Experience.

![Delete](https://liferay-support.zendesk.com/hc/article\_attachments/360029911831/icon-delete.png) deletes the Experience.

![Priority](https://liferay-support.zendesk.com/hc/article\_attachments/360029911811/icon-priority.png) changes the priority of the Experience. If a user meets the criteria for more than one Experience, the highest ordered one is displayed.

When creating a new Experience, you must define the audience by choosing a Segment. If your target audience for the Experience is not yet represented by a Segment, you can create one from the New Experience interface.

![Figure 2: You can add a new Segment while creating a new Experience.](https://liferay-support.zendesk.com/hc/article\_attachments/360036301851/add-seg-from-exp.png)

Next you’ll learn about managing Content Set personalization.

### Managing Content Set Personalization <a href="#managing-content-set-personalization" id="managing-content-set-personalization"></a>

Managing Personalization options for Content Sets is similar. First you must create Content Sets then you can personalize them. To create a new Personalized Variation of a Content Set,

1. Click the _Actions_ button ![Actions](https://liferay-support.zendesk.com/hc/article\_attachments/360033274472/icon-actions.png) → _Edit_ for the Content Set you wish to personalize.
2. Next to the content set is the message _No Personalized Variations yet_. Click the _New Personalized Variation_ button.
3. Select a Segment from the next page to create a variation for that Segment.

![Figure 3: Select a Segment to create a variation for.](https://liferay-support.zendesk.com/hc/article\_attachments/360033265591/select-content-set-variation.png)

You can create a personalized variation for any existing Segment. Each new variation copies the default Content Set, but then essentially functions as its own Content Set after that. To edit or manage a Content Set Variation,

1. Click on the Segment name under _Personalized Variations_.
2. Click on the _Actions_8 button (![Actions](https://liferay-support.zendesk.com/hc/article\_attachments/360033274472/icon-actions.png)) and you can select _View Content_ to preview the content in that set or _Delete_ to remove it.

![Figure 4: You can preview or delete a Personalized Variation from the Actions menu.](https://liferay-support.zendesk.com/hc/article\_attachments/360029927972/manage-content-set-segments.png)

### Previewing User Experiences <a href="#previewing-user-experiences" id="previewing-user-experiences"></a>

As an administrator, when you view a page, you can preview the different experiences that users can have on that page.

1. Click the _Simulation_ button (![Simulation](https://liferay-support.zendesk.com/hc/article\_attachments/360033274492/icon-simulation.png)) icon from the top of any page.
2. Select a segment from the _Segments_ selection to preview the page as a member of that segment.

Viewing the perspective of a segment previews for the administrator any personalizations for Content Pages or Content Sets for that Segment.

![Figure 5: You can preview different experiences from the Preview Panel.](https://liferay-support.zendesk.com/hc/article\_attachments/360029911851/personalization-segment-preview.png)
