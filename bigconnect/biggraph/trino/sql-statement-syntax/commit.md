# COMMIT

### Synopsis <a href="#synopsis" id="synopsis"></a>

```
COMMIT [ WORK ]
```



### Description <a href="#description" id="description"></a>

Commit the current transaction.

### Examples <a href="#examples" id="examples"></a>

```
COMMIT;
COMMIT WORK;
```
