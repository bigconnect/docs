# COMMIT

### Synopsis[#](https://trino.io/docs/current/sql/commit.html#synopsis) <a href="#synopsis" id="synopsis"></a>

```
COMMIT [ WORK ]
```

### Description[#](https://trino.io/docs/current/sql/commit.html#description) <a href="#description" id="description"></a>

Commit the current transaction.

### Examples[#](https://trino.io/docs/current/sql/commit.html#examples) <a href="#examples" id="examples"></a>

```
COMMIT;
COMMIT WORK;
```
