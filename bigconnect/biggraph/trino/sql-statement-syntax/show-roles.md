# SHOW ROLES

### Synopsis[#](https://trino.io/docs/current/sql/show-roles.html#synopsis) <a href="#synopsis" id="synopsis"></a>

```
SHOW [CURRENT] ROLES [ FROM catalog ]
```

![Copy to clipboard](https://trino.io/docs/current/\_static/copy-button.svg)

### Description[#](https://trino.io/docs/current/sql/show-roles.html#description) <a href="#description" id="description"></a>

`SHOW ROLES` lists all the system roles or all the roles in `catalog`.

`SHOW CURRENT ROLES` lists the enabled system roles or roles in `catalog`.
