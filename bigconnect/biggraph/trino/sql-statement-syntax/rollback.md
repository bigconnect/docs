# ROLLBACK

### Synopsis[#](https://trino.io/docs/current/sql/rollback.html#synopsis) <a href="#synopsis" id="synopsis"></a>

```
ROLLBACK [ WORK ]
```

![Copy to clipboard](https://trino.io/docs/current/\_static/copy-button.svg)

### Description[#](https://trino.io/docs/current/sql/rollback.html#description) <a href="#description" id="description"></a>

Rollback the current transaction.

### Examples[#](https://trino.io/docs/current/sql/rollback.html#examples) <a href="#examples" id="examples"></a>

```
ROLLBACK;
ROLLBACK WORK;
```
