# TRUNCATE

### Synopsis[#](https://trino.io/docs/current/sql/truncate.html#synopsis) <a href="#synopsis" id="synopsis"></a>

```
TRUNCATE TABLE table_name
```

![Copy to clipboard](https://trino.io/docs/current/\_static/copy-button.svg)

### Description[#](https://trino.io/docs/current/sql/truncate.html#description) <a href="#description" id="description"></a>

Delete all rows from a table.

### Examples[#](https://trino.io/docs/current/sql/truncate.html#examples) <a href="#examples" id="examples"></a>

Truncate the table `orders`:

```
TRUNCATE TABLE orders;
```
