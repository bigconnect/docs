# RESET SESSION AUTHORIZATION

### Synopsis[#](https://trino.io/docs/current/sql/reset-session-authorization.html#synopsis) <a href="#synopsis" id="synopsis"></a>

```
RESET SESSION AUTHORIZATION
```

![Copy to clipboard](https://trino.io/docs/current/\_static/copy-button.svg)

### Description[#](https://trino.io/docs/current/sql/reset-session-authorization.html#description) <a href="#description" id="description"></a>

Resets the current authorization user back to the original user. The original user is usually the authenticated user (principal), or it can be the session user when the session user is provided by the client.
