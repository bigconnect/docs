# User Authentication

BigConnect Pipelines can authenticate user accounts in several ways.

If you have an enterprise account, you typically use Control Hub authentication to access BigConnect Pipelines.

If you do not have an enterprise account, you use BigConnect Pipelines Accounts to download and log in to BigConnect Pipelines by default. With BigConnect Pipelines Accounts authentication, your user account is granted the Admin role.

You can configure BigConnect Pipelines to use LDAP authentication or file-based authentication. You might make this change when you want to allow multiple users to access BigConnect Pipelines.

BigConnect Pipelines provides several roles that determine the actions that users can perform. The steps you use to assign roles to user accounts vary, based on whether you are using LDAP or file-based authentication.
