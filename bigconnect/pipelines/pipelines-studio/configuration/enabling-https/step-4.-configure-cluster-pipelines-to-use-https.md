# Step 4. Configure Cluster Pipelines to Use HTTPS

To enable HTTPS for cluster pipelines, configure the gateway and worker nodes in the cluster to use HTTPS. If you do not run cluster pipelines, you can skip this step.

Modify the BigConnect Pipelines configuration file, `sdc.properties`, on the gateway node to configure the worker nodes to use the keystore file stored on each worker node. If you created a custom truststore file or modified a copy of the default Java truststore file, configure the gateway and worker nodes to use the truststore file.

1. Verify that you've completed the previous step to configure BigConnect Pipelines to use HTTPS.\
   \
   The gateway node uses the keystore file and keystore password configured for BigConnect Pipelines.\

2.  To define the keystore file used by the worker nodes, configure the following properties in the BigConnect Pipelines configuration file, `sdc.properties`, on the gateway node:\


    | Cluster Pipeline Keystore Property | Description                                                                                                                                                                                                                                                                                                                                     |
    | ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
    | https.cluster.keystore.path        | <p>Absolute path and file name of the keystore file on worker nodes. The file must be in the same location on each worker node.<br></p><p>In our example, we'd configure the property as follows:</p><pre><code>https.cluster.keystore.path=/opt/security/sdc_worker.p12
    </code></pre>                                                          |
    | https.cluster.keystore.password    | <p>Absolute path and name of the file that contains the password to the keystore file on the worker nodes. The file must be in the same location on each worker node.<br><br>In our example, we'd configure the property as follows:</p><pre><code>https.cluster.keystore.password=${file("/opt/security/keystore-password.txt")}
    </code></pre> |
3.  If you created a custom truststore file or modified a copy of the default Java truststore file for cluster pipelines, uncomment and configure the following properties in the BigConnect Pipelines configuration file, sdc.properties, on the gateway node:\


    | Cluster Pipeline Truststore Property | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
    | ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
    | https.truststore.path                | <p>Path and name of the truststore file on the gateway node that stores certificates to trust the identity of the worker nodes. Enter the same path that you entered for the truststore file configured for BigConnect Pipelines.</p><p><br>In our example, we'd configure the property as follows:</p><pre><code>https.cluster.truststore.path=/etc/sdc/truststore.jks
    </code></pre><p>If you register BigConnect Pipelines with Control Hub, set the path and name of the truststore file in the SDC_JAVA_OPTS environment variable with the <code>Djavax.net.ssl.trustStore</code> option. Run the following command:</p><pre><code>export SDC_JAVA_OPTS = "-Djavax.net.ssl.trustStore = &#x3C;path to truststore file> ${SDC_JAVA_OPTS}"
    </code></pre> |
    | https.truststore.password            | <p>Password or path and name of the file that contains the password to the truststore file on the gateway node. Enter the same truststore password that you configured for BigConnect Pipelines.</p><p><br>If configuring a path to a password file, enter an absolute path or a path relative to the <code>$SDC_CONF</code> directory.<br></p><p>In our example, we'd configure the property as follows:</p><pre><code>https.cluster.truststore.password=mypassword
    </code></pre>                                                                                                                                                                                                                                                                         |
    | https.cluster.truststore.path        | <p>Absolute path and name of the truststore file on the worker nodes that stores the certificate to trust the identity of the gateway node. The file must be in the same location on each worker node.</p><p><br>In our example, we'd configure the property as follows:</p><pre><code>https.cluster.truststore.path=/opt/security/truststore.jks
    </code></pre>                                                                                                                                                                                                                                                                                                                                                                                            |
    | https.cluster.truststore.password    | <p>Absolute path and name of the file that contains the password to the truststore file on the worker nodes. The file must be in the same location on each worker node.<br><br>In our example, we'd configure the property as follows:</p><pre><code>https.cluster.truststore.password=${file("/opt/security/truststore-password.txt")}
    </code></pre>                                                                                                                                                                                                                                                                                                                                                                                                      |
4. Restart BigConnect Pipelines to enable the changes.
