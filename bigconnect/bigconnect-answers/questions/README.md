# Questions

Questions are queries plus their visualization. You can ask questions using Answers’s graphical query builder, or create a native/SQL query.

### [Custom expressions](custom-expressions.md) <a href="#custom-expressions" id="custom-expressions"></a>

Custom expressions, like spreadsheet formulas, are tools you can use in the graphical query builder to ask more complicated questions.

### [List of expressions](list-of-expressions.md) <a href="#list-of-expressions" id="list-of-expressions"></a>

You can join data to combine your current data with another table, or even with a saved question.
