# Setting up

## Setting up an admin account

The first thing you’ll need to do is set up an admin account. The account you create when you first install Answers is an admin account by default — handy! If you’ve installed Answers on a production server, you should be really careful to remember the password for this account since it will be used to add other users, connect to databases, set up email, and more. You can also create additional admin accounts later.

For now, let’s just create an account for ourselves to explore Answers. Type in your info, and when you’re ready to continue, click the **Next** button.

## Gathering your database info

At this point you’ll need to gather some information about the database you want to use with Answers. We won’t be able to connect to your database without it, but you’d like to deal with all of this later, that’s okay: just click **I’ll add my data later**. Answers comes with a Sample Database that you can play around with to get a feel for how Answers works.

If you’re ready to connect, here’s what you’ll need:

* The **hostname** of the server where your database lives
* The **port** the database server uses
* The **database name**
* The **username** you use for the database
* The **password** you use for the database

If you don’t have this information handy, the person responsible for administering the database should have it.

## Connect to your database

Now that you have your database info you can connect to your database. Sweet, sweet data at last. Just go ahead and put your info into this form and click **Next**.

For more on connecting to databases, see Adding and managing databases.
