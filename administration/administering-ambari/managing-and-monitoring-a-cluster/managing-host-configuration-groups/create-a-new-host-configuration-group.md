# Create a new host configuration group

To create new groups, reassign hosts, and override default settings for host components, you can use the **Manage Configuration Groups** control:

**About this task**  
To create a new configuration group:  
  
**Steps**

1. Click a service name, then click **Configs**. 
2. In **Configs**, click **Manage Config Groups**. ![](https://docs.cloudera.com/HDPDocuments/Ambari-2.7.3.0/managing-and-monitoring-ambari/how-to/images/amb_mng_cnfg_grps.png) A default config group appears as follows: ![](https://docs.cloudera.com/HDPDocuments/Ambari-2.7.3.0/managing-and-monitoring-ambari/how-to/images/amb_mng_hdfs_cnfgs_ex.png) 
3. In **Manage Config Groups**, click **Create New Configuration Group**. ![](https://docs.cloudera.com/HDPDocuments/Ambari-2.7.3.0/managing-and-monitoring-ambari/how-to/images/amb_create_new_config_grp.png) 
4. Name and describe the group; then choose **OK**.
