# Log In to Ambari as administrator

After installing Ambari, you can log in to Ambari as administrator using the default credentials: username/password = admin/admin

1. To access the Ambari Admin page, enter the following URL in a web browser:`http://[YOUR_AMBARI_SERVER_FQDN]:8080`, where `[YOUR_AMBARI_SERVER_FQDN]` is the fully qualifired domnain name of your Ambari Server host and `8080` is the default HTTP port.
2. Enter your credentials.`username/password = admin/admin`
