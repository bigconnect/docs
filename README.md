# Getting Started

MWARE has a complete product catalog to meet today's data and digitalization and needs.

### Portal

Create amazing digital experiences on the most agile, scalable, and secure portal platform available today.

### Identity & Access Management

Deliver Seamless Login and Authentication experiences with the MWARE IAM Server.

### Virtual Machine

Easily configure, monitor and secure Docker containers in minutes.

### Object Store

Store and quickly access any amount of data reliably in the cloud. The Object Store is an S3-compatible object storage service that lets you store and serve large amounts of data.  The free, built-in Content Delivery Network capability minimizes page load times, improves performance, and reduces bandwidth and infrastructure costs.

### AI

A comprehensive family of cognitive APIs to help you build intelligent apps. Designed to bring AI within reach of every developer, without requiring machine-learning expertise. All it takes is an API call to embed the ability to see, search, understand and accelerate decision-making into your apps.

### Answers

An easy way for everyone to ask questions and learn from data.

### BigGraph

Our proprietary massively scalable big data graph engine with features like enterprise security, enterprise search, dynamic ontologies, Cyper and SQL language support and much more.

### CodeLab

JupyterLab environment with Python, Scala and R kernels and support to install your custom packages.

### Data Pipelines

Easily modernize your data lakes and data warehouses without hand coding or special skills, and feed your analytics platforms with continuous data from any source. An easy-to-use execution engine for fast data ingestion and light transformations that can be used by anyone.

### Discovery

A complete, fast, integrated Business Intelligence service that combines data visualization, exploration and transformation in a friendly and intuitive way.

### Explorer

The perfect service for making sense of unstructured data. See how things are connected, what are their relationships and search information instantly.

### Kafka

Managed Apache Kafka clusters. Just click a button and you'll have a fully managed Kafka cluster up and running in two minutes.

### Spark

A fully managed and highly scalable service for running Apache Spark at scale. Fully managed deployment, logging, and monitoring let you focus on your data and analytics, not on your infrastructure.

### Sponge

Smart, scalable web data collection. Whether is about web sites, blogs or forums, Sponge is a full-featured, flexible and extensible visual web crawler that will help you gather information from web sites and social media.

### TetraML

Create world-class Machine Learning models. A fully distributed in-memory machine learning platform with linear scalability and the most widely used statistical & machine learning algorithms including gradient boosted machines, generalized linear models, deep learning and more.
