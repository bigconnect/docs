# Welcome

## Digitalization

Tailored mostly for government and local administration organization, our digitalization platform is an integrated suite of products designed to meet today's data and digitalization and needs, with a main focus on citizens, automating workflows and inter-organization communication and integration.

### MWARE Portal

Create amazing digital experiences on the most agile, scalable, and secure portal platform available today.

### MWARE Identity & Access Management

Deliver seamless login and authentication experiences with the MWARE Identity & Access Management Server. It's the go-to platform for SSO, Two-Factor authentication, Social Login, SAML, JWT, OAuth and many more.

### **MWARE BPM**

A light-weight, super-fast business process engine designed for deploying and executing Business Processes, Cases and Business Rules. Supports BPMN 2.0, CMMN and DMN.&#x20;

### MWARE ESB

An enterprise API management solution built on the WSO2 API Manager platform. It supports API designing, API publishing, lifecycle management, application development, API security, rate limiting, viewing statistics of APIs, as well as connecting APIs, API Products, and endpoints.

### MWARE Applicaation Server

An enterprise application server built on the Glassfish platform that delivers superb performance, low latencies, containerization, high availability, security and reliability.

## The BigConnect Platform

### BigConnect Intelligence

A comprehensive family of cognitive APIs to help you build intelligent apps. Designed to bring AI within reach of every developer, without requiring machine-learning expertise. All it takes is an API call to embed the ability to see, search, understand and accelerate decision-making into your apps.

### BigConnect Answers

An easy way for everyone to ask questions and learn from data.

### BigConnect Base

Our proprietary massively scalable data lake with features like enterprise security, big graph, enterprise search, dynamic ontologies, Cyper and SQL language support and much more.

### BigConnect Data Pipelines

Easily modernize your data lakes and data warehouses without hand coding or special skills, and feed your analytics platforms with continuous data from any source. An easy-to-use execution engine for fast data ingestion and light transformations that can be used by anyone.

### BigConnect Explorer

The perfect service for making sense of unstructured data. See how things are connected, what are their relationships and search information instantly.

### BigConnect Sponge

Smart, scalable web data collection. Whether is about web sites, blogs or forums, Sponge is a full-featured, flexible and extensible visual web crawler that will help you gather information from web sites and social media.

### BigConnect TetraML

Create world-class Machine Learning models. A fully distributed in-memory machine learning platform with linear scalability and the most widely used statistical & machine learning algorithms including gradient boosted machines, generalized linear models, deep learning and more.

### BigConnect Virtual Machine

Easily configure, monitor and secure Docker containers in minutes.
